# LAST RAIL Act 1 Launch QA Evidence

This folder is the project-local home for launch QA evidence generated by Unity editor tooling.

- `Screenshots/`: portrait 1080x1920 screenshot QA artifacts.
- `Frames/`: editor-flow PNG frame sequences used for video evidence.
- `Video/`: local mp4/webm/gif walkthrough artifacts.
- `Reports/`: small JSON/TXT reports suitable for sharing in launch handoff notes.

Large media artifacts are intentionally ignored by Git unless a release operator explicitly asks to preserve a specific file. Reports and tooling should contain only sanitized QA status, artifact metadata, screen keys, counts, and blocker labels.
