# LAST RAIL | Reina 상세 비주얼 바이블

정리일: **2026-09-21**. 근거: 이 채팅의 Reina 상세 설계 답변과 그 직후 사용자의 **“좋아 ㄱㄱ”**, 기존 [16 아트 방향](16_ART_STYLE_GUIDE.md) 및 [17 오퍼레이터 공통](17_OPERATOR_COMMON_STYLE.md).

**문서 상태:** 기존 보존 외형과 후속 진행 기준으로 채택한 상세안을 유지한다. 이번 채팅에서 얼굴·헤어·복식·색면·역할 장비의 방향과 10인 차별화 보완을 **중립 전신 설계 기준으로 채택**했다. 구체 길이·고정부·파지·모듈 구조·HEX·비례·연출 길이는 실제 시안 검수 전의 비교안이다. 실제 스킬 연결·원화·SD·리그·컷신·실기기 검수 완료를 뜻하지 않으며 신규 전투 기능·개인 서사를 추가하지 않는다.

상위 공통 규칙은 [17](17_OPERATOR_COMMON_STYLE.md), 배경·컷신 제작은 [18](18_BACKGROUND_CUTSCENE_STYLE.md), SD 제작은 [19](19_SD_COMBAT_MODEL_TRANSLATION.md), 시간·입력·DAILY 기록은 [04 §14](04_COMBAT_RUN.md#skill-cinematic-policy)를 참조한다. 공통 규칙을 개인 문서가 덮어쓰지 않는다.

## 1. 캐릭터의 핵심 이미지

> **침착한 시선으로 적의 밀집 지점을 겨누고, 작은 권총에 응축한 마도 화력을 전개하는 전술 사격 요원.**

기존 역할은 **AoE Ranged DPS**, 힘의 체계는 **Science + Arcana**, 전투 정체성은 **Arcane Ballistics**다. 이는 17번이 보존한 기존 기획 역할이며 실제 최신 스킬 코드 전체를 확인했다는 뜻은 아니다. 비주얼 설계가 이를 저격수·순수 마법사로 바꾸지 않는다.

무기를 크게 만들어 화력을 설명하기보다 조준의 정확함·절제된 자세·권총에 모이는 힘과 실제 전장의 광역 효과로 존재감을 만든다.

| 축 | 보여줄 인상 | 피할 결과 |
|---|---|---|
| 인물 | 또렷한 시선·절제된 표정·안정적인 자세 | 항상 화난 얼굴, 무표정만 있는 인물 |
| 장비 | 손에 잡히는 산업적 권총과 작은 마도 보조 장치 | 거대한 라이플, 근거 없는 공중 무기 군단 |
| 행동 | 필요한 순간에 조준하고 힘을 집중하는 움직임 | 끊임없는 곡예·총 돌리기·과도한 전신 회전 |

침착함은 표정과 동작의 연출 방향이다. 출신 부대·과거 사건·계급·정확한 나이·키 같은 서사를 새로 확정하지 않는다.

## 2. 보존할 정체성과 상세 설계안

| 요소 | 기존 보존 기준 |
|---|---|
| 머리 | 네이비·블랙 포니테일 |
| 눈 | 레드·핑크 계열 홍채 |
| 외투 | 블랙·그래파이트 전술 코트 |
| 포인트 | 딥레드 |
| 이너 | 밝은 색의 이너 |
| 하체 | 블랙 허벅지 하이·부츠 |
| 대표 무기 | 권총 |
| 표현 | 고품질 애니메이션풍 2D 원화와 별도로 설계한 SD 전투 모델 |

과거 픽셀 시안의 장총·128×128 규격은 사용하지 않는다. 광역 공격 역할을 이유로 권총을 라이플로 바꾸지 않는다.

**이번 상세안:** 하이 포니테일, 무릎 위에서 끝나는 열린 전술 코트, 오른손 권총, 왼팔의 소형 마도 제어 모듈을 조합한다. 뒤쪽 머리 곡선·코트 자락·전방 권총이 서로 다른 방향으로 읽히게 한다.

왼팔 모듈은 시각적 역할 장비안이다. 이를 그렸다고 새 장비 슬롯·마나 공급 기능·신규 스킬이 생기지 않는다. 기존 역할과 복식의 색·무기는 보존 기준이며 구체적인 길이·고정부·주 손·모듈의 형태는 아래 상세 설계의 검수 대상이다.

## 3. 얼굴·표정·체형

### 3.1 얼굴 — 날카로움보다 정돈된 집중

부드러운 타원형을 바탕으로 눈매에서 집중력이 드러나는 형태를 사용한다.

| 부위 | 상세 설계안 |
|---|---|
| 윤곽 | 볼에서 턱으로 자연스럽게 좁아짐. 지나치게 뾰족한 V자 턱 금지 |
| 눈 | 가로로 정돈된 아몬드형. 바깥 눈꼬리는 약하게 올라가되 공격적으로 과장하지 않음 |
| 눈썹 | 비교적 곧은 형태. 조준 시 안쪽을 조금 내려 집중 표현 |
| 홍채 | 어두운 적색 바탕과 분홍빛 밝은 면. 평상시 눈 전체 발광 없음 |
| 코·입 | 작은 명암과 선으로 정리하되 표정을 지울 정도로 생략하지 않음 |
| 피부 | 중립 원화에서는 균일한 재질·절제된 반사. 조명색과 고유 피부색 분리 |

얼굴의 밝은 면·눈썹·붉은 홍채가 함께 읽혀야 한다. 기본 초상화에서 눈만 밝게 칠하고 얼굴을 검은 그림자로 덮지 않는다.

| 표정 | 표현 |
|---|---|
| 중립 | 입에 힘을 과하게 주지 않고 시선은 명확히 유지 |
| 조준·집중 | 턱이 조금 내려가고 목표에 시선 고정 |
| 가벼운 긍정 | 눈썹과 입가의 긴장만 조금 풀리는 미소 |
| 피로·경계 | 눈꺼풀·입가에 피로를 표현하되 기본 구조 유지 |

네 표정에서 눈 크기·턱선이 임의로 바뀌지 않고 같은 사람으로 보여야 한다.

**Rin과의 얼굴 비교:** 볼에서 턱으로 자연스럽게 좁아지는 흐름과 가로로 정돈된 눈매를 유지한다. [26 Rin](26_RIN_VISUAL_BIBLE.md#face)의 짧은 얼굴·광대 면·짧은 눈썹과 구분한다. 포니테일이 더 길다는 차이에 의존하지 않고, 작은 초상화에서 정돈된 눈매와 앞머리의 큰 면이 남아야 한다. 머리 끝이 잘려도 얼굴과 묶음의 시작으로 같은 인물임을 읽히게 한다.

### 3.2 체형·기준 포즈

성인 인상으로 읽히는 **약 7등신 전후**를 원화 비교값으로 사용한다. 정확한 나이·키의 설정값은 아니다. 어깨와 팔은 권총을 안정적으로 다룰 수 있게, 허리는 과도하게 가늘지 않게, 하체는 무릎·발목·접지가 설명되게 한다.

중립 전신은 의상 구조를 확인할 수 있는 안정된 자세다. 궁극기·키비주얼의 역동적인 포즈는 같은 디자인을 사용하는 별도 표현으로 제작한다.

## 4. 헤어 — 첫 번째 식별 요소

하이 포니테일은 뒤통수 위쪽에서 묶고, 정지 상태의 끝은 등 중간에서 허리 위 사이를 비교한다. **앞머리 → 머리 본체 → 뒤로 흐르는 포니테일**의 세 큰 덩어리를 먼저 읽히게 한다.

앞머리가 양쪽 눈을 모두 가리지 않게 한다. 한쪽으로 조금 흐르는 큰 면을 주되 잔가닥이 각각 다른 방향으로 나뉘어 얼굴을 복잡하게 만들지 않는다.

머리는 차가운 네이비, 코트는 중립 그래파이트로 구분한다. 포니테일 끝과 코트 끝을 같은 위치에 두지 않고 머리는 위쪽에서, 코트는 그 아래에서 끝나게 해 후면 실루엣을 나눈다.

Rin의 짧고 꺾인 하이 테일과 달리 Reina는 뒤로 이어지는 긴 곡선을 유지한다. 후면에서 머리와 코트를 하나의 검은 덩어리로 합치지 않으며, 이 비교를 위해 보존된 헤어·홍채·권총을 변경하지 않는다.

묶는 장치는 작은 무광 고정부와 딥레드 띠를 사용한다. 큰 리본이나 새로운 개인 문장을 추가하지 않는다.

Idle의 머리 움직임은 작게, 조준에서는 몸통이 먼저 안정된 뒤 포니테일이 늦게 따라오게 한다. 궁극기에서 움직임이 커져도 머리가 힘의 원천처럼 떠다니거나 얼굴을 반복해서 덮지 않는다.

## 5. 복식·역할 장비

### 5.1 전술 코트

앞이 열리고 뒤쪽 자락이 두 갈래로 나뉜 무릎 위 길이의 전술 코트를 상세안으로 사용한다.

| 부위 | 설계 |
|---|---|
| 어깨 | 작은 보강 면. 대형 견갑 없음 |
| 칼라 | 낮게 세울 수 있는 짧은 칼라. 턱선·얼굴을 과하게 가리지 않음 |
| 앞판 | 라이트 이너가 보이도록 열림 |
| 허리 | 자연스럽게 정리. 코르셋처럼 강하게 조이지 않음 |
| 소매 | 팔꿈치·손목의 조준 움직임 허용 |
| 뒤 자락 | 중앙 갈라짐으로 다리 움직임과 분리 |
| 딥레드 | 안감·안쪽 접힘·작은 소매 포인트에 집중 |
| 마모 | 밑단·소매 끝·장비 접촉 부위에 제한 배치 |

정면은 검은 코트와 밝은 이너, 이동·조준에서는 딥레드 안감이 읽히게 한다. 동작이 달라져도 같은 옷의 구조를 유지한다.

열린 앞판과 밝은 중심을 보존한다. [23 Sera](23_SERA_VISUAL_BIBLE.md#costume)의 닫힌 밝은 의료복이나 [27 Nyx](27_NYX_VISUAL_BIBLE.md#costume)의 곡선형 겹침 앞판으로 변형하지 않는다.

### 5.2 이너·하체·부츠

이너는 밝은 회백색 기능성 상의다. 얼굴 아래의 밝은 면을 만들어 머리·코트와 분리한다.

하체는 기존 블랙 허벅지 하이·부츠를 유지하면서 짧은 전술 하의와 레그웨어를 코트 아래에 조합한다. 하의의 최종 길이·겹침은 전신 시안에서 확인한다.

부츠는 접지가 읽히는 낮고 안정적인 굽, 작은 정강이 보강과 발목의 접힘 구조를 사용한다. 레그웨어와 부츠가 모두 검어도 재질 차이를 보여준다.

### 5.3 부속 장비 배치

| 위치 | 장비 | 목적 |
|---|---|---|
| 오른쪽 허리 | 권총 홀스터 | 대표 무기의 휴대 위치 |
| 왼쪽 허리 | 소형 보급 파우치 | 좌우 비대칭·현장성 |
| 왼쪽 전완 | 얇은 마도 제어 모듈 | Science + Arcana 연결 |
| 양손 | 파지가 읽히는 전술 장갑 | 손과 사격 동작의 완성도 |

위 부속품은 기본 외형의 구성안이다. 작전 중 3슬롯 장비를 하나씩 몸에 달거나 조합별 새 의상을 생성하는 범위가 아니다.

왼팔 모듈은 권총의 마도 사격을 설명하는 보조 장비안이다. [28 Cipher](28_CIPHER_VISUAL_BIBLE.md#equipment)의 단말처럼 정보 화면과 손가락 입력을 중심 행동으로 만들지 않는다. 기본 식별 순서는 얼굴·포니테일·권총이며, 모듈의 디테일이 이를 약화시키지 않아야 한다.

## 6. 권총·Arcane Ballistics

### 6.1 권총 외형

짧고 단단한 산업적 몸체에 작은 마도 제어부를 결합한다. **그립·총구·상부 몸체가 먼저**, 발광부·제어 모듈은 그다음으로 읽힌다.

긴 총열·개머리판·대형 스코프로 라이플처럼 만들지 않는다. 손에 전부 가려지는 장식품도 피한다. SD에서는 짧은 무기라는 형태와 총구 위치를 조금 강조할 수 있다. 실존 제품명·구체 내부 구조·새 탄약 종류는 확정하지 않는다.

### 6.2 마도 표현

지속적으로 펼쳐진 거대 마법진 대신 조준·발동 순간에 나타나는 짧은 **분절 링·정렬선·응축광**을 사용한다.

| 체계 | 표현 |
|---|---|
| Science | 단단한 권총 몸체, 손의 조작, 모듈 고정부 |
| Arcana | 순간 기하 문양·응축광·탄도와 이어지는 짧은 흔적 |
| 결합 | 손·왼팔 모듈·권총의 방향이 동일한 행동을 설명 |

Vex의 긴 조준축, Mira의 급탄·지속 반동, Nyx의 지속 공간 제어와 다르게 Reina는 **권총에 응축된 힘과 발동 순간**이 중심이다.

피해 범위·발사 횟수·폭발·도탄·관통·상태이상은 실제 스킬이 소유한다. 아트에서 없는 전투 효과를 새로 만들지 않는다.

## 8. 정면·후면·좌·우 기준

주 손은 오른손을 상세안으로 사용한다. 화면 좌우와 인물 자신의 해부학적 좌우를 구분해서 표기한다.

| 방향 | 확인할 정보 |
|---|---|
| 정면 | 눈·앞머리, 열린 코트/이너, 오른손 권총, 왼팔 모듈 |
| 후면 | 포니테일 고정부, 머리/코트 분리, 뒤 갈라짐, 홀스터 |
| 인물 왼쪽 측면 | 왼팔 모듈 두께·고정 위치, 왼쪽 파우치 |
| 인물 오른쪽 측면 | 오른손 파지, 오른쪽 홀스터, 권총 외곽 |

단순 좌우 반전으로 주 손·모듈·홀스터가 뒤바뀌면 안 된다. 미러링 허용 여부는 실제 전투 시점과 파츠 구성을 확인한 뒤 결정한다.

## 9. SD 전투 모델

| 보존 요소 | SD 표현 |
|---|---|
| 포니테일 | 뒤로 빠지는 큰 곡선과 정리된 끝 |
| 붉은 눈 | 작은 붉은 면·또렷한 눈매 |
| 딥레드 코트 자락 | 움직임에서 읽히는 한두 색면 |
| 밝은 이너 | 머리·코트 사이의 상반신 밝기 |
| 권총 | 손과 분리되는 짧은 총구·몸체 |

가닥·봉제선·작은 각인은 덜고 머리/코트 분리와 대표 실루엣을 보존한다. 왼팔 모듈은 미세 글자 대신 얇은 면·발광 위치로 압축한다.

[19](19_SD_COMBAT_MODEL_TRANSLATION.md#prototype-spec)의 **약 3.25등신, 480×480 캔버스, 몸체 약 240px**와 720×1280 화면에서의 몸체 96·128·160px는 비교값이다. 이미 최종 승인된 제작 규격으로 취급하지 않는다.

| 동작 | 인상 |
|---|---|
| Idle | 권총은 안정적으로, 호흡·머리·자락은 작게 |
| Move | 무기·시선을 잃지 않는 짧은 보폭, 머리·코트 지연 |
| Basic Attack | 조준 정리 → 실제 공격 순간 → 짧은 반동 회수 |
| Active | 기본 공격보다 명확한 손·보조 장치 준비, 실제 스킬 효과 |
| Hit | 실제 경직 범위를 넘지 않는 짧은 반응 |
| Down | 중심이 낮아지고 무기가 내려가 전투불능을 표시 |
| Recover | 실제 복귀 허용 시에만 자세 회복 |
| Ultimate | 컷신 모드와 별개로 원궁극기 동작·효과를 연결 |

고공 점프·긴 회전 사격을 기본 요구로 넣지 않는다. 실제 스킬에 그러한 행동이 확인되면 시각안과 대조한다.

## 10. 궁극기 전체화면 장면 구성 — 약 3초 비교안

> **표정이 먼저 집중되고, 손과 장치가 정렬되며, 권총의 발동이 전장으로 이어진다.**

실제 최종 궁극기명·발사 횟수·피해 범위·행동 목록은 현행 자료에서 확인되지 않았다. 아래는 그 데이터를 대신하는 신규 스킬이 아니라 시각 장면 구성이다.

| 구간 | 장면 | 정보 |
|---|---|---|
| 0.00~0.45초 | 얼굴 접근 | 붉은 눈·앞머리·집중하는 시선 |
| 0.45~1.05초 | 손/장치 정렬 | 오른손 권총·왼팔 모듈 반응, 분절 문양 정렬 |
| 1.05~2.05초 | 상반신 대표 포즈 | 얼굴과 권총이 함께 보이는 조준, 머리/코트의 제한된 움직임 |
| 2.05~2.55초 | 힘의 집중 | 총구·조준 방향으로 응축광 집중 |
| 2.55~3.00초 | 전장 연결 | 짧은 발동광과 방향성 전환, 실제 전투로 복귀 |

3초는 시전시간이 아니다. 연사/단발 확인 전 여러 발 사격·여러 적 처치를 고정 연출하지 않는다.

대표 포즈는 몸통을 과하게 비틀지 않은 3/4 구도다. 얼굴·권총·보조 장치가 하나의 사선을 이루고, 포니테일·코트가 반대편으로 약하게 흐른다. 권총으로 눈을 가리지 않는다.

대표 장면은 얼굴 가까이의 작은 권총과 그 방향으로 정리되는 시선에 집중한다. [24 Mira](24_MIRA_VISUAL_BIBLE.md#full-cinematic)의 본체·급탄부 부피나 [25 Vex](25_VEX_VISUAL_BIBLE.md#full-cinematic)의 긴 조준축을 가져오지 않는다. 전체화면과 요약 모두 얼굴을 보호하고, 요약에서는 왼팔 모듈 전체보다 얼굴·포니테일·권총을 우선한다.

배경은 금속 구조와 제한된 경고광을 추상화한다. 현재 전장과 무관한 성역·우주·왕궁으로 이동하지 않는다. 특정 객차 번호·정상 작동 포탑을 고정해 현재 전투 상태와 모순되는 것도 피한다.

## 11. OFF·DAILY 반복의 요약 컷인

**약 0.9초 비교안:** 얼굴·권총이 있는 상반신 등장 → 시선·짧은 발동광 → 실제 전장으로 복귀.

전체화면 영상을 단순 고속 재생하는 대신 대표 포즈를 별도 크롭한다. 공용 분리 원화를 활용하되 얼굴·포니테일·권총이 우선이고, 왼팔 모듈은 공간에 따라 생략할 수 있다. 위험 예고·지원 버튼·실제 타격 위치를 가리지 않는다.

| 모드 | Reina 표시 |
|---|---|
| ON / ALWAYS | 표준 전체화면. 실제 재생 중 전투 유효 배속 0 |
| DAILY의 표준 대상 | 같은 전체화면 자산 사용 |
| DAILY의 반복 대상 | OFF와 동일한 부분 요약 컷인 |
| OFF | 짧은 부분 컷인 + 실제 SD 궁극기 모션/FX. 전투 계속 |

DAILY의 스킬별 집계·초기 기본값·날짜·시청 기록 세부는 [04 §14.6](04_COMBAT_RUN.md#cinematic-daily-policy)의 권장안이다. 이 바이블에서 자동 승인하지 않는다.

비용·피해·쿨타임·스킬 발동은 원스킬 사건이 담당한다. 컷신 종료·스킵·애니메이션 프레임에서 별도 피해나 보상을 지급하지 않는다. 전체화면 종료 시 컷신이 소유한 정지만 해제하고 다른 정지는 유지한다.

## 12. 대표 원화·장면

**A. 기준 전신:** 단순 배경·중립 표정·안정된 자세. 코트·이너·장비·주 손을 가리지 않고, 권총 구조를 확인할 수 있게 한다. 강한 색조명이 기준색을 덮어쓰지 않는다.

**B. 소개 원화:** 황혼의 열차 플랫폼에서 작전 대기. 얼굴은 약한 따뜻한 빛, 머리/코트 외곽은 차가운 객차등, 딥레드 포인트는 제한적으로 드러낸다. 선로·금속 구조가 인물보다 대비가 높지 않게 한다.

**C. 이야기 CG:** 객차의 좌석·작업대에서 권총과 모듈 점검. 전투보다 편안한 표정을 보여주되 머리·복장·부속 장비 위치를 유지한다. 신규 친밀도 시스템이나 특정 스토리 사건의 승인이 아니다.
