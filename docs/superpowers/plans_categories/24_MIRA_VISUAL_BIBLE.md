# LAST RAIL | Mira 상세 비주얼 바이블

정리일: **2026-09-21**. 근거: 비주얼 기획 채팅의 Mira 상세안·교차 검토·개인 보완·후속 기준안 채택.

**문서 상태:** 성인 여성 인상·짧고 굵은 땋은 머리·헤드셋·짧은 방호 베스트·기관총 본체와 급탄부를 구분하는 외형·색면 배치를 **중립 전신 설계 기준으로 채택**했다. 단일 총열/밀착 급탄함은 외형 비교안이며 실제 발사 방식·재장전·과열 규칙의 확정은 아니다. 완성된 원화·SD·컷신·코드·실기기 검증은 없다. 수치·파지·장착 구조는 시안과 기존 스킬에서 확인한다.

공통 품질은 [16](16_ART_STYLE_GUIDE.md)·[17](17_OPERATOR_COMMON_STYLE.md), 장면은 [18](18_BACKGROUND_CUTSCENE_STYLE.md), SD는 [19](19_SD_COMBAT_MODEL_TRANSLATION.md), 시간·입력·복원은 [04 §14](04_COMBAT_RUN.md#skill-cinematic-policy)를 따른다.

## 1. 핵심 이미지

> **한 번의 큰 동작보다, 반복되는 사격을 끝까지 통제하는 화력지원 요원.**

기존 역할 **Sustained Machine Gun DPS**, 힘의 체계 **Science**, 기본 5인 정체성을 유지한다. 근거는 [17 §2](17_OPERATOR_COMMON_STYLE.md#roster)이며 실제 공격 코드 전부를 검증한 것은 아니다.

큰 총뿐 아니라 얼굴·양손·하체가 흔들리지 않는 숙련된 인상이 핵심이다. 평소에는 솔직한 표정과 쉽게 풀리는 입가, 사격에서는 분명히 정리되는 시선·어깨를 사용한다. 항상 소리 지르거나 이를 악물고 난폭하게 무기를 휘두르지 않는다.

기준 조합은 **러스트 브라운의 짧고 굵은 땋은 머리 + 밀착 헤드셋 + 슬레이트 블루 방호 베스트 + 샌드 전투복 + 본체 가까운 급탄함의 기관총**이다. 긴 코트 없이 허리·하체를 드러낸다. 전면 덩어리는 갑옷보다 기관총과 두 팔에서 만든다.

| 비교 대상 | 차별화 |
|---|---|
| Reina | 작은 권총의 응축보다 큰 기관총과 반복 사격을 지지하는 몸 |
| Vex | 가느다란 조준축보다 본체·급탄부의 수평 두께 |
| Kyle | 몸통 전면 방호보다 반동을 회수하는 양팔·어깨·하체 |
| Eve | 설치·정비하는 손보다 무기를 같은 방향으로 통제하는 두 손 |

Kyle의 무기 미확정을 Mira가 대신 결정하지 않는다. Vex의 세부는 [25](25_VEX_VISUAL_BIBLE.md), Reina는 [20](20_REINA_VISUAL_BIBLE.md)를 참조한다.

## 2. 얼굴·표정·체형

### 2.1 얼굴

성인 여성 인상, 볼과 턱에 폭이 남는 얼굴이다. Eve의 부드러운 사각형보다 광대 아래가 조금 정리되고 턱 끝은 넓고 둥글다. V자 턱이나 근육을 과장한 거친 얼굴로 힘을 설명하지 않는다.

윗눈꺼풀은 분명하고 바깥 끝은 짧게 정리한다. Reina보다 눈동자가 조금 더 보이며 집중에서 지나치게 가늘어져 다른 얼굴이 되지 않는다. 눈썹은 두껍고 곧되 끝을 약하게 내려 강함이 악역 과장으로 이어지지 않게 한다.

홍채는 낮은 채도의 황금빛 갈색이다. 구릿빛 머리와 연결하되 얼굴 전체가 오렌지에 몰리지 않게 흰자·피부 명도를 구분한다. 입은 조금 넓어 가벼운 긍정이 분명하게 읽히지만 송곳니·항상 이를 드러내는 표정을 필수화하지 않는다. 피부는 중간 명도의 따뜻한 톤 비교안이며 흉터·분장·기름 얼룩 없이도 식별되어야 한다.

| 표정 | 기준 |
|---|---|
| 중립 | 눈·입에 과한 힘이 없는 안정감 |
| 집중 | 시선과 입가가 정리되고 어깨와 얼굴이 같은 방향 |
| 긍정 | 분명한 입가 변화·풀리는 눈썹 |
| 피로·긴장 | 턱·입 주변 긴장, 얼굴 전체 찡그림은 제한 |

**Kyle과의 얼굴 비교:** Mira의 둥근 턱 끝·드러나는 눈동자·조금 넓은 입과 Kyle의 각진 턱·좁힌 눈·직선 입을 구분한다. 강한 인상을 같은 얼굴 구조로 통일하거나 성별·헤어만으로 구분하지 않는다.

### 2.2 체형·기준 자세

어깨·전완·허벅지에 힘이 느껴지는 탄탄한 체형이다. Kyle처럼 흉부 폭 자체가 전열 방호를 뜻하지는 않는다. 팔꿈치·어깨·무릎·발의 연결로 무게를 보여준다. 과하게 가는 허리·다리·손목을 피한다. 원화 약 7등신은 비교값이지 공식 키가 아니다.

오른손 주 파지, 왼손 하부 지지로 총을 낮게 든다. 총열은 완만한 사선이며 가슴·얼굴을 전부 가리지 않는다. 한 발이 약간 앞이되 과한 런지가 아니다. 무릎을 잠그지 않고 골반·상체가 같은 무게를 지지한다. 이 압력은 실제 전진 이동·이동 제한·반동 수치·Martial 분류를 추가하지 않는다.

## 3. 헤어·헤드셋

러스트 브라운 머리를 뒤로 모아 짧고 굵게 땋는다. 이마를 모두 덮지 않고 한쪽에서 뒤로 넘긴 큰 앞머리 면을 둔다. 눈·눈썹이 보이며 귀 주변은 헤드셋과 간섭하지 않게 정리한다.

땋은 부분은 목덜미에서 등 위쪽까지, 인물 왼쪽에 조금 치우친 배치를 비교한다. 허리까지 늘이지 않는다. Reina의 긴 곡선·Sera의 작은 매듭과 달리 굵은 분절 외곽을 먼저 잡는다. 잔가닥만으로 땋은 구조를 설명하거나 매끈한 일반 포니테일로 지우지 않는다.

끝은 작은 무광 밴드다. 큰 리본·개인 문장이 없다. 오른쪽 어깨의 무기 접점과 겹치지 않으며 왼쪽 머리도 슬링·급탄부 앞에 말려들지 않는다. 사격마다 크게 휘날리거나 길이가 달라지지 않게 한다.

헤드셋은 양귀에 낮게 밀착되는 이어컵과 얇은 상부 밴드다. Eve의 고글 같은 큰 가로 덩어리를 만들지 않는다. 렌즈·대형 안테나·공중 지휘 화면·통신 버프를 추가하지 않는다. 초상화는 착용 상태, 얼굴 보조도는 헤드셋 없이도 구조를 확인한다.

## 4. 복식·방호·휴대

짧은 방호 베스트 + 샌드 긴소매 전투복 + 작업 팬츠 + 접지 부츠를 사용한다. 무기 아래의 허리·골반·무릎이 연결되어야 하며 긴 코트는 없다.

| 부위 | 설계 |
|---|---|
| 베스트 | 허리 위에서 끝나는 슬레이트 블루, 몸 가까운 제한된 부피 |
| 흉부 | 작은 방호 면·고정부. 방패 같은 넓은 한 장 금속판 없음 |
| 오른쪽 어깨 | 얕은 완충 패드 비교안. 무기 접점 설명 |
| 왼쪽 어깨 | 전방 지지팔 공간을 남김 |
| 이너·소매 | 목을 과하게 감싸지 않고 팔꿈치·전완 방향을 보여줌 |
| 장갑 | 손바닥 파지와 손등 보강 구분 |
| 팬츠 | 허벅지 여유·발목 정리·작은 무릎 보강 |
| 부츠 | 넓은 밑창·낮은 굽·발끝/발목 접힘 |

어깨 패드는 반동 감소·방어력 장비 정의가 아니다. 무기 없이도 짧은 베스트와 밝은 소매·하체의 배치가 읽혀야 한다. Vex의 좁은 어두운 몸과 작은 밝은 어깨 패널 구조로 통일하지 않는다.

슬링은 몸 가까이 한 개의 분명한 대각선으로 비교하며 연결부가 실제 이어져야 한다. 여러 줄이 손과 몸을 가리지 않는다. 파우치는 옆·뒤로 제한하고 큰 정비 팩을 추가하지 않는다.

베스트는 무광 코팅 직물, 이너·팬츠는 부드러운 전투복, 무기는 금속·합성 외장이다. 사용감은 어깨 접점·장갑·슬링·무릎·손잡이에 둔다. 검댕을 얼굴 전체에 덮지 않고 서로 다른 무게와 표면을 표현한다.

## 5. 기관총·급탄부 외형

### 5.1 우선 비교안

**단일 총열 기관총 + 본체 가까운 상자형 급탄함**을 우선 비교한다. 드럼형도 후보이지만 본체와 공급부가 나뉘는 상자형부터 확인한다. 회전 총열·거대 백팩 급탄은 부피와 동작 의존성이 크게 달라 현재 기본안으로 선택하지 않는다.

이는 외형 설계이며 실존 제품·내부 작동·구경·탄 수·발사속도는 정하지 않는다.

| 덩어리 | 확인 |
|---|---|
| 본체 | 얇은 장총과 다른 높이·두께·무게 중심 |
| 전방 총열 | 같은 사격 방향으로 연결. 여러 가짜 총구 없음 |
| 급탄함 | 본체 아래/옆에 밀착된 별도 형태 |
| 어깨·손 접점 | 오른손 주 파지·왼손 지지·어깨 관계 |

본체가 얼굴 높이까지 올라오지 않게 하고 큰 조준경으로 Vex처럼 만들지 않는다. 왼손 지지부는 급탄함과 구분한다. 손이 공급부 안에 들어간 듯 보이면 명도·위치를 수정한다.

### 5.2 급탄·파지

정상 파지에서 사수가 총구를 볼 때 **무기 왼쪽 아래**에 급탄함을 붙이는 후보안이다. 인물/화면/무기 좌우를 혼용하지 않는다. 공급 연결은 짧게 정리하고 긴 탄띠가 가슴·다리·옆 요원을 가로지르지 않게 한다.

확대도는 연결부, SD는 두 덩어리와 짧은 연결을 남긴다. 급탄함·탄띠의 시각적 크기는 실제 보유량이나 공격 횟수가 아니다. 본체·급탄함·양손의 경계를 유지하고 얼굴을 가리면 각도와 파지를 먼저 바꾼다. 몸체 전체 축소는 피한다.

### 5.3 기능 경계

탄창 소진·강제 재장전·과열·냉각 대기·고장·바닥 고정 사격을 새로 만들지 않는다. 실제 상태가 없으면 공격 사이의 긴 급탄 교체나 빨갛게 과열된 뒤 정지하는 반복 규칙을 넣지 않는다. 휴대 기관총을 열차 포탑으로 바꾸거나 포탑 궁극기와 연결하지 않는다.

## 7. 정면·후면·좌·우

| 방향 | 확인 |
|---|---|
| 정면 | 눈썹·헤드셋·짧은 베스트·양손·얼굴을 가리지 않는 총 높이 |
| 후면 | 땋은 머리 연결·밴드·슬링·어깨 패드·허리 장비 |
| 왼쪽 | 왼손 지지·급탄함 두께·머리/슬링 겹침 |
| 오른쪽 | 오른손 파지·어깨 접점·팔꿈치 거리·총열 방향 |

인물 좌우는 해부학, 무기 좌우는 사수 기준으로 기록한다. 기준 정면에서 총구가 관객을 정확히 향하는 강한 원근을 피하고 무기 길이·두께를 읽히게 한다. 강한 사격 원근은 별도 키포즈다. 단순 반전으로 파지·급탄함·머리·패드 위치를 바꾸지 않는다.

## 8. SD 전투 모델

다섯 식별 요소는 **짧고 굵은 땋은 머리/헤드셋, 드러난 얼굴, 짧은 베스트와 밝은 전투복, 기관총/급탄부, 버티는 하체**다. 잔가닥·미세 결합선·탄띠 부품·봉제선을 줄인다.

손과 총이 합쳐지면 명도·파지 위치를 조정하고 급탄부가 안 보인다고 대형 팩을 추가하지 않는다. 몸체 높이와 무기 전체 외곽을 따로 측정한다. [19 §3](19_SD_COMBAT_MODEL_TRANSLATION.md#prototype-spec)의 480×480·240px·3.25등신·표시96/128/160px는 비교안이다. 무기가 넘친다고 얼굴·몸만 줄이지 않고 분리/여백을 비교한다.

무기·양팔·몸통의 연결이 중요하다. 무기만 반동으로 움직여 손·어깨에서 떨어지지 않게 한다. 급탄함이 본체와 같이 움직이면 억지로 분리하지 않는다. 슬링·머리도 독립 움직임·렌더 순서에 따라 나눈다. 가려진 손가락·총 뒤 이너·슬링 뒤 베스트·머리 뒤 목을 복원하며 각 다리에 부츠를 포함한다.

## 9. 동작·FX

지속 사격은 큰 상체 젖힘보다 안정된 자세 안의 작은 반동·회수를 우선한다. 시선은 목표를 유지하고 어깨·팔꿈치가 지지한다. 총열이 크게 출렁이는 통제 불가 인상을 피한다. 무겁다는 이유로 실제 이동·공격을 느리게 하지 않는다.

| 동작 | 표현 |
|---|---|
| Idle | 무기를 낮게 유지하는 양손 준비 |
| Move | 몸 가까운 총·발과 상체가 같은 무게를 지지 |
| Basic Attack | 실제 발사에 맞춘 정렬·짧은 반동·회수 |
| Active | 실제 스킬의 준비·기계 반응을 기본 공격과 구분 |
| Hit | 무기를 놓지 않으려는 짧은 팔·어깨 반응 |
| Down | 몸의 중심과 총구가 함께 낮아짐 |
| Recover | 허용 상태에서 중심·양손 파지 회복 |
| Ultimate | 본체·급탄·얼굴·지지 자세, 실제 사건에 연결 |

Down의 떨어진 총은 장비 드랍/무기 상실이 아니며 복귀가 탄약을 지급하지 않는다. 총구광은 짧고 방향이 분명해야 한다. 계속 켜진 거대 불꽃으로 화염방사기처럼 만들지 않는다. 탄도·피격은 실제 사건에 연결하며 장식 탄환이나 반동 루프가 피해를 생성하지 않는다.

고공속에서는 회수 포즈·보간·섬광 노출을 조정하되 횟수를 바꾸지 않는다. 탄피·연기·금속 떨림은 장식 후보이며 경고·피격을 가리거나 보상처럼 보이면 줄인다.

<a id="full-cinematic"></a>
## 10. 궁극기 전체화면

> **정리되는 시선 → 무기를 지지하는 양손 → 어깨·하체의 안정 → 기관총 방향을 따라 전장으로.**

| 순서 | 장면 |
|---|---|
| 1 | 얼굴·헤드셋·러스트 헤어, 표정이 집중으로 정리 |
| 2 | 양손·본체·급탄부 확대 |
| 3 | 어깨·무릎·골반의 지지 |
| 4 | 얼굴·두 손·본체 두께가 남는 대표 반신 |
| 5 | 총열 방향을 따라 실제 SD와 원효과 연결 |

**약 3초**는 애니매틱 비교값이며 실제 시전·공격 대기시간이 아니다. 카메라는 작은 총구광이나 렌즈만이 아니라 **본체·급탄부의 두께와 지지 관계**에 머문다. 외형의 대형화·변신·탄약 보충·과열 해제를 보증하지 않는다.

세로 화면에서는 완전 측면의 긴 총보다 전경으로 약하게 들어오는 3/4를 비교한다. 얼굴은 상단 열린 공간, 손·본체는 중앙, 급탄부는 아래에 둔다. 원근으로 폭을 정리하되 총열을 줄이거나 급탄부를 옮기지 않는다. 총보다 사람이 중심이다.

객차의 차가운 빛으로 금속·베스트를 나누고 얼굴·머리에 작은 따뜻한 빛을 둔다. 배경의 특정 객차 수·정상 포탑을 고정하지 않는다. 발사광·횟수는 실제 궁극기 확인 뒤 결정하며 미확인 다수 처치·벽 관통·폭발은 넣지 않는다.

<a id="summary-cinematic"></a>
## 11. 요약 컷인

**약 0.9초 비교안:** 얼굴·헤드셋·기관총 상부의 반신 → 어깨와 왼손 지지 정리 → 실제 전장. 무기 전체 길이보다 얼굴·주 파지·본체 두께·급탄부 일부를 남긴다. 양끝을 넣으려고 얼굴을 축소하지 않는다.

분리 원화를 활용하되 크롭·타이밍은 별도로 제공한다. 요약에서 총열 일부가 잘리는 것과 외형도에서 끝을 확인하는 것을 구분한다. 긴 외곽은 지원3개·실제 표적을 가리지 않는다. 컷인과 전장의 총이 동시에 쏴 추가 공격처럼 보이지 않게 한다. 모드·시간 계약은 [04](04_COMBAT_RUN.md#skill-cinematic-policy)·[18](18_BACKGROUND_CUTSCENE_STYLE.md#cinematic-scope)를 따른다.

<a id="key-art"></a>
## 12. 대표 원화·장면

**A. 기준 전신:** 양손으로 낮게 지지하고 얼굴·베스트·급탄함·양발을 보여준다. 강한 발사광 없이 확인하고 가려진 복식은 보조도로 설명한다.

**B. 소개 원화:** 정차 열차의 플랫폼·전투 객차 근처에서 경계한다. 얼굴·무기의 무게를 함께 읽히게 하며 배경 철도 구조의 대비는 낮춘다. 고정 기관총 진지·외부 보행 전투 기능의 추가가 아니다.

**C. 이야기 CG:** 무기를 지정 거치대에 두고 장갑·슬링을 정리하는 장면. 표정·어깨를 편안하게 하되 동일 인물이 남아야 한다. 동료 관계·과거 전투·탄약 보급 이벤트를 확정하지 않는다.

## 13. 제작 산출물

중립 전신/복식 보조도, 얼굴4표정·헤어/헤드셋 확대, 네 방향, 기관총 외형·양손/어깨 파지 확대, 준비·반동·회수 키포즈, 몸체/무기 폭 분리 SD 비교, 5인 군집, 전체화면/요약 구도와 안전 크롭, 실제 사건·앵커·revision 연결 자료를 마련한다.

실제 재장전·과열이 미확인인 동안 그 모션을 필수 목록에 넣지 않는다. ID·경로를 문서 완성을 위해 발급하지 않는다.
