# LAST RAIL | Kyle 상세 비주얼 바이블

정리일: **2026-09-21**. 근거: 이 채팅에서 Reina 다음에 작성한 Kyle 상세 비주얼 바이블 답변. 원화 품질·공통 문법은 [16](16_ART_STYLE_GUIDE.md)·[17](17_OPERATOR_COMMON_STYLE.md), 배경/컷신은 [18](18_BACKGROUND_CUTSCENE_STYLE.md), SD 제작은 [19](19_SD_COMBAT_MODEL_TRANSLATION.md)를 참조한다.

**문서 상태:** 최초 수록 당시 세부 제안이었으나, 이번 채팅의 외형 기준안 승인으로 **성인 남성 인상·크롭컷 우선안·넓은 상체·중형 방호·짧은 하체 패널·건메탈/올리브 계열과 개인 차별화 보완을 중립 전신 설계 기준으로 채택**했다. 최종 무기·방패 유무·주 손·정확한 비대칭/HEX·궁극기 실제 동작/길이·자산 매핑은 확인 대기다. 문서 전달을 완성 원화·SD·컷신·구현·실기기 검수 완료로 취급하지 않는다.

**기존 역할과 제안의 경계:** [17 §2](17_OPERATOR_COMMON_STYLE.md#roster)의 Kyle 역할은 **Tank / Block / Taunt**, 방향은 **Science + Martial / Cyber Martial Heavy Vanguard**다. 아래의 ‘돌파·충격’과 ‘단축형 라이플 + 근접 돌파 기능’은 직전 답변의 **시각·무기 후보**를 보존한 것이다. 이를 근거로 기존 블록·도발·공격 방식·이동·궁극기 효과를 변경하지 않는다. 후보와 실제 스킬의 적합성은 구현/기존 원화 확인 후 확정한다.

## 1. 캐릭터 핵심 이미지

> **열차 전열에서 먼저 맞고 먼저 버티며, 적의 진입을 끊고 아군의 사격선을 열어주는 돌파형 전열 요원.**

기본 5인 중에서 플레이어가 먼저 **앞에서 버티는 사람**으로 인식할 캐릭터다. ‘돌파형’은 이번 답변에서 제안한 인상이고 기존 Tank/Block/Taunt를 대신하는 새로운 시스템 역할이 아니다.

Reina가 정교한 원거리 광역 화력의 인상이라면 Kyle은 넓은 상체·낮은 무게중심·강한 접지·방호 장비·근거리 압박으로 대비한다. 라인을 밀고 버티는 전면성을 보여주되 실제 스킬에 없는 이동·밀어내기·충격 피해를 시각안만으로 추가하지 않는다.

## 2. 유지할 정체성과 제안 범위

### 2.1 유지할 방향

기본 5인 출격 멤버이며 전열의 기준이다. Rin보다 무겁고 넓고 안정적인 실루엣을 사용하고, Military / Tactical / Industrial / Post-Collapse와 장갑열차 세계의 기술 문명을 대표한다.

### 2.2 구체화한 범위와 채택 상태

헤어·얼굴 인상·주무기 후보·아머/코트 구조·색 계열·궁극기 구도·SD 식별 요소를 구체화했다. 얼굴·헤어·체형·복식·색면은 이번에 설계 기준으로 채택했지만 무기와 실제 스킬은 제외한다. 기존 승인 원화가 발견되면 승인 순서와 근거를 대조하고 충돌을 보고하며, 최신 채택 방향 또는 기존 상세 내용을 조용히 덮어쓰지 않는다.

## 4. 얼굴·체형

### 4.1 얼굴

얼굴은 미형 여부보다 신뢰감이 먼저 읽히는 방향을 제안한다. 너무 뾰족하지 않은 각진 턱, 짧고 단단한 눈썹, 조금 좁힌 눈매, 과장 없는 직선형 입을 사용한다.

냉정·책임감·선두·버팀목·전투 경험을 표정의 키워드로 두되, 구체 나이·복무 경력·계급·흉터 원인은 새 서사로 확정하지 않는다. 너무 어린 인상·악역처럼 과장한 눈매·흉터만으로 만드는 개성·존재감 없는 무표정은 피한다.

공통 표정 비교는 [17](17_OPERATOR_COMMON_STYLE.md#rendering)을 참조한다. 중립·집중·가벼운 긍정·피로/긴장의 네 장을 같은 인물로 유지한다.

**Mira와의 얼굴 비교:** 넓다는 공통점보다 Kyle의 각진 턱·짧고 단단한 눈썹·조금 좁힌 눈·직선형 입을 유지한다. [24 Mira](24_MIRA_VISUAL_BIBLE.md#face)의 둥근 턱 끝·더 드러난 눈동자·넓은 입과 구분하며 성별·헤어만으로 차이를 대신하지 않는다.

### 4.2 체형

**성인 남성 인상과 넓은 체형 방향**은 중립 전신 설계 기준으로 채택했다. 완성된 몸체 비례의 승인은 아니며, 원화는 Reina보다 확실히 넓고 무거운 체형으로 비교한다. 넓은 어깨·삼각형 상체·굵은 전완·안정된 하체를 사용한다.

움직일 수 없는 중장비 병사나 거대한 파워슈트까지 부풀리지 않는다. 상체 방호의 두께와 큰 장비를 지탱할 체격을 보여주되 전진 동작이 자연스럽게 가능한 관절·허리·다리 구조를 남긴다.

## 5. 헤어 기준 — 크롭컷 우선안 채택

얼굴과 장비를 먼저 읽히게 하는 짧고 정돈된 전투형 스타일이다.

| 후보 | 방향 | 상태 |
|---|---|---|
| A. 짧은 투블럭/크롭컷 | 짧은 앞머리로 얼굴 노출, 기능적 전열 인상, SD 압축 용이 | **중립 전신의 우선 기준으로 채택** |
| B. 짧게 뒤로 넘긴 스타일 | 더 성숙하고 베테랑 같은 인상 | 비교 대안 이력. A와 동등한 현행안으로 혼용하지 않음 |

A안으로 먼저 설계하되 최종 머리 그림의 검수는 남는다. 다크 브라운~흑갈색의 방향을 사용하고 완전 블랙 한 면보다 갈색 기운으로 얼굴·장비와 분리한다. [25 Vex](25_VEX_VISUAL_BIBLE.md#hair)의 옆 사선, [28 Cipher](28_CIPHER_VISUAL_BIBLE.md#hair)의 둥근 웨이브, [29 Iris](29_IRIS_VISUAL_BIBLE.md#hair)의 라운드 픽시컷과 같은 외곽으로 정리하지 않는다.

헬멧·고글과 조합 가능하다는 것은 형태상 여유를 뜻한다. 이번 바이블에서 기본 헬멧·고글 착용을 새 필수 외형으로 추가하지 않는다.

## 6. 의상·방호 구조

**중형 전술 아머 + 레이어드 전술복 + 허벅지까지 오는 짧은 하프코트/가드 패널**을 중립 전신 설계의 기본 조합으로 채택한다. 세부 결합·장착·비대칭은 검수 전이다. 완전 롱코트보다 전열 방호와 이동성을 함께 보여준다.

| 부위 | 설계 방향 |
|---|---|
| 이너 | 짙은 기능성 전투복 |
| 흉부 | 중형 방호 베스트 또는 흉부 아머 |
| 어깨 | 한쪽 또는 양쪽의 제한된 보호 파츠; 최종 비대칭은 보조도에서 결정 |
| 목 | 과도하게 답답하거나 얼굴을 가리지 않는 구조 |
| 장갑 | 손등 보호가 있는 전술 장갑 |
| 하체 | 기능성 팬츠·무릎 보호대·접지 부츠 |
| 허리 | 벨트·파우치·유틸리티 장비 |
| 하프코트/가드 | 뒤쪽의 짧은 전술 패널. 전열 실루엣은 강화하고 다리 움직임은 보존 |

풀 플레이트처럼 전신이 막힌 구조, 탱크 같은 과잉 부피, 지나치게 긴 코트, 과도한 미래형 파워슈트는 이번 제안에서 피한다. 현실적인 밀리터리 인상과 장갑열차 세계의 기술감을 섞는다.

세부 장갑 결합선·파우치 수·마모는 큰 형태가 정해진 다음 추가한다. 색·빛을 제거해도 흉부 방호와 접지가 읽히는지 먼저 확인한다.

큰 면은 흉부와 어깨의 방호에서 만든다. Iris의 한쪽 팔 프레임·Mira의 기관총 부피로 전열의 무게를 대신 설명하지 않는다. Rin과는 흉부 폭·낮은 중심·짧은 하체 패널이 함께 달라야 하며, 좁은 몸체에 큰 무기만 얹은 모델을 크기만 바꿔 사용하지 않는다.

## 7. 주무기 후보

직전 채팅에서 제시한 후보와 추천을 그대로 보존한다. 실제 공격 수단·블록·도발·기존 무기 자산과의 적합성 확인 전에는 운영 무기 정의가 아니다.

| 후보 | 장점/비교점 | 상태 |
|---|---|---|
| 1. 방패 없는 브리칭 샷건형 | 가까운 거리의 대응과 무게감이 잘 읽힘 | 비교 후보 |
| 2. 단축형 라이플 + 전술 배턴/충격기 계열의 근접 돌파 기능 | 짧고 단단한 화기와 산업적 보강, 전면 대응 인상 | **직전 답변의 우선 추천 후보** |
| 3. 중형 자동화기 | 화력 덩어리는 크지만 Mira와 겹칠 위험 | 비추천 후보 |

2안에서는 짧고 단단한 총열, 산업 장비 같은 몸체, 근접 보강 구조를 외형 언어로 사용한다. 장식보다 기능성이 먼저 읽히게 한다.

**확인 경계:** 라이플을 그렸다는 이유로 Kyle을 원거리 DPS로 바꾸지 않는다. ‘충격기·배턴’이라는 후보 이름으로 새 기절·넉백·근접 판정을 추가하지 않는다. 방패를 없애거나 새로 지급하는 결정도 실제 스킬/기존 자산 확인 없이 자동 처리하지 않는다.

기존 전열 역할을 무리 없이 보여줄 수 있는지 먼저 검토한다. 정리 과정에서 샷건·방패 등으로 후보를 조용히 교체하지 않았으며, 미정이 드러나도록 유지했다.

## 8. 팔레트 제안

Reina의 네이비·검붉은 색과 대비되는 **건메탈 + 올리브/카키 + 샌드 계열**을 설계 방향으로 채택한다. 작은 오렌지·앰버 포인트와 현장 재질의 인상을 유지하되 정확한 출력 색상은 검수 전이다.

| 용도 | 색 방향 |
|---|---|
| 메인 아머 | 건메탈·딥 그레이 |
| 이너 | 다크 차콜 |
| 보조 장비 | 올리브·카키 |
| 작은 포인트 | 머스터드 브라운 또는 딥 오렌지 |
| 금속 | 무광 스틸 |
| 가죽/벨트 | 다크 브라운 |
| 궁극기/표현 포인트광 | 따뜻한 오렌지·앰버 |

표의 색 계열은 설계 방향이고 정확한 HEX/RGB 값은 아직 작성하지 않았다. 최종본이라는 이유로 새 색상 코드를 임의로 넣지 않는다.

현장성이 있고 사용감이 자연스러운 팔레트로 비교한다. 지나친 네온, Reina와 겹치는 큰 붉은 면, 과도한 청색 미래광 중심은 이 후보의 중심으로 삼지 않는다. 팀·위험 색은 별도의 UI 규칙을 따른다.

## 9. SD에서 유지할 다섯 요소

| 요소 | 의미 |
|---|---|
| 넓은 어깨 | 가장 먼저 보이는 전열 덩어리 |
| 짧은 머리 | 기능적인 전열 인상 |
| 중형 돌파 무기 후보 | 짧고 단단한 전진 축; 최종 무기 결정에 따라 조정 |
| 흉부 방호 | 버티는 역할의 근거 |
| 하체 가드/짧은 패널 | 전열 이동 실루엣 보강 |

이 다섯 요소는 **현재 디자인 후보의 압축 기준**이다. 아직 미승인인 무기 후보를 필수 제작 규칙으로 확정하지 않는다. 후보가 변경되면 무기 표식과 모션만 명시적으로 갱신한다.

## 10. 정면·후면·좌·우

## 11. SD 전투 모델과 동작

무게감·접지감을 우선하고, 넓은 어깨·짧은 머리·무기 외곽·흉부 방호·짧은 하체 패널을 남긴다. 작은 결합선·파우치 수·봉제선·미세 스크래치는 줄인다. 공통 시제품 규격은 [19](19_SD_COMBAT_MODEL_TRANSLATION.md#prototype-spec)를 참조하며 개별 바이블에서 확정치로 승격하지 않는다.

| 동작 | 시각 인상 |
|---|---|
| Idle | 낮은 무게중심과 준비 자세 |
| Move | 짧고 무게가 느껴지는 보폭 |
| Attack | 반동을 버티고 밀어붙이는 인상 |
| Active | 돌파/밀어냄/충격 전달의 후보 이미지. **실제 동작이 있는 경우에만** 판정과 연결 |
| Hit | 흔들리되 쉽게 무너지지 않는 인상. 실제 경직을 임의 변경하지 않음 |
| Down | 버티다 중심이 무너지는 무게감 |
| Recover | 실제 복귀가 있을 때만 호흡·자세 회복 |
| Ultimate | 전면성·충격의 인상. 실제 한방/광역 여부는 스킬 계약 확인 |

‘무겁게 보임’은 공격속도·이동속도 수치를 낮추라는 뜻이 아니다. 시각 준비·지지·회수로 표현하고 실제 사건 타이밍을 바꾸지 않는다.

<a id="cinematics"></a>
## 12. 궁극기 전체화면·요약 연출

> **버티는 힘이 전진으로 바뀌는 순간.**

Reina의 얼굴·정밀 조준보다 무기·어깨·발·전진 축에 무게를 둔 장면 후보다. 정확한 궁극기명·이동 여부·타격 횟수·범위·재생 길이는 아직 정하지 않았다.

### 12.1 ON / ALWAYS 및 DAILY 첫 재생의 전체화면

| 순서 | 장면 | 중심 |
|---|---|---|
| 1 | 상반신·얼굴 클로즈업 | 고정되는 시선 |
| 2 | 무기를 고쳐 쥐는 준비 | 손과 어깨의 힘 |
| 3 | 발을 딛는 장면 | 접지·무게중심 |
| 4 | 무기와 몸의 전면 행동 | 실제 궁극기가 허용하는 범위의 동작 |
| 5 | 충격 방향을 따라 전장 복귀 | 실제 스킬 사건과 연결 |

금속 반응·먼지·충격 표현을 후보로 사용하되 적을 반드시 죽이는 장면이나 게임에 없는 충격파·이동을 확정하지 않는다. ‘돌파’가 실제 스킬에 없는 경우 전장 이동을 만들지 않고 자세·화면 구성으로 전면성을 표현하는 검토가 필요하다.

위 순서를 유지하면서 무기를 고쳐 쥐고 발을 딛는 구간의 손·어깨·몸통이 같은 힘을 지탱하게 한다. 정밀 사격의 조준선보다 전면성과 접지가 중심이다. 무기 확인 전 이 보완을 새 돌진·넉백·범위 공격의 승인으로 사용하지 않는다.

### 12.2 OFF / DAILY 반복의 요약

짧은 상반신 또는 반신 컷인에서 무기를 쥐는 순간·어깨·전진 방향을 강조하고 실제 SD 동작으로 연결한다. Reina가 얼굴/권총 중심이라면 Kyle은 무기/어깨/전면 축이 중심이다.

DAILY와 ALWAYS는 같은 전체화면 자산, DAILY 반복과 OFF는 같은 요약 구성을 사용한다. 전체화면 동안에는 전투 유효 배속 0, 부분 요약에서는 전투가 계속되는 최신 [04 §14](04_COMBAT_RUN.md#skill-cinematic-policy)를 따른다.

스킵·종료가 피해·비용을 생성하지 않는다. 실제 시전시간을 생략하거나 새 궁극기를 추가하지 않는다. DAILY 세부 집계·기본값·날짜는 공통 미확정 권장안으로 유지한다.

## 검은 도복 양방향 애니메이션 검수 기준 — 2026-11-03 사용자 승인
