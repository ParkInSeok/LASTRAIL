# LAST RAIL | Vex 상세 비주얼 바이블

정리일: **2026-09-21**. 근거: Vex 1차 상세안·10인 교차 검토·개인 보완과 후속 외형 기준안 채택.

**문서 상태:** 성인 남성 인상, 실버 애시 숏레이어, 좁은 재킷과 짧은 비대칭 방진 패널, 긴 정밀 장총의 조준축, 색 계열·색면을 **중립 전신 설계 기준으로 채택**했다. 장총의 정확한 작동·파지·형상, 실제 타깃·보스 부위·공격/궁극기 계약은 확인 대기다. HEX·비례·연출 길이는 비교값이며 원화·SD·컷신·구현·실기기 검수 완료가 아니다.

공통은 [16](16_ART_STYLE_GUIDE.md)·[17](17_OPERATOR_COMMON_STYLE.md), 장면은 [18](18_BACKGROUND_CUTSCENE_STYLE.md), SD는 [19](19_SD_COMBAT_MODEL_TRANSLATION.md), 시간·입력·복원은 [04](04_COMBAT_RUN.md#skill-cinematic-policy)를 따른다.

## 1. 핵심 이미지·기존 역할

> **많이 움직이기보다 필요한 방향을 정확히 잡고, 작은 동작으로 사격 자세를 완성하는 정밀 사격 요원.**

기존 역할 **Elite / Special / Boss Part Sniper**, 힘의 체계 **Science + Martial**을 보존한다. [17 §2](17_OPERATOR_COMMON_STYLE.md#roster)의 기획 역할이며 실제 스킬 코드·타깃 선택을 검증했다는 뜻은 아니다.

거대 장총이나 차가운 표정만이 아니라 사람을 먼저 보여주고 조준에서 얼굴·손·어깨가 한 방향으로 정리되게 한다. 평소 시선과 자세에는 여유가 있다. 항상 날카롭게 노려보거나 얼굴을 가리고 혼자 있는 인물로 고정하지 않는다.

기준 조합은 **실버 애시 옆가르마 숏레이어 + 회보라색 홍채 + 차콜 플럼 재킷 + 왼쪽 어깨의 짧은 스톤 그레이 방진 패널 + 긴 정밀 장총**이다. 후드 망토·거대 강화 슈트보다 얼굴·양손·조준 관계를 드러낸다.

| 비교 | Vex의 차이 |
|---|---|
| Mira | 급탄부 두께보다 길고 정돈된 총열·조준부 |
| Reina | 작은 권총·마도 응축보다 양손 장총과 몸의 정렬 |
| Kyle | 넓은 방호보다 좁은 몸체·절제된 자세 |
| Cipher | 정보 전달보다 자신이 직접 완성하는 사격 |

해금 요원이라는 이유로 마감·장비·발광을 상위호환처럼 만들지 않는다. 기본 요원과 같은 품질의 다른 전술 선택지다.

## 2. 얼굴·표정·체형

### 2.1 얼굴

성인 남성 인상, 조금 긴 타원형과 좁지만 지나치게 뾰족하지 않은 턱선이다. Kyle보다 볼 아래 면을 정리하되 턱 끝 폭은 남긴다. 눈은 가로 방향이 분명하고 위 눈꺼풀이 비교적 곧다. 바깥 끝은 짧게 정리하며 늘 반쯤 감긴 눈으로 무기력하게 만들지 않는다.

눈썹은 중간 두께의 긴 선으로 눈과 나란히 이어진다. 홍채는 낮은 채도의 회보라색이며 마도 발광·문양을 넣지 않는다. 코는 비교적 길게 정리하되 코만 실사처럼 만들지 않고, 입은 얇지만 사라지지 않는 선이다. 깊은 주름·안대·흉터·기계 눈으로 나이·과거를 확정하지 않는다.

| 표정 | 기준 |
|---|---|
| 중립 | 또렷하지만 과한 눈썹·입 긴장 없음 |
| 집중 | 목표 방향 시선, 줄어드는 입가 움직임 |
| 긍정 | 눈 주변과 입가가 작게 풀림 |
| 피로·경계 | 눈꺼풀·입 주변의 긴장, 같은 구조 유지 |

**Cipher와의 비교:** 얼굴의 세로 길이·긴 눈썹·정리된 턱을 보존한다. Cipher의 짧은 얼굴과 반응이 잘 드러나는 눈·입에 같은 헤어만 달리 얹지 않는다.

### 2.2 체형·기준 자세

Kyle보다 좁고 Mira보다 상체 덩어리가 작다. 다만 긴 장총을 지지하기 어려운 가는 팔·손목은 피한다. 옷과 장비 두께로 가벼운 인상을 만들고 과한 허리 축소는 하지 않는다. 정확한 나이·키·출신·경력은 추가하지 않는다.

몸을 과하게 비틀지 않은 기준 전신에서 오른손 주 파지·왼손 전방 지지를 비교한다. 총은 낮은 사선으로 두어 얼굴·양손이 보이게 한다. 좁은 체형·긴 총·정적인 자세는 낮은 HP·더 긴 사거리·느린 이동의 수치 정의가 아니다.

## 3. 실버 애시 숏레이어

앞쪽 길이가 조금 남고 목덜미는 짧게 정리된다. 옆가르마의 큰 면이 인물 왼쪽으로 흐르며 앞머리 끝은 눈썹 주변에서 옆으로 빠진다. 두 눈은 기본 자세에서 보인다.

오른쪽 귀 주변은 짧고 정돈되고 왼쪽 관자놀이에는 조금 긴 면을 남긴다. 귀를 덮는 단발·한쪽 눈을 숨기는 긴 앞머리로 확장하지 않는다. 후면은 둥근 뒤통수와 짧은 끝선, 전면은 사선이 중심이다. Cipher의 웨이브나 Iris의 둥근 짧은 본체처럼 통일하지 않는다.

Sera는 따뜻한 애시블론드와 매듭, Vex는 차가운 회색과 묶이지 않은 외곽으로 구분한다. 순백 대신 뿌리·그림자의 중간 명도를 남긴다. 색으로 나이·염색·신체 변화를 확정하지 않는다.

머리 본체는 안정적이고 끝만 짧게 반응한다. 조준에서 얼굴이 먼저 정리되고 잔움직임이 따라온다. 반동마다 머리가 크게 날려 얼굴을 가리지 않으며 후드·모자를 필수 추가하지 않는다.

## 4. 재킷·짧은 방진 패널

몸 가까운 전술 재킷, 왼쪽 어깨 뒤의 짧은 패널, 기능성 팬츠·낮은 부츠를 조합한다. 밝은 패널은 긴 망토가 아니라 작은 비대칭 면이다.

| 부위 | 설계 |
|---|---|
| 재킷 길이 | 골반 위에서 종료, 긴 뒤 자락 없음 |
| 앞판 | 차콜 플럼의 좁은 면, 큰 가슴 장치 없음 |
| 칼라 | 낮은 스탠드형, 턱·조준 자세를 가리지 않음 |
| 오른쪽 어깨 | 얕은 무기 접점 보강 |
| 왼쪽 어깨 | 짧은 스톤 그레이 패널을 뒤로 연결 |
| 소매·장갑 | 팔꿈치·손목의 천을 정리하고 파지 유지 |
| 팬츠·부츠 | 짙은 회색, 무릎/발목 접힘·낮은 접지 |
| 허리 | 옆·뒤의 작은 파우치, 전면 무기 공간 확보 |

패널은 왼쪽 어깨에서 등 위를 덮고 허리 위에서 끝나는 얕은 사각형이다. 앞쪽은 쇄골 부근에서 정리하고 가슴 중앙을 덮지 않는다. 옆을 열어 왼팔이 앞으로 나갈 때 천이 감기지 않게 한다. 산업용 잠금·재킷 연결을 사용하고 브로치·체인·문장을 중심으로 삼지 않는다.

패널의 비대칭·재질 대비는 은신·피해감소·방진저항·위장 기능을 추가하지 않는다. 밝은 머리와 패널 사이에 어두운 목·재킷 면을 남기고 양어깨 망토로 넓히지 않는다.

재킷은 무광 직물, 패널은 조금 거친 부드러운 직물, 총은 금속·합성 외장이다. 마모는 팔꿈치·어깨·슬링·부츠·파지에 한정한다. 모든 모서리의 밝은 스크래치보다 재단·손·무기와 몸 사이의 공간을 중시한다.

## 5. 정밀 장총·조준부

긴 단일 총열, 비교적 얇은 본체, 낮은 광학 조준부를 우선 비교한다. Mira 같은 큰 급탄 덩어리도, 무게 없는 가느다란 막대도 피한다. 제품명·구경·내부 구조·탄약·볼트액션/반자동/에너지식은 정하지 않는다.

| 부분 | 형태의 우선점 |
|---|---|
| 총열 | 전체 방향을 만드는 긴 선 |
| 본체 | 양손·어깨가 지지할 최소 두께 |
| 조준부 | 본체 위 같은 방향으로 정렬되는 낮은 장치 |
| 어깨 접점 | 무기가 몸에서 떨어져 보이지 않는 관계 |
| 전방 지지 | 왼손과 무기 사이의 빈 공간 |

중립 전신·초상화에서는 눈을 드러내고 실제 조준에서만 눈·조준부·총을 연결한다. 얼굴을 보여주려고 조준부를 옮기지 않는다. 렌즈 반사는 작게, 항상 붉게 빛나는 눈 모양이나 큰 공중 조준 화면은 없다. 기계 눈·이식 센서 없이도 Science 장비를 설명한다.

오른손 주 파지·왼손 지지·오른쪽 어깨 접점을 비교한다. 왼쪽 패널이 지지팔·무기 아래에 말려들지 않게 한다. 슬링은 연결을 보여주되 목·턱·렌즈를 가로지르지 않는다. 파우치는 뒤쪽에 제한하고 대형 탄약 상자·보조총·드론을 추가하지 않는다.

정밀 장총만으로 관통·즉사·헤드샷 배율·방어무시·무한사거리·은신·소음억제·보스 부위 자동 선택을 추가하지 않는다. 기존 역할과 실제 적격성·우선순위·부위 판정은 구분한다. 긴 준비 포즈로 실제 조준 대기·재장전을 새로 만들지 않는다.

## 6. Science + Martial 표현

Science 단독으로 바꾸지 않으며 Martial을 위해 칼·격투·거대 기파를 추가하지 않는다. [17 §7](17_OPERATOR_COMMON_STYLE.md#origin-language)의 자세·중심·사지 힘을 정밀 사격 지지로 구체화한다.

Science는 장총·광학부·파지·기능성 복식, Martial은 잔움직임이 정리되는 손·어깨·중심이다. 장비가 자동으로 겨누는 것이 아니라 사람이 자세를 완성하는 인상이다.

모티프는 **정렬되는 순간**이다. 시선이 먼저 머물고 손·어깨가 방향을 받친다. 준비 동작을 길게 늘이지 않는다. 카메라가 대표 포즈에 잠깐 머물 수 있으나 추가 조준 시간·정지 버프·집중 게이지가 아니다. 기 발산·내공 효과는 실제 정의가 있을 때만 연결하며 Vex만 적·탄환 시간을 늦추는 능력을 추가하지 않는다.

## 8. 정면·후면·좌·우

| 방향 | 확인 |
|---|---|
| 정면 | 두 눈·옆가르마·좁은 재킷·왼쪽 패널·양손 |
| 후면 | 짧은 목덜미·패널 시작/끝·슬링·허리 |
| 왼쪽 | 긴 옆머리·패널 두께·전방 왼팔 공간 |
| 오른쪽 | 귀 주변·오른손·어깨·눈/조준부 관계 |

좌우는 해부학 기준이다. 중립은 낮은 총 사선으로 전신과 무기 끝을 보여주고 강한 원근은 별도 키포즈다. 단순 반전으로 헤어·패널·손을 바꾸지 않는다. 무기 배출/조작부의 미확인 비대칭은 실제 자산 후 기록한다. 외형 네 방향이 전 동작 네 방향 제작을 의미하지 않는다.

<a id="sd"></a>
## 9. SD 전투 모델

필수는 **밝은 숏레이어 사선 / 좁은 몸체 / 왼쪽 작은 밝은 패널 / 긴 장총·낮은 조준부 / 절제된 지지 자세**다. 홍채 층·렌즈 눈금·미세 재단·작은 부품은 줄인다. 밝은 머리와 총만 남기고 얼굴·손·패널을 전부 생략하지 않는다.

[19 §3](19_SD_COMBAT_MODEL_TRANSLATION.md#prototype-spec)의 비교값을 사용하되 몸체 높이와 총 전체 외곽을 따로 잰다. 긴 총 때문에 얼굴·몸을 축소하지 않는다. 같은 높이의 Mira와 좁은 본체·작은 공급부·긴 축·자세로 구분한다.

파츠는 총·양팔·패널·앞머리가 중심이다. 조준 각도 변경 때 왼손이 미끄러지거나 어깨가 떨어지지 않게 한다. 패널은 앞뒤 순서가 바뀌는 부분만 분리한다. 총 뒤 재킷·패널 뒤 어깨/상완·손가락·앞머리 뒤 이마를 복원한다. 각 다리에 부츠를 포함한다.

| Down | 중심·총구가 낮아져 조준 자세 소멸 |
| Recover | 허용 상태의 파지·중심 복귀 |
| Ultimate | 얼굴·조준부·양손 정렬, 실제 사건 연결 |

엎드리기·무릎 꿇기·거치·볼트 조작은 확인 없이 필수화하지 않는다. 절제된 반동은 무반동 성능이 아니다. 무기·자세로 방향을 먼저 보여주고 상시 레이저·새 조준점·보스 부위 표식을 생성하지 않는다. 실제 표시가 있으면 그 UI에 연결한다. 잔상·프레임 반복이 추가 탄환이나 피해를 만들지 않는다.

<a id="full-cinematic"></a>
## 11. 궁극기 전체화면 — 약 3초 비교안

> **대상을 읽는 눈 → 조준부와 양손 → 잔움직임이 정리되는 순간 → 장총 방향을 따라 전장으로.**

| 비교 구간 | 장면 |
|---|---|
| 0.00~0.50초 | 얼굴·실버 헤어·회보라 눈의 집중 |
| 0.50~1.20초 | 파지·전방 지지·낮은 광학부 |
| 1.20~2.00초 | 어깨/무기/시선 정렬, 줄어드는 잔움직임 |
| 2.00~2.60초 | 얼굴과 장총이 보이는 3/4 반신 |
| 2.60~3.00초 | 실제 SD/스킬로 연결 |

Mira와 동일한 전경 큰 총 구도를 반복하지 않고 눈·조준부의 관계를 남긴다. 장총은 아래에서 위 대각선의 약한 원근, 얼굴은 총 위의 열린 공간에 둔다. 한쪽 눈이 렌즈 가까이에 있어도 눈썹·입이 남아야 한다. 패널과 머리를 그림자로 분리한다.

얼굴은 중성광, 머리·총은 짧은 차가운 반사, 패널은 중간 명도다. 금속 프레임·객차 창틀을 추상화한다. 검은 실루엣/렌즈 번쩍임만 남기거나 우주·무한 저격 공간·새로운 먼 표적을 만들지 않는다.

발사 유무·횟수·탄도·결과는 실제 궁극기 확인 뒤 결정한다. 관통·부위 확정 파괴·즉사·거대화·특수 탄환 생성을 고정하지 않는다. 3초는 공통 강제 길이나 시전시간이 아니다.

## 12. 부분 요약 컷인

약 **0.9초** 비교안이다. 얼굴·앞머리·조준부·오른쪽 어깨가 있는 반신에서 무기가 짧게 안정되고 전장으로 연결한다. 얼굴·밝은 머리·낮은 조준부·긴 방향을 우선하며 양끝을 담으려고 인물을 줄이지 않는다.

전체화면 원본을 활용하되 크롭·타이밍은 따로 둔다. 외형도와 요약의 무기 끝 크롭을 구분한다. 총 외곽·장식 조준선이 실제 표적·경고·지원3개를 가리지 않게 한다. 모드·정지·DAILY 세부는 [04](04_COMBAT_RUN.md#skill-cinematic-policy)·[18](18_BACKGROUND_CUTSCENE_STYLE.md#cinematic-scope)에 둔다.

## 13. 대표 원화·장면

**A. 중립 전신:** 낮은 사선 총, 얼굴·양손·패널·발·총끝 확인. 가려진 앞판은 복식 보조도로 보여준다. 발사광 없이 비교한다.

**B. 소개 원화:** 정차 열차의 금속 프레임 옆에서 전방을 살핀다. 시선이 무기보다 먼저 화면 밖으로 이어지고 배경 철도는 깊이를 보강한다. 외부 저격 위치·직접 조준 모드·신규 이동 구간은 아니다.

**C. 이야기 CG:** 객차 좌석/작업대 가까이 안전하게 거치한 총의 광학 외장을 살핀다. 손과 어깨를 편하게 하되 항상 혼자인 경계 서사로 고정하지 않는다. 관계·과거는 별도 승인 내용을 사용한다.
