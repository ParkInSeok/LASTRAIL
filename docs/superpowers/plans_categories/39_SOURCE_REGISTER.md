# 상세 원문 등록부

이 파일은 원문 경로 안내다. 정책 전문은 복사하지 않는다. [현행 번호 문서](00_INDEX.md)에서 명시적으로 정정한 규칙이 우선하며, 그 외 기존 API 필드·오류·직렬화·원요청·복구·상태 수명은 원문을 유지한다. 제목의 승인/완료 표기는 당시의 범위다.

번호 밖의 기존 화면·경제·퀘스트·레이드·협동·내러티브·빌드 계약도 아래에 포함한다. 현행 번호 문서에서 언급하지 않았다는 이유로 폐기하지 않는다. 2026-09-21 후속 전문 정책 대조는 [충돌·보존 결과](38_DOCUMENT_RECONCILIATION.md)와 분야별 보충에 반영했다. 아래 표의 보존 상태는 전문 내용을 삭제/폐기하지 않는다는 뜻이며, 검토 미실시를 뜻하지 않는다. 실제 결정이 남은 충돌은 해당 결과 목록을 따른다.
