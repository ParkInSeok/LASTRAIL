정리일: **2026-09-21**. 이 파일은 적용 안내이며 게임 정책·개인 외형의 별도 원본이 아니다. 현행 기준은 [00_INDEX.md](00_INDEX.md)와 각 담당 문서다.

**출처 한계:** 이전 동명 안내문 원본은 이번 작업에서 확보하지 못했다. 아래 내용은 사용자가 이번 채팅에서 명시한 기준본/변경분 인계와 현재 작성·승인 내용으로 다시 정리한 안내다. 이전 안내의 전체 원문을 그대로 보존·비교했다고 주장하지 않는다.

## 1. 어떤 기준본에 적용하는가

사용자가 처음 다운로드한 기준본은 **00~16번 MD + data 폴더 JSON4개**다. 이후 아트 작업에서17~21이 추가되고00·04·11·16이 수정되었다. 이번 채팅에서는22~29를 작성하고00·16·17·18·19·20·21을 추가 갱신했다.

이 전달은 최초 기준본 이후의 누적 변경분이다. **번호 MD17개 + 안내/지시3개 + 문서 검사1개 = 총21개 파일**을 개별 제공한다. ZIP·중복 합본·30번 통합 바이블은 없다. 적용 후 사용자의 전체 번호 체계는00~29의30개지만, 변경 없는13개 번호 문서는 다시 전달하지 않는다.

| 사용자 폴더 상태 | 이번 적용 |
|---|---|
| 최초00~16 기준본만 있음 | 00·04·11·16 교체,17~29 추가 |
