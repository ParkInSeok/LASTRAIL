## 1. 핵심 이미지와 역할

> **상처 입은 동료를 먼저 살피고, 흔들리지 않는 손으로 다시 전투를 이어갈 여지를 만드는 현장 의료 요원.**

기존 역할은 **Medic / Heal / Down Recovery**, 힘의 체계는 **Science + Arcana**다. 기본 5인 정체성과 [17의 역할](17_OPERATOR_COMMON_STYLE.md#roster)을 유지하며 실제 스킬 코드를 검증했다는 뜻은 아니다.

단순히 온화한 얼굴·밝은 옷보다 상황을 읽는 눈과 필요한 순간 망설이지 않는 손이 중심이다. 평상시에는 열린 인상, 위급할 때에는 눈썹과 입가가 정리되는 집중을 보여준다. 항상 웃거나 걱정하는 얼굴로 고정하지 않는다.

기준 조합은 **애시블론드 로우 번 + 청회색 눈 + 오프화이트 의료 필드코트 + 세이지 보조색 + 부드러운 의료낭 + 손에 잡히는 소형 의료 촉매**다. 장식 로브보다 의료 행동을, 대형 의료 팩보다 얼굴·손을 드러낸다.

| 비교 | Sera의 강조 | 피할 중복 |
|---|---|---|
| Eve | 사람을 살피는 시선·섬세한 도구 취급·처치하는 손 | 공구 헤드·설비 케이스·정비 팩 중심 |
| Iris | 대상을 확인하고 회복을 돕는 행위 | 큰 방어판·충격을 받는 전면 보호 자세 |
| Reina | 열린 손·안정시키는 동작 | 권총 조준과 발사 전 응축 포즈 재사용 |
| Nyx | 같은 처치 대상을 향하는 얼굴과 양손 | 공간의 경계를 정리하는 마도 제어 포즈 |

비교 인물의 전문은 [22 Eve](22_EVE_VISUAL_BIBLE.md)·[29 Iris](29_IRIS_VISUAL_BIBLE.md)·[27 Nyx](27_NYX_VISUAL_BIBLE.md)에 둔다.

## 2. 얼굴·표정·체형

### 2.1 얼굴

조금 길이가 있는 부드러운 타원형을 사용한다. Eve의 볼 폭이 남는 인상과 달리 턱으로 내려오는 흐름은 매끈하되 끝을 과하게 좁히지 않는다.

눈은 Reina보다 가로로 길게 뻗지 않고 위아래의 열림이 조금 더 보인다. 눈꼬리는 거의 수평이다. 처진 눈만으로 다정함을 만들지 않고 시선·눈썹 긴장으로 상황을 구분한다. 눈썹은 완만한 곡선이며 초상화에서 사라지지 않는 두께를 남긴다.

홍채는 낮은 채도의 청회색이다. 평상시 자체 발광이 없고 Arcana 사용 때도 눈 전체가 하얗게 되는 변화를 기본으로 두지 않는다. 코·입은 작은 면으로 정리하되 입술선을 완전히 없애지 않는다. 다정함을 지속적인 홍조나 벌어진 입으로 대신하지 않는다.

| 표정 | 설계 |
|---|---|
| 중립 | 상대를 보는 안정된 시선. 과한 미소 없이 차갑지 않음 |
| 집중 | 턱을 조금 내리고 눈썹 안쪽에 힘. 입은 분명하게 닫힘 |
| 긍정 | 눈 주변이 풀리고 입가가 작게 올라감 |
| 피로·긴장 | 눈꺼풀·입가의 피로와 상대를 살피는 시선 유지 |

**Nyx와의 구조 비교:** Sera는 눈의 위아래 열림과 얼굴의 세로 흐름, Nyx는 상부 얼굴 폭과 완만한 아래 눈꺼풀 곡선이 중심이다. '온화함/신비로움'이라는 표정 명칭만으로 나누지 않는다. 헤어·장비 없는 얼굴 비교에서도 차이가 남아야 한다.

### 2.2 체형·기준 자세

의료 장비를 휴대하고 자세를 낮출 수 있는 성인 보통 체형이다. 과하게 연약하거나 보호받아야 할 인상으로 만들지 않는다. Kyle보다 어깨가 좁고 Eve보다 상체 장비가 가벼워 보이게 한다. 정확한 나이·키·경력은 새로 정하지 않는다.

양발로 안정적으로 서고 상체는 상대를 향해 약하게 열린다. 왼손은 몸 앞에서 자연스럽게 열고 오른손 도구는 낮게 든다. 얼굴과 양손이 같은 처치 대상을 향하는 관계를 남긴다. 상체 기울임·손 내밂은 행동 인상이지 원거리 효과를 근접 처치로 바꾸거나 접근·무릎 꿇기·긴 정지를 필수화하지 않는다.

## 3. 헤어 — 낮은 매듭과 열린 얼굴

애시블론드 머리를 목덜미 위에서 낮고 납작하게 묶은 **로우 번**을 기준으로 삼는다. Reina처럼 긴 꼬리, Eve처럼 턱선 단발이 아니라 뒤통수 아래의 작고 분명한 묶음이다.

중앙에서 조금 벗어난 가르마를 기준으로 큰 면을 나눈다. 이마를 모두 덮지 않고 광대~턱 주변의 짧은 옆머리를 남긴다. 두 눈은 드러낸다. 왼쪽 관자놀이의 작은 무광 직사각 클립은 형태 비교안이며 큰 리본·보석·개인 문장은 없다.

후면에서는 머리가 모이는 방향·묶인 중심·접혀 들어간 끝을 설명한다. 묶음과 칼라 사이에 목덜미 또는 어두운 그림자가 보여야 한다. Iris의 귀가 드러난 짧은 둥근 헤어와 달리 묶음의 연결부를 유지한다.

고정은 작은 천 밴드나 기능성 고정부로 정리한다. 종교 장신구·소속 표장을 추가하지 않는다. 머리 본체와 매듭은 회전을 따라가고 옆머리 끝만 짧게 지연한다. 매듭이 풀렸다 다시 묶이는 듯한 변화는 피한다. SD에서 묶음이 사라지면 연결부·외곽을 강조하되 긴 포니테일로 바꾸지 않는다.

## 4. 의료 필드코트·재질

앞판이 겹쳐 닫히는 오프화이트 필드코트, 어두운 이너·팬츠, 안정적인 작업 부츠를 조합한다. Reina의 열린 코트와 달리 상체에 넓고 정리된 밝은 면을 만든다. 가운·로브처럼 무릎 아래로 길어지지 않는다.

| 부위 | 설계 |
|---|---|
| 길이 | 허벅지 중간. 앉거나 숙일 때 무릎 움직임 유지 |
| 앞판 | 중심에서 약간 벗어난 겹침과 낮은 잠금. 큰 장식 단추 없음 |
| 칼라 | 낮게 서는 짧은 구조. 턱·옆머리와 간격 |
| 어깨 | 작은 부드러운 보강 면. 대형 방어판 없음 |
| 소매 | 팔꿈치 여유·손목 정리. 손을 덮는 넓은 소매 없음 |
| 옆트임 | 보폭·허리 장비 접근을 위한 짧은 트임 |
| 뒤판 | 긴 두 갈래 대신 짧은 겹트임 |
| 허리 | 좁은 기능성 벨트·고정부. 과한 코르셋형 조임 없음 |
| 하체 | 짙은 슬레이트 팬츠·낮고 안정적인 부츠 |

세이지는 칼라·소매 안쪽·잠금 주변의 보조 면이다. 코트 전체를 녹색으로 바꾸지 않는다. Sera의 밝은 면은 몸통 전체에 집중하며 Iris처럼 한쪽 팔만 밝거나 Nyx처럼 짧은 덧깃만 밝은 구조로 변형하지 않는다.

코트는 부드럽게 접히지만 형태가 남는 직물, 장갑은 얇은 작업 재질, 의료낭은 무광 직물, 도구는 단단한 외장과 작은 투명창이다. 밑단·소매·가방 모서리에 사용감을 남기되 처치 도구는 관리된 인상을 유지한다. 새하얀 성물처럼 세계에서 떨어지지 않도록 접힘·잠금·장비 무게·부츠 접지를 보여준다.

## 5. 의료 촉매·휴대 장비

### 5.1 오른손 소형 의료 촉매

손바닥보다 길고 전완보다 짧은 캡슐형 도구를 비교한다. 길쭉한 타원 본체 가운데 파지부, 앞쪽 둥근 작업 헤드와 낮은 보호 프레임, 엄지 조절부, 측면의 좁은 투명창을 둔다.

Eve의 각진 두꺼운 공구나 Reina의 꺾인 권총 실루엣과 다르게 손가락으로 자세를 조절하고 손바닥으로 안정시키는 도구다. 긴 지팡이·거대 주사기·총 같은 치료기를 기본안으로 사용하지 않는다. 내부 촉매 구조·눈금은 실제 치료 횟수·자원·탄창·쿨타임이 아니다.

대표 역할 도구 기준안이며 기본 공격 무기·치유 판정 원점·접촉 필요 여부·스킬 자원을 확정하지 않는다.

### 5.2 왼쪽 뒤골반의 의료낭

Eve의 하드 케이스와 달리 모서리가 부드럽고 납작한 직물 의료낭이다. 왼쪽 뒤골반에 몸 가까이 붙이고 벨트 고정부를 실제로 보여준다. 팔을 뻗을 때 손목을 막지 않게 약간 뒤에 둔다.

덮개·손잡이·얕은 수납 구획은 남기되 병·포장·도구를 바깥에 줄줄이 달지 않는다. 열고 닫는 보조도는 가능하지만 매 스킬에 가방 여는 동작을 요구하지 않는다. 실제 단체 표장을 복제하거나 새 소속·개인 문장을 확정하지 않는다.

### 5.3 열린 왼손

왼손에는 큰 정보 패널·방어판을 추가하지 않는다. 얇은 장갑과 작은 손목 고정부로 정리한다. 대상을 살피거나 안정시키는 형태로 오른손과 같은 행위를 설명한다. 항상 관객에게 손바닥을 편 마법사 포즈로 고정하지 않는다. 의료 도구의 수보다 얼굴과 양손이 같은 대상을 향하는 관계가 우선이다.

## 6. Science + Arcana 표현

Sera의 마법을 화면 효과·나노기술로만 설명해 없애지 않는다. [17 §7](17_OPERATOR_COMMON_STYLE.md#origin-language)의 실제 Arcana와 기술 문명의 공존을 따른다.

| 층위 | 표현 |
|---|---|
| Science | 외장·조절부·보호 프레임·장갑·의료낭 고정부 |
| Arcana | 짧은 빛의 선이 이어지고 정리되는 초상적인 형태 |
| 결합 | 안정된 손 조작과 촉매 주변의 변화가 같은 처치를 설명 |

### 6.1 짧게 이어지는 빛의 선

작업용 시각 모티프 **'봉합광'**은 스킬명·신규 치료 기능이 아니다. 짧게 끊긴 선이 간격을 잇고 작은 매듭처럼 모였다 사라지는 인상이다. 큰 원형 마법진·폭발보다 정리와 연결을 강조한다.

Reina의 전방 사격 인상, Iris의 넓은 방벽과 구분한다. Nyx와의 차이는 빛 색이 아니라 사람을 살피고 처치하는 행동이다. 실제 시작 위치·대상·범위·유지시간은 스킬이 소유하며 모든 회복이 반드시 도구에서 출발한다고 정하지 않는다.

### 6.2 Down Recovery

기존 역할은 보존하되 자기 부활·전원 소생·영구 사망 복구·무제한 복귀로 확대하지 않는다. 실제로 허용되고 상태 전환이 일어난 경우에만 대상이 일어나는 모습을 연결한다. 손동작·빛의 종료가 정상 상태를 만드는 판정이 아니다. Sera 자신의 Recover 모션과 다른 요원에게 사용하는 Down Recovery를 구분한다.

| 방향 | 개인 확인 |
|---|---|
| 정면 | 이마·두 눈·청회색 홍채·겹친 밝은 앞판·오른손 촉매·왼손 |
| 후면 | 낮은 매듭 연결·목덜미/칼라 간격·짧은 뒤트임·의료낭 고정부 |
| 왼쪽 | 헤어 클립·귀 주변·의료낭 두께·왼팔 공간 |
| 오른쪽 | 도구 파지·헤드·허리 수납부·겹침 앞판 두께 |

좌우는 해부학적 좌우다. 수납부는 코트 바깥 고정부와 이어지며 도구가 옷을 관통하지 않는다. 헤어·가방·도구가 비대칭이므로 단순 반전을 기본 허용하지 않는다. 도구를 보여주기 위해 반대 손으로 옮기지 않는다.

<a id="sd"></a>
## 9. SD 전투 모델

필수 식별 요소는 **낮은 매듭 / 열린 얼굴·손 / 밝은 닫힌 의료 필드코트 / 길쭉하고 둥근 소형 촉매 / 부드러운 의료낭**이다. 홍채 세부·도구 눈금·가방 봉제선·작은 잠금부는 줄인다.

매듭이나 도구가 사라지면 배치·명도·손과 간격부터 조정하고 긴 머리·대형 지팡이로 바꾸지 않는다. 밝은 코트와 피부가 붙어 팔이 사라지는지, 가방이 자락처럼 보이는지, 도구 손과 열린 손이 나뉘는지 확인한다.

[19 §3](19_SD_COMBAT_MODEL_TRANSLATION.md#prototype-spec)의 3.25등신·480×480·240px 몸체·96/128/160px 표시 시험을 비교로 사용한다. 확정 규격이 아니다.

파츠는 오른팔/도구·왼팔·움직이는 코트 하단·필요한 옆머리 중심으로 판단한다. 매듭이 머리와 함께 움직이면 억지로 나누지 않는다. 의료낭의 관성과 렌더 순서를 보고 분리한다. 왼팔 뒤 앞판·가방 뒤 코트/허리·매듭 뒤 목·도구 뒤 손가락을 복원한다. 각 다리에 부츠를 포함한다.

<a id="motion"></a>
## 10. 동작과 전장 FX

| 동작 | 표현 | 경계 |
|---|---|---|
| Idle | 낮은 도구·편안한 시선·손 | 상시 치유 없음 |
| Move | 도구·가방을 몸 가까이 두고 균형 이동 | 실제 속도 변경 없음 |
| Basic Attack | 실제 수단에 맞는 파지·회수 | 도구 사격/마법탄/공격 불가 임의 결정 없음 |
| Active | 대상 확인·명확한 손 조작 | 치유와 Down Recovery를 같은 스킬로 합치지 않음 |
| Hit | 도구 회수·짧은 상체 반응 | 긴 경직 추가 없음 |
| Down | 중심·손·도구가 낮아짐 | 스스로 회복광을 켜 자동 부활하지 않음 |
| Recover | 허용된 상태에서 중심·파지 복구 | 모션 종료가 부활 판정 아님 |
| Ultimate | 판단·열린 손·촉매 변화 | 원스킬 대상·효과·조건 확인 |

회복의 시작·적용·유지·종료를 실제 상태와 구분해 읽히게 한다. 끝난 효과의 잔광이 지속 치유로 보이지 않게 하고, 미완료 Down Recovery 대상에 성공 표시·정상 자세를 먼저 보여주지 않는다. 장식광을 줄여도 실제 성공과 상태 변화는 판독 가능해야 한다.

<a id="full-cinematic"></a>
## 11. 궁극기 전체화면 — 약 3초 비교안

> **대상을 보는 눈 → 안정된 양손 → 촉매와 이어지는 짧은 빛 → 실제 전장.**

| 비교 구간 | 장면 | 정보 |
|---|---|---|
| 0.00~0.50초 | 얼굴 접근 | 낮은 매듭·대상 확인·정리되는 집중 |
| 0.50~1.20초 | 양손과 도구 | 오른손의 작은 조작·열리는 왼손 |
| 1.20~2.30초 | Arcana 연결 | 촉매와 손 가까이의 짧은 선 |
| 2.30~3.00초 | 대표 반신·전장 연결 | 얼굴·양손·도구가 함께 읽힘 |

3초는 시전·회복·복귀 시간이나 대상 수가 아니다. 몸통은 약한 3/4, 왼손은 얼굴보다 낮게 바깥으로, 오른손 촉매는 가슴 아래에 둔다. 얼굴과 두 손이 완만한 삼각형을 이루되 과도한 손가락 벌림·큰 손바닥 원근은 피한다. 도구는 관객에게 겨누지 않고 처치 방향을 설명한다.

얼굴과 손을 촉매광으로 가리거나 두 팔 사이에 큰 원을 넣어 공간 제어처럼 만들지 않는다. 작은 몸 이동과 정확한 손을 강조하며 공중 부양·변신을 기본에 넣지 않는다.

배경은 금속 프레임·중성 작업등의 추상 공간이다. 얼굴은 중성광, 코트는 차가운 그림자, 손은 제한된 따뜻한 반응광이다. 밝은 머리·옷·FX를 같은 흰색으로 날리지 않는다.

특정 동료가 매번 쓰러졌다 일어남·전원 완전회복·영구 부상 소멸·열차 시설 복구를 고정 결말로 만들지 않는다. 실제 대상과 결과는 전장 상태에서 보여준다.

<a id="summary-cinematic"></a>
## 12. 부분 요약 컷인

**약 0.9초 비교안:** 얼굴과 열린 왼손의 반신 → 촉매 주변의 간단한 빛 정리 → 손 방향으로 전장 연결. 얼굴·매듭 일부·밝은 코트 상단·열린 손·촉매를 우선한다. 의료낭 전체를 넣으려고 축소하지 않는다.

전체화면 분리 원화를 활용하되 별도 크롭·타이밍을 제공한다. 실제 회복 대상·Down 표시·위험 예고를 컷인 뒤에 가리지 않는다. 모드 연결과 정지·입력·복원은 [04](04_COMBAT_RUN.md#skill-cinematic-policy)·[18](18_BACKGROUND_CUTSCENE_STYLE.md#cinematic-scope)를 참조하며 DAILY 세부를 여기서 확정하지 않는다.

<a id="key-art"></a>
## 13. 대표 장면

**A. 중립 전신:** 밝은 앞판·매듭·양손·도구·의료낭을 확인한다. 왼팔을 몸에 완전히 붙이지 않고 오른손 도구의 옆면을 읽히게 한다. 강한 치유광 없이 비교한다.

**B. 소개 원화:** 열차 의료/지원 공간에서 출격 전 도구를 확인한다. 큰 설비보다 작은 도구·의료낭·화면 밖 동료를 향하는 시선이 중심이다. 객차 종류·시설·해금 조건은 새로 확정하지 않는다.

**C. 이야기 CG:** 작업대에서 의료낭을 정리하거나 장갑을 내려놓는 조용한 장면. 전투와 같은 얼굴·복식을 유지하고 승인 없는 부상·관계·사건을 확정하지 않는다.

## 승인 서사 기반 디자인 상세 후보 — 2026-10-17

Direction_11. 근거: [32 승인 서사 골격](32_NARRATIVE_REFERENCE.md#sera-narrative-approved-20261017). 이 절은 사용자 검수용 디자인 제안이며 최종 미술 승인이 아니다. op_sera와 기존 승인 초상/외형 기준을 유지한다. 기존 sera-idle-firstpose-d2-v01은 미승인 후보다. 신규 이미지 생성·수정 및 애니메이션/Unity 연결은 수행하지 않았다.

### 인상과 서사의 연결
세라는 철수 의료 거점에서 여러 사람을 살린 숙련자이며, 구하지 못한 결과까지 떠안는 사람이다. 사람을 직접 보는 열린 시선과 처치 중 안정된 손을 기본으로 한다. 책임감은 장비를 제자리에 정돈하고 인계 뒤에도 확인하려는 습관으로 표현한다. 상시 피로/슬픔으로 기본 얼굴을 바꾸지 않는다. 성장 후에는 같은 복식과 도구로 어깨와 손의 긴장이 풀리고 동료에게 자리를 내어 주는 대비를 만든다. 새 유품·상처·종교/소속 문장으로 미결 과거를 시각 확정하지 않는다.

### 상세안
| 요소 | 구체화 후보 | 목적과 검수 |
|---|---|---|
| 얼굴·헤어 | 승인 얼굴 구조·애시블론드 낮고 납작한 매듭 유지. 옆머리는 두 눈과 처치 시야를 열고, 기존 작은 무광 직사각 클립 후보는 기능성 고정물로만 비교 | 상시 처진 눈·다크서클을 추가하지 않음. 클립은 신규 채택 아님 |
| 코트 | 오프화이트 겹침 앞판을 큰 밝은 면으로 유지. 짧은 세이지 칼라 안쪽과 정리된 소매 끝, 어두운 이너로 목·손 경계 분리 | 장식 수보다 겹침·소매·허리 구조로 밀도 확보. 허벅지 중간 길이/옆트임 유지 |
| 재질·사용감 | 밑단·부츠·의료낭 모서리에 제한된 마찰. 촉매 작업부와 손목 주변은 관리된 상태 | 철수 경험을 특정 상처나 혈흔으로 대신하지 않음. 과도한 오염으로 처치 인상을 흐리지 않음 |
| 손 | 얇은 작업 장갑과 기존 작은 손목 고정부. 오른손은 촉매를 안정적으로 쥐고 왼손은 상대를 안내하는 자연스러운 열림 | 손가락을 과장해 벌리지 않음. 좌우 손/엄지/손바닥 구조를 모든 방향에서 확인 |
| 촉매 | 캡슐 외장, 낮은 보호 프레임, 엄지 조절부, 좁은 투명창. 단단한 청회 외장과 작은 따뜻한 내부 반응광 비교 | 대기 시 강한 발광 없음. 빛은 독립 효과이며 표면 눈금을 실제 잔탄/횟수로 사용하지 않음 |
| 의료낭 | 왼쪽 뒤골반에 납작한 무광 직물, 몸 가까운 벨트 고정부, 단순 덮개와 짧은 손잡이 | 사용 흔적과 정돈된 형태의 대비. 외부 병/부적/장식 묶음 없이 손목과 코트 동선 확보 |

### 표정·자세 검수안
