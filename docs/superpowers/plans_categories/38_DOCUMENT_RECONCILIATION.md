## 임의 확정하지 않은 항목

1. **T18 예비 배선:** HP0 객차에서 Gun 임시 작동 후보는04 J01의 객차 생존 필수와 충돌한다. 현재 기본 생존 조건을 유지하고 후보 재설계/명시 예외 결정 전 사용하지 않는다.
2. **노드3선택과 물리 좌우 분기:** 맵의3선택을 좌우 레버2갈래/연속 자동확정과 동일시하지 않는다. 확인 시점과0.01 시간 정책의 대응이 필요하다.
3. **협동 시간:** 온라인 서버 시간·선택/전체화면 정지·역할 소유 hold의 결합은 실제 권위 계약 확인이 필요하다. 로컬 정지를 네트워크 정지 완료로 주장하지 않는다.
4. **작전 보급품:** 도입 방향은 채택됐으나 시작30/협동20, 가격·수급은 제안이다. 서로 다른 숫자를 확정 표로 합치지 않는다.
5. **World Raid 초기화:** 기존05KST와 공통04KST가 다르며 기존 계약은 레이드 시각 유지라고 명시한다. 변경 승인 전 임의 통일하지 않는다.
6. **출석 엘리트 확정권:** 실제 아이템/풀/소비 경로가 미확정이다. 과거15인 제안을 출시10인으로 추정 치환하지 않는다. binding 없는 상태를 개방하지 않는다.
7. **캐릭터 효과 매핑·신규 노드 목표 집계·구형 성장 카탈로그:** 최신 그림/맵으로 바뀌었다고 저장 ID·스킬 효과·퀘스트 웨이브·구매 가능 대상을 자동 변경하지 않는다.
8. **기존 명시 미승인 사항:** J04 적/웨이브 수, 전체 맵 길이, 상세 균등 랭킹 지급량, 실제 SKU·플랫폼 연결·publishable=false 작성 데이터는 확정/구현으로 승격하지 않는다.
