# LAST RAIL | Nyx 상세 비주얼 바이블 — 가칭

정리일: **2026-09-21**. 근거: Nyx 상세안·교차 검토·개인 보완·후속 외형 기준안 채택.

**문서 상태:** 성인 여성 인상, 풀어 내린 애시 모브 중장발, 곡선형 코트와 밝은 덧깃, 열린 휴대 촉매, 색 계열·색면을 **중립 전신 설계 기준으로 채택**했다. 정확한 촉매·파지·비례·HEX·재생 길이는 검수 전이며 실제 영역·대상·효과·지속/종료는 스킬 확인 대기다. 원화·SD·컷신·코드·실기기 검증을 완료한 문서가 아니다.

[16](16_ART_STYLE_GUIDE.md)·[17](17_OPERATOR_COMMON_STYLE.md)은 공통 품질, [18](18_BACKGROUND_CUTSCENE_STYLE.md)은 장면, [19](19_SD_COMBAT_MODEL_TRANSLATION.md)는 SD, [04](04_COMBAT_RUN.md#skill-cinematic-policy)는 시간·입력·복원을 담당한다. Nyx는 작업명이며 이름의 의미·첫 글자로 문양/로고·새 ID를 고정하지 않는다.

<a id="identity"></a>
## 1. 핵심 이미지·역할

> **한 지점을 향해 힘을 쏘아내기보다, 손과 촉매로 전장의 공간을 정리하는 마도 제어 요원.**

기존 **Arcane Control / Zone Control**, **Arcana 중심·공통 기술 문명 기반**을 [17 §2](17_OPERATOR_COMMON_STYLE.md#roster)에 따라 보존한다. 스킬명·범위·대상·지속시간 확인을 대신하지 않는다.

큰 마법진보다 어디를 제어하려는지 읽히는 시선·손·촉매가 중심이다. 평소 주변을 살피는 여유, 집중에서 시선과 손 사이의 분명한 간격을 사용한다. 항상 무표정·불길한 웃음으로 고정하지 않는다.

기준 조합은 **애시 모브 중장발 + 옅은 황갈색 홍채 + 딥 청록 곡선 코트 + 밝은 짧은 덧깃 + 왼손의 열린 타원 촉매**다. 후광·등 뒤 거대 원형 장치 대신 손 가까운 곡선과 옷자락을 사용하고 효과를 꺼도 식별되게 한다.

| 비교 | Nyx의 차이 |
|---|---|
| Reina | 권총 응축·발동 순간보다 공간 정리 |
| Sera | 처치 대상을 향하는 손보다 위치·영역을 다루는 손 |
| Iris | 충격 방어의 불투명한 면보다 경계·표식 |
| Cipher | 정보 화면보다 실제 Arcana가 나타나는 물리 촉매 |

기본 마도 요원의 상위호환으로 만들지 않는다. 전문 비교는 [23 Sera](23_SERA_VISUAL_BIBLE.md)·[29 Iris](29_IRIS_VISUAL_BIBLE.md)·[28 Cipher](28_CIPHER_VISUAL_BIBLE.md)를 참조한다.

## 2. 얼굴·표정·체형

### 2.1 얼굴

성인 여성 인상, 이마·볼에 폭이 있고 아래로 부드럽게 정리되는 타원형이다. Rin보다 세로 흐름을 남기고 Vex처럼 턱 아래를 날카롭게 정리하지 않는다. 나이·키·소속·마도 교육·출신은 추가하지 않는다.

눈은 길이가 있으나 눈꼬리를 과하게 올리지 않는다. 위 눈꺼풀은 완만하고 아래 곡선이 조금 더 보인다. 반쯤 감겨 무기력한 눈을 기본으로 두지 않는다. 눈썹은 적당한 두께의 완만한 곡선이며 집중에서 안쪽이 정리된다.

홍채는 밝기를 낮춘 옅은 황갈색이다. 애시 모브와 대비되는 작은 따뜻한 면, 상시 문양 눈·이중 동공·발광은 없다. 코·입은 작은 면이지만 표정이 남아야 한다. 신비함을 입 생략·항상 비웃는 표정으로 대신하지 않는다.

| 표정 | 기준 |
|---|---|
| 중립 | 열린 눈·힘이 적은 입가 |
| 집중 | 턱이 조금 내려가고 시선·손이 같은 공간 |
| 긍정 | 눈과 입가가 함께 풀림 |
| 피로·경계 | 눈꺼풀·입 주변 긴장과 같은 비례 |

**Sera와의 비교:** Nyx의 상부 얼굴 폭·아래 눈꺼풀 곡선과 Sera의 위아래 열린 눈·긴 얼굴 흐름을 구분한다. '신비/온화' 표정과 색만으로 나누지 않는다. 촉매·머리·빛 없는 얼굴도 구별되어야 한다.

### 2.2 체형·기준 자세

어깨가 과하게 넓지 않은 보통 체형이다. 긴 옷이 몸을 가늘게 보이게 하더라도 복식 보조도에서 어깨·골반·다리를 설명한다. 기본 부유가 아니라 두 발이 지면에 안정적으로 닿는다.

몸은 약한 사선, 왼손은 낮게 촉매를 지지하고 오른손은 앞의 열린 공간을 향한다. 항상 양팔을 크게 벌린 주문 포즈가 아니다. 손을 유지하는 인상은 지속 시전·이동 불가·유지 비용을 새로 만드는 규칙이 아니다.

## 3. 풀어 내린 중장발

어깨 아래~등 중간 위쪽에서 끝나는 묶지 않은 머리다. 가르마는 중앙에서 조금 벗어나고 이마·두 눈을 드러낸다. 얼굴 옆은 광대·턱·어깨로 이어지는 큰 곡선이다.

오른쪽 귀 주변은 작은 무광 클립으로 뒤로 정리하는 안, 왼쪽은 넓은 옆머리를 남기는 안이다. 후면은 중앙 큰 덩어리와 양옆 완만한 곡선, 끝은 몸을 따라 안으로 약하게 굽는다. 잘게 흩어진 가닥보다 큰 면이 우선이다.

머리 끝은 허리 고정부 위에서 먼저 비교한다. 그 아래에 어두운 코트 면과 다시 밑단 곡선이 나타나야 한다. 머리·허리 장치·코트가 같은 높이에서 붙지 않게 하고 하나의 외곽으로 합치지 않는다.

몸통 뒤로 짧게 따라오는 관성을 사용한다. 항상 머리가 부유하거나 무중력으로 움직이지 않는다. 마도 반응에서 끝의 움직임을 키울 수 있지만 얼굴/손을 덮거나 머리를 공격·속박 수단으로 만들지 않는다.

<a id="costume"></a>
## 4. 곡선형 마도 전술 코트

몸을 비스듬히 감싸는 딥 청록 코트, 짧은 밝은 덧깃, 어두운 이너·팬츠·낮은 작업형 부츠를 사용한다. Reina의 열린 앞판·Rin의 직선 사선과 달리 가슴 아래에서 허리로 완만하게 휘는 겹침이다.

| 부위 | 설계 |
|---|---|
| 앞판 | 곡선 겹침. 큰 중앙 코어 없음 |
| 칼라 | 낮아 턱 아래 공간 유지 |
| 덧깃 | 쇄골·어깨 위의 짧은 밝은 면. 망토·후광형 확대 없음 |
| 소매 | 팔꿈치 여유·손목 정리, 종 모양 넓은 소매 없음 |
| 허리 | 왼쪽 옆구리의 낮은 잠금부 |
| 오른쪽 밑단 | 허벅지 중간의 짧은 길이 |
| 왼쪽 밑단 | 무릎 위까지 완만한 긴 곡선 |
| 뒤판 | 보폭을 허용하는 짧은 겹트임 |
| 하체 | 어두운 팬츠·부츠로 다리/접지 분리 |

덧깃을 몸통 전체로 넓혀 Sera처럼 만들지 않는다. 왼쪽 촉매 고정부와 코트 잠금은 위/아래·바깥쪽으로 분리한다. 오른쪽은 손 회수 공간을 비우고 파우치는 뒤에 제한한다. 옷자락이 촉매를 통과하거나 소매가 손잡이를 덮지 않게 한다.

코트는 형태가 남는 유연한 기능성 직물, 덧깃은 조금 두꺼운 무광 직물, 잠금은 금속, 촉매는 외장/반투명 재료다. 마모는 밑단·소매·고정 부위에 한정한다. 문양으로 빽빽하게 채우거나 모두 헤진 천으로 만들지 않는다.

## 5. 열린 타원형 촉매

### 5.1 우선안

왼손으로 직접 잡는 열린 타원형 휴대 촉매다. 부유형도 비교 이력으로 남기되 손·인물·장비의 관계가 분명한 휴대형을 먼저 사용한다. 부유를 선택해도 드론·독립 공격 개체를 자동 추가하지 않는다. 거대 지팡이·후광·등 원형 장치는 기본안이 아니다.

### 5.2 큰 형태

아래쪽이 조금 두껍고 위쪽이 가는 세로 타원 프레임이다. 한쪽이 열려 있지만 끝은 둥글고 짧아 칼날·낫처럼 보이지 않게 한다. 손바닥보다 크고 전완 길이 부근에서 비교하며 얼굴/상체를 둘러쌀 크기는 피한다.

하단 파지부 위 하우징에 작은 반투명 촉매편을 물리적으로 고정한다. 어디에 붙는지 보여준다. 빈 공간은 중요한 식별 요소다. 전체를 불투명한 방패·태블릿으로 채우거나 넓은 표시창을 추가하지 않는다.

### 5.3 룬·기술·파지

외장에는 작은 잠금·점검 덮개·고정 구조, 안쪽에는 제한된 룬/짧은 선 배열을 둔다. 새 언어·세력 문장·스킬 목록·N 로고는 아니다. 작동 시 정보 화면과 다른 짧은 룬 선·곡선이 공간에 나타나 실제 Arcana를 보여준다.

왼손은 하단 파지, 오른손은 촉매 바깥의 공간을 향한다. 오른손이 계속 프레임 안을 관통하지 않는다. 도구를 수리하거나 버튼을 누르는 손과 구분한다. 대기는 낮게 들기/허리 부착을 비교할 수 있으나 전투 기준 자세는 하나부터 정해 위치가 흔들리지 않게 한다. 접기·분리·공격 수단·효과 원점·자원 기능을 확정하지 않는다.

## 6. 공간 경계가 읽히는 Arcana

기술 문명과 연결하되 마법을 홀로그램·중력 발생기·전자 장치로 모두 다시 설명하지 않는다. [17 §7](17_OPERATOR_COMMON_STYLE.md#origin-language)의 실제 Arcana를 유지한다.

모티프는 떨어진 곡선과 짧은 표식이 같은 영역을 따라 정렬되는 모습이다. Reina의 응축·Sera의 회복 연결광과 달리 어느 공간을 제어하는지가 중심이다.

**촉매 주변 문양**은 인물의 행동을 설명하는 장식이다. **전장 영역**은 실제 스킬 위치·형태·범위·상태를 따른다. **대상 상태**는 실제 적용 결과를 따른다. 타원 시안을 실제 판정으로 고정하거나 영역 안의 모든 적이 자동 속박/감속/모임 성공한 것처럼 표시하지 않는다.

Iris와는 바닥·공간의 경계/방향/표식으로 구분한다. 전면 불투명 판·피격에 깨지는 벽·아군 보호막은 기본 모티프가 아니다. '결계'라는 단어만으로 제어와 피해 방어 기능을 합치지 않는다.

## 8. 정면·후면·좌·우

| 방향 | 확인 |
|---|---|
| 정면 | 두 눈·옆머리 곡선·덧깃·겹침·왼손 촉매·오른손 |
| 후면 | 머리 끝·그 아래 코트·뒤트임·고정부 |
| 왼쪽 | 넓은 옆머리·촉매 두께/파지·긴 밑단 간격 |
| 오른쪽 | 귀 뒤 정리·제스처 공간·짧은 밑단·앞판 겹침 |

해부학적 좌우를 유지한다. 촉매를 얼굴 옆에 들어도 머리와 떨어져 후광처럼 보이지 않아야 한다. 반전으로 주 손·클립·밑단·고정부를 바꾸지 않는다. 외형 네 방향은 전 동작의 의무 방향 수가 아니다.

<a id="sd"></a>
## 9. SD 전투 모델

필수는 **묶지 않은 큰 머리 곡선 / 밝은 짧은 덧깃 / 비대칭 곡선 밑단 / 열린 타원 촉매 / 지지와 제어로 다른 양손**이다. 작은 룬·내부 무늬·봉제를 줄이고 촉매 구멍이 사라져 방패처럼 되지 않게 한다. Idle부터 거대 마법진으로 얼굴·발을 가리지 않는다.

[19 §3](19_SD_COMBAT_MODEL_TRANSLATION.md#prototype-spec)의 비례·480×480·몸체240px·표시96/128/160px는 비교다. 머리·촉매·옷의 옆 폭을 우선 확인하고 몸을 축소하지 않는다. 손 위치·프레임 각도·머리/밑단의 명도/길이를 먼저 조정하며 발광 외곽만으로 해결하지 않는다.

머리 뒤/옆·양팔·촉매·움직이는 하단을 분리 검토한다. 덧깃이 몸통과 함께 움직이면 나누지 않는다. 목/등·촉매 뒤 손/소매·오른팔 뒤 앞판·코트 밑 팬츠·촉매의 앞뒤 숨은 면을 복원한다. 각 다리에 부츠를 포함한다.

## 10. 동작·전장 상태

Idle은 촉매를 낮게 지지하고 오른손은 몸 가까이 둔다. 상시 주문·제어광은 없다. Move는 발·중심 이동 뒤 머리·코트가 따라오며 부유·순간이동을 기본화하지 않는다. Basic Attack은 실제 수단 확인 뒤 만들고 마법탄/근접/공격 불가를 임의 선택하지 않는다.

Active/Ultimate는 양손이 같은 공간을 설명한다. 준비·유지·회수는 시각 구간일 뿐 실제 지속 시전·제약은 원스킬에 있을 때만 연결한다. Hit/Down/Recover에서는 정상 제어와 전투불능을 구분하며 Nyx Down 때 기존 영역을 자동 삭제/무조건 유지한다고 결정하지 않는다.

| 표시 대조 상황 | 기준 |
|---|---|
| 준비 | 촉매·손 반응, 아직 유효하지 않은 영역을 활성처럼 표시하지 않음 |
| 영역 활성 | 실제 위치·형태·범위의 경계 |
| 대상 적용 | 실제 대상 상태와 일치 |
| 영역은 있으나 대상 미적용 | 영역과 개별 성공을 분리 |
| 종료/해제 | 잔광이 지속 효과로 보이지 않게 정리 |

새 enum/계약을 만드는 표가 아니다. 감속·속박·모임의 존재와 차이는 실제 스킬에서 확인한다. 겹침에서는 내부 문양·입자를 줄이되 실제 경계를 옮기거나 합치지 않는다. 왜곡으로 적/위험 위치가 달라 보이지 않게 한다.

## 11. 궁극기 전체화면

> **촉매의 빈 공간 너머의 눈 → 다른 역할의 양손 → 곡선이 정렬되는 공간 → 실제 전장.**

| 순서 | 장면 |
|---|---|
| 1 | 열린 촉매 옆 얼굴·눈·애시 모브 머리 |
| 2 | 왼손 지지·오른손 제스처 |
| 3 | 인물 근처 제한된 룬·곡선 정렬 |
| 4 | 얼굴·덧깃·양손·촉매의 3/4 반신 |
| 5 | 오른손 방향과 흐름에서 실제 효과 연결 |

약 **3초**는 편집 비교값이지 시전/영역 유지시간이 아니다. 촉매의 빈 공간·팔 사이 공간이 중심이다. Iris처럼 큰 전경 면으로 화면을 나누지 않는다.

촉매는 얼굴 아래·왼쪽, 오른손은 가슴 앞에서 조금 바깥으로 둔다. 팔이 화면폭을 채우거나 프레임이 눈·입을 덮지 않게 한다. 머리·코트는 완만한 반대 흐름을 쓸 수 있으나 공중 부양·장비 공전으로 확장하지 않는다.

금속 구조와 제한된 마도 반응의 추상 공간을 사용한다. 별세계·거대 성역·우주로 옮기지 않는다. 얼굴은 중성, 머리/코트는 차가운 약한 반사, 촉매는 작은 따뜻한 빛이다. 손가락·프레임 구조가 빛 속에 남아야 한다.

컷신 곡선은 연출 공간이며 맵 경계·영역 개수·적이 반드시 모이거나 멈추는 결과가 아니다. 마지막 연결은 실제 궁극기와 대조한다.

## 12. 부분 요약

약 **0.9초** 비교안. 얼굴·덧깃·촉매 반신 → 작은 오른손 이동·곡선 정렬 → 전장. 열린 프레임·왼손 파지·얼굴을 우선하며 머리·코트 전체를 넣으려고 줄이지 않는다. 전체화면 원본을 쓰되 크롭/타이밍은 별도다.

촉매 문양이 실제 영역 경계처럼 보이지 않고 실제 제어·경고·지원3개를 가리지 않게 한다. 모드·시간·DAILY 세부는 [04](04_COMBAT_RUN.md#skill-cinematic-policy)·[18](18_BACKGROUND_CUTSCENE_STYLE.md#cinematic-scope)를 따른다.

### 4. 독립 FX와 수명
- 인물/물리 촉매: 발광 OFF에서도 형태와 파지 확인. 촉매의 고정 재질은 인물에 포함 가능하나 발광은 분리.
- 준비광: 촉매 입구의 낮은 응축, 액티브는 작은 곡선, 궁극기는 조금 넓은 분절 곡선. 실패/취소 시 소거, 생성 성공광과 구별.
- 실제 영역 경계: 권위 있는 범위를 투영한 외곽 분절선. 새 원형 장판을 그림으로 고정하지 않는다. 객차/적/기존 경고와 깊이·가림 검수. 내부를 불투명 면으로 덮지 않음.
- 지속 피해: 실제 tick 수혜자 위치의 짧은 수축선/접촉광. 대상이 없거나 피해가 없을 때 성공 타격광을 찍지 않는다. 장판 유지와 피해 표시는 독립.
- 공격 간격 지연: 실제 적용 상태일 때만 짧은 간격의 분절 고리 후보. 빙결/발목 족쇄/느려진 이동 애니메이션 금지. 면역 대상에는 표시하지 않음.
- 강화tick: 실제 패시브 적용 결과에만 얇은 추가 테두리. 일반 피해를 두 번 재생하지 않는다.
- 만료/교체: 경계가 짧게 사라지는 장식 잔광은 충돌·대상 적용 표시와 분리. 원활성 종료 즉시 효과성 경계/지연표시 제거. 다운/노드 종료도 동일.
모든 효과는 각각 숨김·교체 가능해야 하며 인물 시트에 장판/피해/문구를 굽지 않는다. 절차적 곡선/기존 공통 FX 사용 가능, 상태마다 신규12장 생성을 강제하지 않는다. 따뜻한 장밋빛 선/크림빛 중심은 기존 색 비교안에서 출발하되 붉은 위험 경고와 혼동하면 밝기·패턴부터 조정한다.
