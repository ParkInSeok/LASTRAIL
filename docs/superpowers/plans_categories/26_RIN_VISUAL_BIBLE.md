## 1. 핵심 이미지·역할

> **상대의 움직임을 읽고, 몸과 무기를 짧은 사선으로 정리해 필요한 순간에 개입하는 근접 돌입 요원.**

기존 역할 **Martial Assault / Interrupt / Breaker**, **Science + Martial 방향**을 [17 §2](17_OPERATOR_COMMON_STYLE.md#roster)에서 보존한다. Martial 중심·Science 보조는 이전 인계의 시각 방향으로 이어받는다. 이전 대화의 Military + Mercenary 시너지 언급은 출처/실제 태그·ID 재확인 대상이다. 이번 외형 채택으로 현행 시너지 데이터에 승격하지 않는다.

큰 무기를 빠르게 휘두르기보다 행동 전 준비와 행동 뒤 회수의 정확함이 중심이다. 평소 눈·입가에는 반응이 있고 집중에서는 표정이 일그러지기보다 시선·어깨·전완이 정리된다. 항상 화내거나 충동적으로 달리는 인물로 고정하지 않는다.

기준 조합은 **먹청록 짧은 하이 테일 + 회녹색 눈 + 미네랄 오렌지 사선 전술 상의 + 얇은 전완/정강이 보강**, 여기에 단창형 병기를 먼저 비교한다. 긴 코트·망토 없이 중심과 다리를 드러낸다.

## 2. 얼굴·표정·체형

### 2.1 얼굴

성인 여성 인상, 광대 위의 면이 조금 읽히고 턱으로 자연스럽게 좁아지는 짧은 타원형이다. Eve보다 볼을 정리하되 턱 끝은 과하게 뾰족하지 않다. 정확한 나이·키·출신·유파·경력은 추가하지 않는다.

눈은 가로 방향이 분명한 아몬드형이지만 Reina보다 바깥 끝이 짧고 눈동자 움직임이 읽힌다. 항상 가늘게 감거나 한쪽 눈을 찡그리지 않는다. 눈썹은 짧고 적당한 두께, 안쪽은 곧고 끝은 약하게 꺾인다. 집중에서 안쪽 높이가 내려가고 긍정에서 풀린다.

홍채는 회색이 섞인 청록/녹색 비교안이다. 어두운 머리보다 밝게 읽히되 자체 발광은 없다. 입은 작지만 입가 변화가 보이며 긍정에서 한쪽 끝이 조금 먼저 올라가는 정도다. 송곳니·이를 드러내는 웃음을 필수화하지 않는다.

중립은 또렷한 눈과 힘이 적은 입, 집중은 낮아진 턱과 고정 시선, 긍정은 풀리는 눈썹·입가, 피로는 입·볼 주변 긴장으로 표현한다. 네 표정에서 비례를 유지한다.

**Reina와의 비교:** 짧은 얼굴·광대 작은 면·짧은 눈썹과 앞머리를 보존한다. 어두운 높은 묶음 머리라는 공통점만 남기지 않는다. 작은 초상화에서 꼬리가 잘려도 얼굴과 앞머리의 짧은 흐름이 구분되어야 한다.

### 2.2 체형·기준 자세

좁지만 약하지 않은 탄탄한 체형이다. 전완·허리·허벅지의 연결과 열린 관절로 가벼움을 표현하고 가는 팔다리·작은 체격으로 대신하지 않는다. 원화 약 6.75~7등신은 비교값이다.

한 발을 조금 앞에, 몸통은 목표에 비스듬히 둔다. 발을 과하게 벌리거나 허리만 꺾어 상체를 내밀지 않는다. 골반·무릎·발이 같은 중심을 받친다. 전방 기울기는 실제 이동속도·돌진 거리·공격 중 이동의 승인이 아니다.

## 3. 짧게 꺾이는 하이 테일

먹색에 가까운 청록 머리를 뒤통수 위에서 짧게 묶는다. 앞머리는 큰 사선 면, 양눈은 드러내며 귀 주변을 정리한다. 광대 부근의 짧은 옆머리만 남긴다.

꼬리는 길게 흐르지 않고 짧은 쐐기처럼 한 번 꺾여 끝난다. 기준에서 목선 아래로 길게 내려오지 않는다. Reina의 긴 곡선과 달리 짧고 각진 외곽이다. 길이만 조금 줄인 동일 포니테일로 만들지 않는다.

고정부는 작고 무광인 띠/구조다. 큰 리본·금속 장식·이름 문양을 붙이지 않는다. 후면에서 머리가 모이는 방향과 꼬리 시작이 이어지며 칼라와 목 뒤 공간을 남긴다.

동작에서는 머리 본체 뒤로 꼬리가 짧게 따라온다. 긴 천 같은 반복 흔들림, 프레임마다 길이·가닥 수가 달라지는 변화를 피한다. SD는 잔가닥보다 묶인 위치·꺾인 외곽이 우선이다.

## 4. 사선 전술 상의·하체

허리선에서 끝나는 사선 여밈 상의, 짙은 이너·팬츠, 얇은 보강·낮은 부츠를 조합한다. 전통 도복·의례복을 복사하지 않고 겹침 구조를 산업용 잠금·기능성 직물로 정리한다.

앞판은 인물 오른쪽 쇄골에서 왼쪽 허리로 이어지는 큰 사선이다. 여러 버클·끈보다 한 방향이 몸통을 설명한다. 칼라는 낮고 가슴 중앙에 큰 문양·발광부가 없다. 겉소매는 상완에서 정리하고 짙은 기능성 이너 소매가 팔에 붙는다. 팔꿈치와 전완 보강 사이의 가동부를 드러낸다.

허리선은 팬츠와 자연스럽게 이어지고 복부 노출은 필수 아니다. Nyx의 곡선 겹침·긴 밑단으로 바꾸지 않는다. 상체 방호를 덜어 Kyle 몸체를 축소 재사용하는 방식도 피한다.

팬츠는 허벅지 여유·발목 정리, 작은 무릎 보강이다. 허리 파우치는 옆/뒤에 작게 두고 무기를 회수할 전면을 비운다. 대형 등 팩·긴 허리띠·두 갈래 천·무릎 아래 장식을 기본에서 제외한다. 사선은 천보다 몸과 무기에서 만든다.

겉상의는 두께가 있는 무광 직물, 이너는 유연한 소재, 보강은 외장/완충부다. 마모는 장갑·팔꿈치·파지·무릎·부츠에 둔다. 붕대와 찢어진 천으로 무술가를 대신 설명하지 않는다.

## 5. 사지 보강

착용형 외부 보강 프레임을 우선한다. 미확인 영구 의수·의족으로 신체 설정을 바꾸지 않는다.

전완 바깥에 얇은 외장과 장갑 연결을 두고 손목 안쪽·팔꿈치는 연다. 왼쪽 면을 조금 넓게 비교할 수 있지만 전면 방패로 부풀리지 않는다. 정강이는 바깥의 길고 좁은 면·작은 고정부로, 무릎/발목을 금속 한 덩어리로 잠그지 않는다.

발광은 작은 연결부에 한정하고 꺼져도 구조가 남게 한다. 기술은 Martial 몸을 보조하며 추진기·공중 대시·전완 포격·반사 방패를 새 기능으로 추가하지 않는다.

| 단봉 | 간결한 외곽·회수 | 공구/일반 배턴과 구분 약화 | 비교 후보 유지 |

단창의 우선 이유는 한 개 무기로 Kyle와 다른 사선을 만들기 쉽다는 점이다. 후보 수만큼 전환 기능·스킨을 생성하지 않는다.

### 6.1 단창 외형

세워 두었을 때 끝이 어깨 높이 부근까지 오는 길이를 먼저 비교한다. 실제 사거리 값이 아니다. 짧고 단단한 쐐기형 헤드·정돈된 자루·어두운 파지구간을 사용한다. 거대한 월도·도끼날로 늘이지 않는다.

헤드와 자루 사이에는 작은 산업적 연결부를 둔다. 외장·완충은 같은 기술 문명의 물건으로 읽히게 하되 내부 제작·작동 설계를 새로 정의하지 않는다. 큰 술·깃발·용 문양·이름 장식판이 없다. 효과를 꺼도 물리적 무기 유형이 남아야 한다.

### 6.2 파지·휴대

준비 자세는 오른손이 뒤쪽 몸 가까운 파지, 왼손이 앞쪽 지지인 안이다. 끝은 낮은 전방 사선으로 얼굴을 가리지 않는다. 각 손의 위치를 보조도에 표시하며 방향 변경으로 손을 바꾸거나 자루를 관통하지 않는다.

휴대 고정이 필요하면 몸 옆에 가까운 위치부터 비교한다. 등 뒤 긴 대각선으로 다른 요원 얼굴을 가리는 배치를 우선하지 않는다. 던지기·분리·연장·총기 변형·무기 전환은 포함하지 않는다.

### 6.3 실제 역할 연결

Interrupt를 모든 기본 공격 기절로, Breaker를 방어력 감소·보스 부위 확정 파괴로 해석하지 않는다. 대상·조건·이동·횟수·상태는 실제 계약이 소유한다. 단창이 맞지 않으면 무기·파지·준비/회수·SD·컷신을 함께 수정하고 스킬을 무기에 맞춰 바꾸지 않는다.

## 7. Martial 중심·Science 보조

개인 동작은 **좁게 모임 → 한 방향으로 정리 → 회수**다. 준비에서는 손과 무기가 몸 가까이, 행동에서는 얼굴·전완·끝이 같은 방향, 회수에서는 중심도 함께 정리된다. 세 구간은 3연타·3단계 스킬이 아니다.

[17 §7](17_OPERATOR_COMMON_STYLE.md#origin-language)의 자세·중심·사지 힘을 전면에 두고 장비가 보조한다. 실제 스킬에 없는 거대 기탄·충격파·분신·시간정지를 기본 효과로 넣지 않는다. 반대로 모든 힘을 모터로만 설명해 Martial을 없애지도 않는다.

## 10. SD 전투 모델

필수는 **짧은 하이 테일·오렌지 사선 앞판·좁은 몸/열린 관절·사지 보강·몸과 이어지는 무기 사선**이다. 무기 항목은 후보 의존성을 유지한다. 작은 잠금·나사·결합·가닥을 줄이고 팔/몸 빈 공간·파지·끝 방향을 보존한다. 단창이 안 보인다고 거대 도끼날로 바꾸지 않는다.

[19 §3](19_SD_COMBAT_MODEL_TRANSLATION.md#prototype-spec)의 3.25등신·480×480·240px·96/128/160px는 비교다. 긴 무기는 별도 외곽으로 측정하고 얼굴/몸만 축소하지 않는다. 같은 표시 높이의 Kyle와 폭·방호·팔 공간·자세로 구분한다.

파츠는 무기·양팔·짧은 묶음·필요 보강이다. 전완 외장이 팔과 함께 움직이면 나누지 않아도 된다. 회전 중 손과 자루, 앞뒤 팔의 렌더 순서를 유지한다. 무기 뒤 앞판·전완 뒤 소매·파우치 뒤 팬츠·가려진 손/자루를 복원한다. 각 다리 부츠를 포함한다.

<a id="motion"></a>
## 11. 동작·전장 FX

| 동작 | 표현 | 경계 |
|---|---|---|
| Idle | 몸 가까운 손/무기, 준비 | 상시 튀기·위치 이동 없음 |
| Move | 중심·방향을 유지하는 체중 이동 | 실제 이동 이중 적용 없음 |
| Basic Attack | 준비·실제 타격·회수 | 구간을 여러 피해로 해석하지 않음 |
| Active | 원행동에 맞는 사선·개입 | 돌진/밀어내기/기절은 스킬 확인 |
| Hit | 무기 회수·짧은 중심 정리 | 자동 반격 없음 |
| Down | 몸/무기가 낮아짐 | 장비 드랍 생성 없음 |
| Recover | 허용 상태의 중심/파지 | 부활 권한 생성 없음 |
| Ultimate | 얼굴·사지·무기 사선 | 원대상·횟수·행동에 연결 |

속도감은 무조건 빠른 재생보다 명확한 준비·짧은 행동·회수로 만든다. 회수가 실제 다음 공격을 늦추지 않는다. 무기 궤적은 실제 방향에 가까운 짧은 선이며 화면 전체 광역처럼 만들지 않는다. 잔상을 별도 인물/타격으로 보이게 하지 않는다.

Interrupt 성공은 실제 결과가 있을 때만 표시한다. 면역·미적용인데 연출만으로 적을 중단시킨 것처럼 보이지 않게 한다.

<a id="full-cinematic"></a>
## 12. 궁극기 전체화면

> **딛는 발 → 전완과 단창 → 얼굴과 무기가 정리되는 사선 → 실제 전장.**

| 순서 | 중심 |
|---|---|
| 1 | 발·무릎·허리, 열린 관절과 좁은 중심 |
| 2 | 전완 보강·양손 파지·무기 진입 |
| 3 | 짧은 테일·집중한 눈·오렌지 앞판 |
| 4 | 몸·손·무기가 같은 방향인 대표 포즈 |
| 5 | 실제 SD/원효과로 연결 |

약 **2.5~3초**는 비교값이며 공격/이동 속도나 시전시간이 아니다. 몸의 준비가 무기의 방향을 만든다. 전경 큰 무기를 먼저 놓고 몸을 뒤에 붙이는 구도보다 발·중심에서 올라간다.

화면 아래에서 무기가 대각선으로 올라오고 얼굴은 열린 위 공간에 둔다. 약한 3/4에서 양손이 설명되어야 한다. 얼굴을 보이려고 손목을 꺾거나 끝 방향을 바꾸지 않는다. 머리·밑단의 지연은 작게 둔다.

연출의 중심 이동은 실제 전장 이동과 다르다. 긴 돌진·적 뒤 순간이동·반사·관통·확정 기절·부위 파괴를 고정하지 않는다. 접촉/타격은 실제 궁극기 확인 뒤 넣는다. 금속 프레임의 추상 배경, 중성 얼굴광·짧은 차가운 보강 반사를 사용하고 오렌지로 전장을 물들이지 않는다.

<a id="summary-cinematic"></a>
## 13. 부분 요약

약 **0.8~1.0초** 비교안. 얼굴·앞 전완·단창 일부의 반신에서 손/무기가 짧은 사선으로 정리된 뒤 전장으로 이어진다. 눈·짧은 테일·상의·보강·무기 방향이 우선이다. 발/하체는 SD에서 읽히게 하고 작은 컷인에 전신을 넣지 않는다.

전체화면을 고속 재생하지 않고 원화 공유·별도 크롭을 사용한다. 단창 사선이 적 예고와 혼동되거나 접촉점·지원3개를 가리지 않는지 확인한다. 모드/정지/입력/DAILY는 [04](04_COMBAT_RUN.md#skill-cinematic-policy)·[18](18_BACKGROUND_CUTSCENE_STYLE.md#cinematic-scope)에 둔다.

<a id="delivery"></a>
## 14. 대표 장면·산출물

중립 전신은 낮은 사선 무기·얼굴·양손·여밈·보강·발을 효과 없이 보여준다. 소개 원화는 열차 통로나 플랫폼에서 준비하는 장면이며 새 외부 보행/돌진 조작을 추가하지 않는다. 이야기 CG는 객차에서 보강 고정이나 장갑을 확인하는 장면으로 유파·수련장·사제 관계·과거를 확정하지 않는다.

산출물은 전신/복식 보조도·네 방향·4표정·헤어 고정부·사지 관절/결속·무기 후보/파지·SD/Kyle 비교·전체화면/요약 구도다. 무기가 바뀌면 준비·파지·회수·SD·크롭을 함께 수정하고 유지 가능한 얼굴/복식은 보존한다.

실제 operatorId·skillId·경로·앵커·revision은 프로젝트에서 확인한다. 파일명 RIN은 작업명이며 최종 이름 변경이 서버 ID 변경을 뜻하지 않는다.
