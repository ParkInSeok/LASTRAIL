## 4. 고정된 아트·컷신 경계

세계는 Cyberpunk + Industrial + Post-Collapse + Armored Train이며 Science·Arcana·Martial이 공존한다. 픽셀 아트가 아닌 고품질 애니풍2D 원화와 작은 화면용 SD를 사용한다. 두 번째 릴스의 얼굴·머리·재질·조명 품질, 첫 번째 릴스의 공간 스케일이 이전에 채택되었다. 원작 캐릭터·복식·문양·정확한 포즈를 복제하지 않으며 영상 제작기법을 추정해 확정하지 않는다.

파트는 독립 움직임과 렌더 순서로 나누고 가려진 형태를 복원한다. BackLeg/FrontLeg에는 각각의 부츠를 포함한다. 공통 전문은19에 둔다.

컷신은04 §14의 최신3모드를 유지한다. ALWAYS/ON과 DAILY의 표준 대상은 전체화면, OFF와 DAILY 반복은 요약이다. OFF는 삭제가 아니다. 실제 전체화면 동안 전투 유효 배속0, 부분 요약은 전투 진행이며 별도 허용된 초토화 요약이 전체화면이면 동일 정지를 적용한다. 스킵·종료는 원스킬의 피해·비용·보상을 새로 처리하지 않으며 자신이 소유한 정지만 해제한다. 포탑 궁극기는 없고 오른쪽 지원 버튼3개를 유지한다.

DAILY의 스킬별 집계·서버 게임일자·기본값DAILY·시작/스킵 기록은 이후 명시 승인 없으면04의 권장안으로 남긴다. 이 단락은 회귀를 막는 참조 안내이며 시간·입력·복원 전문은04를 따른다.

## 5. 남은 작업의 순서

먼저 실제 프로젝트의 승인 무기·공격·스킬·자산 ID를 확보해 미확정 연결을 대조한다. 자료가 없다는 상태와 실제로 정의가 없다는 상태를 구분한다. 이미 결정된 외형 방향을 다시 처음부터 묻지 않는다.

별도 제작 요청을 받으면 중립 전신 시안에서 얼굴/헤어/복식/장비를 비교하고 승인 후 SD를 설계한다. 현재 문서화 자체는 이미지 생성·모션·Unity 구현 시작 지시가 아니다. 실제 검수 순서는17·19를 따른다.

주요 비교쌍은 Kyle↔Rin, Eve↔Cipher, Sera↔Iris, Nyx↔Iris, 사격3인이다. 얼굴은 Eve↔Iris, Sera↔Nyx, Kyle↔Mira, Vex↔Cipher를 먼저 보고 전체10인 비교도 수행한다. 문서 비교와 실제 그림의 합격을 혼동하지 않는다.
