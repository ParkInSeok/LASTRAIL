# LAST RAIL | 오퍼레이터 원화·아트 스타일 가이드

> **최신 승인 2026-10-05:** 전투 요원은 SD 기본 정책을 대체하여 일반 비율·단순화한 실루엣·큰 전투 동작으로 제작한다. 과거 SD 비례/제작 기록은 역사 보존. [현행 리소스·모션 정책](19_SD_COMBAT_MODEL_TRANSLATION.md#normal-proportion-large-motion-approved-20261005)이 충돌하는 과거 지침보다 우선한다.

기준일: **2026-09-21**. 근거: 이 채팅에서 사용자가 첨부한 두 릴스 녹화, 특히 두 번째 영상의 캐릭터 품질을 선호한다고 밝힌 뒤 스타일 가이드 작성을 “좋아 ㄱㄱ”로 승인한 내용. 이 문서는 그 승인 방향과 직전 가이드의 적용 범위를 정리한 것이다. 신규 캐릭터 그림·전투 스프라이트·애니메이션·홈페이지 시안의 제작 완료를 뜻하지 않는다.

이 파일은 **아트의 상위 방향과 레퍼런스 채택 범위**를 소유한다. 세부 제작은 아래 분야 문서 한 곳씩에서 관리하며, 같은 전문을 서로 복사하지 않는다. 전투 조작·상태는 [04 전투](04_COMBAT_RUN.md), 홈페이지 기능과 운영은 [11 홈페이지](11_WEBSITE_COMMUNITY.md), 실제 콘텐츠 배포는 [02 콘텐츠](02_CONTENT_UPDATE.md)와 [08 배포](08_BALANCE_RELEASE.md)를 따른다.

## 1. 최종 방향

> **고급 애니메이션풍 2D 캐릭터 일러스트를 원화 품질 목표로 삼고, 세계관은 Cyberpunk + Industrial + Post-Collapse + Armored Train으로 유지한다. 전투 모델은 원화의 정체성을 유지한 2D Stylized SD Military/Tactical로 단순화한다.**

두 번째 릴스는 얼굴·머리카락·의상 재질·명암·인물 중심 구도의 품질 참고다. 첫 번째 릴스는 거대한 구조물·깊이감·공간 스케일의 보조 참고다. 참고 영상의 고전 판타지 세계를 LAST RAIL의 주된 세계관으로 바꾸거나, 원본의 특정 캐릭터·의상·문양·장면을 그대로 복제하는 지시가 아니다.

**품질 목표와 실제 제작 기법은 구분한다.** 업로드 영상의 제작 도구, 실제 2D/3D 파이프라인, AI 사용 여부는 확인되지 않았다. 여기서 “2D”는 LAST RAIL이 제작할 결과물의 방향이며, 원본 영상이 특정 방법으로 제작됐다고 단정한 설명이 아니다. 압축된 화면녹화만으로 원본 해상도·프레임별 완성도·게임 엔진 성능을 보증하지 않는다.

## 4. 세계관 변환과 비채택 범위

| 레퍼런스에서 보이는 표현 언어 | LAST RAIL에서의 변환 방향 |
|---|---|
| 판타지 복식·장식 | 전술복·산업복·장갑열차 승무복·현장 생존 장비 |
| 신성한 장신구가 중심인 실루엣 | 기능성 모듈·통신기·센서·탄창·유틸리티 파츠 |
| 성역·유적·자연 낙원을 중심으로 한 세계 | 철도 시설·붕괴 인프라·장갑열차·폐허 도시·황무지·정비 구역 |
| 청금빛·순백·황금빛의 신성한 무드 | 흑철·건메탈·샌드·딥레드와 제한된 전자광 포인트 |
| 서정적이고 고요한 장면 | 작전 대기·이동 중 휴식·전투 후 정비·긴장 속 동료 관계 |

성역·엘프·성녀풍이 작품 전체의 첫인상이 되는 방향은 채택하지 않는다. 세계 전체를 지나치게 깨끗하고 평온한 자연 낙원으로 바꾸지 않는다.

**범위 해석:** 위 비채택은 레퍼런스의 세계관 전체를 이전하지 않는다는 뜻이다. 기존 LAST RAIL의 Science·Arcana·Martial 설정을 없애거나, 조용한 휴식 장면·나무·물·푸른 조명·밝은 색을 일괄 금지하는 신규 정책이 아니다. 작품의 중심인 사이버펑크·산업·붕괴 이후·장갑열차를 유지하면서 각 장면의 필요에 맞게 사용한다.

이 표는 사용할 수 있는 표현 영역을 정한 것이다. 모든 요원의 새 일러스트 수량, 컷씬 개수·길이, 친밀도 기능, 캐릭터 획득 방식, 실제 홈페이지 공개 일정을 새로 확정하지 않는다. 컷신 범위는 원화 가이드 자체가 아니라 후속 사용자 승인 [04 §14](04_COMBAT_RUN.md#skill-cinematic-policy)에 따른다. 스킬 컷신은 DAILY/ALWAYS/OFF 세 모드다. 실제 전체화면 재생 시 전투배속0을 적용한다. OFF·DAILY 반복은 기존 요약 연출이며, 요원 부분 컷인·일반 지휘관 명령은 전투를 계속 진행하고 별도 허용된 초토화 요약이 전체화면일 때만 정지한다. 자동 액티브·패시브·포탑 궁극기까지 확대하지 않는다.

## 6. 원화 → SD 전투 모델 변환

**원화는 품질 기준, 전투 모델은 판독 기준**으로 구분한다. 전투 캐릭터를 낮은 품질로 만드는 것이 아니라, 같은 캐릭터를 작은 화면과 반복 애니메이션에 맞는 정보량으로 다시 설계한다. 아래는 상위 압축 원칙이며 구체적인 파츠·출력·표시·모션 전문은 [19 SD 변환](19_SD_COMBAT_MODEL_TRANSLATION.md)에 둔다.

| 원화 요소 | SD에서 유지할 정보 | 줄이거나 분리할 정보 |
|---|---|---|
| 얼굴 | 눈색·눈매의 인상·핵심 표정 | 작은 화면에서 구분되지 않는 피부 그라데이션·세밀한 코와 입 |
| 머리카락 | 포니테일·앞머리 등 큰 형태, 대표 색 | 잔결·과도한 가닥·복잡한 윤기 |
| 의상 | 상하체 색분리, 코트 길이, 대표 포인트 파츠 | 미세 주름·봉제선·읽히지 않는 장식 |
| 장비 | 무기 유형, 대표 장갑·백팩·어깨 파츠 | 작은 부품·문구·장식 밀도 |
| 광원 | 역할과 상태가 보이는 안정적인 명암 | 일러스트 장면에 고정된 강한 역광·색반사 |
| 캐릭터 정체성 | 대표 실루엣·색배치·장비의 일관성 | 다른 캐릭터와 구별에 기여하지 않는 세부 요소 |

실제 전투 상태의 HP·Ready·Down·쿨타임·위험 예고를 원화에 고정해서 그리지 않는다. 상태 UI와 이펙트는 게임 로직에 연결된 독립 요소로 유지한다. 참고영상처럼 보이게 하려고 합성 이미지를 실제 버튼과 전투 상태 위에 덮지 않는다. 기능 책임은 [04](04_COMBAT_RUN.md)를 따른다.

## 9. Codex·디자인 세션 전달 규칙

작업 전 [00_INDEX.md](00_INDEX.md)와 이 문서, 담당하는17~19번 공통 가이드를 읽는다. 오퍼레이터의 기존 바이블과 실제 자산을 확인한 뒤 얼굴·머리·재질·조명·구도의 표현 품질을 맞춘다. 원화와 SD 변환은 별도 산출물·별도 검수로 처리한다.

## 10. 남은 제작 결정

원화별 실제 해상도·캔버스 비율·레이어 납품 방식, 확정 시안, 애니메이션 제작 방식과 사용 도구는17~19번에 제작 후보와 검수 기준으로 구체화했다. 예를 들어 SD3.25등신·480px 캔버스는 시제품 비교안이지 이미 승인된 규격이 아니다. 기존 제작 규격을 먼저 대조하고 실제 화면 검수 뒤 필요한 값만 고정한다. 개별 외형은 각 오퍼레이터 비주얼 바이블에서 확정한다.

마지막으로, 이 문서의 승인과 **J04 노드·웨이브 숫자**, 미작성 상위 특성 매개변수, 공개 데모 진행 승계 등은 별개다. 미확정 게임 규칙은 [00의 판단 대기](00_INDEX.md#open-decisions)를 유지한다.
