OFF stops future choices and retains accepted casts. Preserve charge across down/recovery, default AUTO false for new runs; restore mode/individual charges/automatic ID sequence in a new checkpoint schema. Use deterministic automatic command IDs and manual precedence for inputs received before the tick. Pause toggles may persist mode but cannot advance combat.
