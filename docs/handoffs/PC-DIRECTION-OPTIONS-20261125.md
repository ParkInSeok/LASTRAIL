# Steam PC 방향 논의 — 2026-11-25
미확정 기획 제안. 유료 PC 전환 시 요원 뽑기를 삭제하는 방향을 논의했다. 현행 게임 정책을 변경하거나 아래 후보를 채택한 기록은 아니다.

- 움직이는 요새: 객차와 전력 배분으로 이번 운행의 전투 방식을 구성.
- 철도망 추격전: 추격열차, 분기기, 정차 비용으로 노선 선택의 결과를 표현.
- 폐열차 강탈: 접현·객차 견인·철수 시점으로 위험과 보상을 결정.
- 피난열차: 승객과 화물, 구조 선택이 다음 역의 상황을 바꿈.
- 기관사의 10초: 제동·포격·차폐를 예약하고 결과를 관찰.

비교 제안: 세 역·분기 하나·추격열차·견인 가능한 객차 한 칸으로 추격과 강탈의 조합을 평가. 아직 구현하지 않았다.

레이나 타입 3 우측 대기 픽셀 비교는 12프레임, 장당 100ms, 고정 40색 변환이다. 중간 채색 문제 해결이나 전면 픽셀화 승인으로 취급하지 않는다. 78번 장비 교체 결과 역시 검토 후보다.
