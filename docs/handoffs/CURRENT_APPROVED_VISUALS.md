## 역사자료와 검색 분리

루트 .rgignore는 폐기 열차 35개 폴더 및 확인된 대응 세로 시안의 정확한 파일 경로를 기본 rg 검색에서 제외한다. 파일 이동·삭제·런타임 참조 변경은 하지 않았다. 명시 경로 열기 또는 rg --no-ignore로 역사자료 확인은 가능하다. 다른 앱의 검색에는 자동 적용되지 않는다.

초기 landscape-entry-v01은 세로 승인 자료를 참조했고 landscape-management-v01은 구 인물 화풍을 따라간 오류가 기록되어 있다. 최신 열차 제작 원본으로 세로 시안을 다시 선택하지 않는다.

세로 파일 물리 삭제는 보류: 참조 전수검사 미완료이며 Tools/FrameStudio/vendor 일부 접근 오류가 있었다. 이미 삭제된 세로 로비·로그인은 복원하지 않는다. 대체본 불명확한 세로 화면은 일괄 제외하지 않는다.

보존 파일은 현행 승인본이 아니다. 폐기 표시와 기존 참조 보존을 구분한다.
