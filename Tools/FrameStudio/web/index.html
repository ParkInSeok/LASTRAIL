03 / 프레임 검토

전체 제작

정식 생성: 빈 주요 포즈 → 사람 승인 → 빈 중간 프레임 → 검토 GIF. 시험 생성: 모든 빈 칸 생성 후 검토 GIF, 정식 승인 불가. 실패·취소 후 이어하기는 완료한 칸을 보존합니다.

로컬은 이 PC의 GPU, Codex는 구독 연결을 사용합니다. 자동 엔진 전환 없음. 로컬 원화 시험은 512px 불투명 시험본이며 정식 승인·출력이 차단됩니다.



플리커 · 동작 연결 보정
흰 영역은 움직임 보간, 검정 영역은 기준 프레임으로 고정합니다. 원본 시간표·승인은 유지하고 별도 검토 영상을 만듭니다. 영상 보간이며 새 작화가 아닙니다. 대응점을 지정하면 해당 위치를 기준으로 연결합니다. 손가락·가림 경계 왜곡을 검토하세요.
고급 관절 좌표·시간표
관절 회전은 같은 원화의 비율을 유지합니다. 접합부만 겹쳐 덮고 엄지 영역을 짧게 전환합니다. 가림면을 새로 그리지는 않습니다.
원본을 보존하는 국소 수정
현재 결과의 흰색 영역만 다시 그립니다. 검정 영역은 유지합니다. 기본 모드에서는 기존 투명도와 부드러운 외곽도 보존합니다. 프레임과 같은 크기의 불투명 흑백 PNG를 사용하며, 수정 영역은 가로·세로 512픽셀 이내로 나눠 주세요. 전체 수정은 같은 위치의 마스크를 모든 프레임에 적용합니다.
프레임별 생성 강도·지시를 변경하는 동작 시험입니다. 자연스러움은 검토가 필요합니다.
로컬 엔진 전용 검토본입니다. 새 버전으로 저장하며 자동 승인하지 않습니다. 윤곽 변경 시험에서는 검은 배경에서 투명도를 추정하므로 최종 납품용 alpha로 간주하지 않습니다. 테두리 정리는 검은 배경에 접한 붉은 색번짐을 보정합니다. 정상적인 붉은 장식은 마스크에서 제외하세요. 선명도 보정은 기존 선의 대비만 조정하며 사라진 디테일을 복원하지 않습니다. 반복 적용은 피하세요.
