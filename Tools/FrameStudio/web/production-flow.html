승인 원화·기준 채색과 비교

동일 캔버스의 실제 투명 PNG를 사용하세요. 생성 도구에서 받은 단계별 그림을 등록합니다. 자동으로 선화를 추출하거나 명암을 생성하는 버튼은 아닙니다.

내보내기는 검토용 반복 재생입니다. 최종 승인·idle 연결 검수를 대신하지 않습니다.



형태·내부선 보호 지도 (미채색 단계)
같은 크기의 흰색/투명 PNG입니다. 전체 선 영역, 색·농도를 바꿀 내부선, 손·발·겹침 보호 영역을 구분합니다. 외곽과 보호 영역은 변경 범위에 넣을 수 없습니다. 승인 후 지도는 잠깁니다.
부위 마스크로 정확한 팔레트 적용
같은 캔버스의 투명 PNG: 흰 영역을 적용하고 검정/투명은 제외합니다. 기본 부위끼리 겹치면 조합을 차단합니다. 명암은 해당 기본 부위 안에만 적용합니다. 광택 PNG는 별도 광택 위치 마스크와 기본 부위의 교집합 안에서만 최종 합성됩니다. 마스크의 회색값·투명도로 적용 강도를 조절하며 승인 명암층은 바꾸지 않습니다.
색 단계 지도는 회색값 0~255로 저장된 색상표의 처음~마지막 색을 선택합니다. 적용 면 안은 불투명하게 채우고, 프레임마다 색상표를 새로 추출하지 않습니다.
