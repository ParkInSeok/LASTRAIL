2. **세 경로 재현:** 같은 원점에서 원본 PNG → 출력 → 실제 표시를 비교한다. 화면 크롭/셀 추출, alpha 누락/테두리, 형태·가림 단절, 명암·재질 단절, 프레임 간 부착점 이동으로 분류한다. 원본이 정상인 표시 오류에 원화를 덧칠하지 않는다.
3. **양쪽 구조 명시:** 고정 핵심부·가동부·연결 면을 분리한다. 피부와 옷의 경계, 깃의 앞뒤, 머리카락의 가림, 주름의 흐름을 먼저 확인한다. 기존 마스크 선을 수정 범위의 정답으로 삼지 않는다. 연결 면 안에 생긴 직선/다각형 절단과 이중 외곽선도 검사한다.
4. **한 구간 시험:** 문제 프레임과 양옆을 기준으로 한 원인·한 방법만 적용한다. 필요한 연결 면을 국소 작화하거나 실제 자세·가림이 맞는 유효 원본을 동일 좌표로 복원한다. 조각 이동·확대·경계 블러로 구조 작화를 대신하지 않는다. 원본/수정 전/수정 후를 확대와 실제 크기에서 비교하고, 마스크 경로 표시와 표시 없는 그림을 모두 본다. 경로 표시만 보고 합격하지 않는다.
5. **확대 조건:** 지적한 절단이 줄고, 피부/옷/머리의 가림과 주름 연결이 자연스러우며, 양옆에 새 단절이 없고 보호 영역이 유지될 때만 나머지 프레임으로 확대한다. 실패 방식은 중단하되 정상 복구본에서 다른 원인을 확인하여 작업을 계속한다. 효과 미확인 상태로 반복 덧칠하지 않는다.
6. **전수·회귀 검수:** 모든 인접 쌍과 마지막→처음(또는 idle 복귀)을 같은 원점·시간표에서 검사한다. 접합 부위의 12장 배열만으로 전환 검사를 대체하지 않는다. 정상/느린 재생, 밝은/어두운 배경, 실제 크기/확대에서 목·깃·가슴과 기존 소매·손목·외곽선·접지 보호 영역을 함께 확인한다. 수정 전후 보존과 프레임 간 일관성을 별도 기록한다.
7. **증거·한계:** 선택 자산과 출력/화면 사용본의 대응을 확인한다. 정지 관찰, 순차 전환 관찰, 재생 실행 확인, 연속 영상 지각 검수를 구분한다. 자동 수치·픽셀 보존이나 카운터 변화로 연속 검수 통과를 선언하지 않는다. 미검수 또는 재발 부위는 실패/미확인으로 유지한다. 사용자 승인은 별도다.

### 도구 보강 구축안 — 미구현 계획

새 제작 엔진 대신 기존 패치·검토 경로에 다음 순서로 붙인다. 현재 적용은 위 수동 운영 절차이며, 아래 자동 기능은 구현·실행 검증 전까지 미구현이다.

| 단계 | 기존 책임에 추가할 최소 기능 | 수용 근거 |
| --- | --- | --- |
| 1. 연결 검사 기록 | 기존 프로젝트/패치 이력이 원본·donor·mask·선택 자산과 검사 ROI, 양옆 프레임, 보호 영역, 관찰 결과를 소유. View에 별도 승인 상태 복제 금지 | 현재 실패 사례의 원본/마스크/결과를 같은 좌표로 다시 열 수 있음. 기록 없는 기존 자산은 미확인 |
| 2. 비교 화면 | 기존 검토 View에 원본/전후·마스크 경로 켜기/끄기·양옆 이동을 조합. Controller의 기존 프레임 선택과 재생을 재사용 | 경로를 숨긴 실제 그림에서 단절이 보이는지 확인 가능. 재바인딩 입력 중복·종료 후 타이머 없음 |
| 3. 검수 유효성 | 관련 선택 자산·마스크·양옆 자산·시간표가 바뀌면 영향받는 항목만 재검수로 표시. 사용자 승인 이력은 보존 | 한 프레임 변경 시 그 프레임의 두 전환, 끝 프레임 변경 시 루프 검수가 오래된 근거로 통과하지 않음 |
| 4. 보조 경고 | 마스크 경계 부근의 alpha 단절·새 장선·급격한 명암 변화는 검토 후보 위치로만 표시. 형상·가림에 따른 정상 선을 자동 실패 처리하지 않음 | 알려진 실패 사례를 보여 주되 깃/머리 가림의 정상 경계와 구분해 사람이 판정. 수치 개선만으로 승인 불가 |

구현 전에 해당 코드의 실제 저장/조회·View/Controller 경로와 모든 호출부를 확인하고 위 표의 소유 경계를 확정한다. 최소 검증 사례는 이번 다각형 명암 단절, 정상 의상 경계, 투명 외곽 잘림, 손목 접합 재발, 12→1에서만 발생하는 단절, 선택본 변경으로 오래된 검수 무효화다. 자동 경고 임계값은 검증 전 임의 확정하지 않는다. 게임 연결·전체 과거 자산 재제작·자동 미술 승인 기능은 이 계획에 포함하지 않는다.

## 승인 기준·현재 작업본 관리 — 2026-11-08 사용자 승인 / 필수

다음 신규 제작·수정·재개부터 적용한다. 승인 사실의 원본 기록은 **대상별 기존 QA/제작 명세 한 곳**, 현재 선택 상태의 원천은 **실제 FrameStudio 프로젝트**로 둔다. 인계에는 원본 기록 링크와 필요한 변경 사실만 남긴다. 문서와 도구 상태가 다르면 둘 중 하나를 추측으로 덮어쓰지 않고 변경 이력을 대조한다.

1. **승인 범위 식별:** 캐릭터·방향·동작별로 외형/화풍, 첫 자세, 주요 동작, 광원, 특정 부위, 전체 클립의 승인 버전·자산 경로·사용자 승인 근거를 구분한다. 승인 근거가 없으면 후보/미확인으로 남긴다. 부분 승인을 전신·다른 방향·전체 애니메이션 승인으로 확대하지 않는다.
2. **현재 작업본 식별:** 작화 전에 프로젝트 ID, revision, 실제 선택 프레임별 자산/버전, 참조 원본, 프레임 수·노출 시간, 변경/보호 범위를 확인한다. 여러 버전이 섞여 있으면 프레임별 선택 목록 또는 그 목록을 소유하는 도구 기록을 연결한다. 파일명·폴더의 latest/approved 표기만 믿지 않는다.
3. **작업본과 기준본 분리:** 승인 원본을 보존하고 새 후보로 수정한다. 후보는 편집의 출발점일 수 있지만 승인 기준을 대체하지 않는다. 수정 직전 선택 상태와 복구 방법을 남기며, 실패 후보는 이력을 유지한 채 비교 기준이나 후속 수정의 정상본으로 승격하지 않는다.
4. **제시 전 연결 확인:** 선택 자산 → 출력물 → 비교 화면이 같은 버전·시간표를 사용하는지 확인한다. 자산 ID/경로·필요한 해시와 실제 화면을 함께 확인하고, 이전 캐시·다른 출력·잘못된 선택으로 불일치하면 먼저 연결을 바로잡는다. 원본과 출력의 크기/포맷이 달라 해시가 다를 수 있으므로 파일 동일성과 표시 대응을 구분한다.
5. **승인 반영:** 사용자가 승인한 정확한 후보·범위·근거만 기존 기록에 추가하고 이전 승인 이력을 보존한다. 도구의 승인 상태 변경은 해당 범위의 지원 여부를 확인해 공식 UI/API로 처리한다. 부분 승인을 전체 승인 버튼으로 대신하지 않는다. 승인본을 수정하면 변경 범위와 영향받는 검수는 후보/재검수로 분리하되, 변경 없는 과거 승인 사실은 지우지 않는다.
6. **재개·인계:** 승인 기준, 현재 선택본, 마지막 제시본, 미승인/미검수 항목, 다음 허용 작업을 구분해 넘긴다. 승인 여부는 사용자 근거로, 현재 선택은 도구 상태로 확인한다. 변경 없는 근거는 재사용하고 작업 전환·자산/시간표 변경·상충 기록이 있을 때 필요한 범위만 다시 확인한다. 실제 원본 확인이 불가능한 제작은 보류하고 구체적인 복구 사항을 알린다.

기존 QA에 아래 항목을 유지한다. 해당 정보가 이미 있으면 중복 표를 만들지 않고 연결한다.

```text
대상: 캐릭터 / 방향 / 동작
승인 기준: 범위별 버전·자산 / 사용자 승인 근거 / 미확인 범위
현재 작업본: 프로젝트 ID·revision / 프레임별 선택 기록 / 시간표
수정 범위: 변경·보호 대상 / 수정 직전 선택 상태·복구 방법
제시본: 출력 경로·원본 버전 / 비교 화면 사용본 / 일치 확인 근거
상태: 후보·부분 승인·전체 승인 / 실제 검수·미검수 / 게임 연결 별도
```

## 주요 자세 사전 검수 — 2026-11-08 사용자 승인 / 필수

신규 동작 또는 승인된 동작 변경은 **주요 자세를 먼저 검수한 뒤 중간 프레임을 제작한다.** 기존 클립의 플리커만 수정하는 작업에 새 포즈 제작·동작 변경을 끼워 넣지 않는다. 기존 주요 자세와 검수 근거가 유효하면 재사용하며, 영향받는 부분만 재검수한다.

1. **작화 전 동작 계약:** 인물 기준 좌/우 공격 손, 화면 진행 방향, 카메라, 시작·종료 자세, 발 접지, 몸통/골반 회전 의도, 무기/FX 부착점, 프레임 수·시간표와 보호 대상을 기록한다. 화면 오른쪽과 인물의 오른손을 혼동하지 않는다. 단순 좌우 반전도 공격 손·의상 비대칭·광원을 바꾸는지 확인한다. [첫 프레임 구도·광원 기준](#first-frame-lighting-layout-gate-20261108)을 작화 전에 확정한다.
2. **필요한 주요 자세만 준비:** 공격은 시작 → 준비 → 타격 정점 → 회수 → 복귀를 기본으로 하되 같은 자세는 재사용한다. 대기/바람은 기준 → 최대 반응 → 반대 반응/복귀 등 실제 변화의 극점을 고른다. 모든 동작에 다섯 장을 강제하지 않는다. 각 자세의 역할·배치 프레임·노출 시간을 정하고 고유 원화 수와 최종 노출 수를 구분한다. 단계별 작화는 기존 도구 흐름으로 즉시 연결한다.
3. **나란히 비교:** 같은 캔버스·배치 기준으로 승인 원본과 주요 자세를 펼쳐 놓고 실제 배경/표시 크기와 확대에서 검사한다. 자동 중심 정렬로 접지·체격 변화를 가리지 않는다.

| 검사 대상 | 통과 기준 |
| --- | --- |
| 인물·체격 | 얼굴 정체성, 머리 부피, 어깨/승모근·팔·몸통·골반·다리 비례가 원근·가림에 맞게 이어짐. 갑작스러운 어깨 축소 없음 |
| 공격 손·연결 | 지정한 손이 준비 위치에서 공격하며 반대팔 회수, 어깨–팔꿈치–손목, 어깨–몸통–골반 회전이 동작 의도와 일치 |
| 접지·무게 이동 | 지지발과 발목–신발 연결이 유지되고 의도하지 않은 미끄러짐·발 크기 변화가 없음 |
| 의상·부착·가림 | 소매·띠·옷자락·머리뿌리·무기 부착점, 앞뒤 겹침과 필요한 숨은 면이 연결됨 |
| 광원·재질 | 같은 광원 기준에서 형태 회전에 따른 명암이 이어짐. 자세마다 새로운 하이라이트·주름 무늬를 임의 생성하지 않음 |
| 궤적·복귀 | 주요 자세의 순서·간격·시간 배치가 의도한 타격/반응과 회수를 표현하고 이전/다음 동작 또는 루프로 연결 가능 |

4. **통과 후 중간 제작:** 항목별 통과/실패/미확인과 근거를 기존 QA에 짧게 기록한다. 주요 자세를 시간표에 놓은 간단 재생도 확인하되 중간 프레임 없는 단계의 끊김과 구조 오류를 구분한다. 구조·손 방향·광원 불일치가 남으면 해당 주요 자세부터 수정하고 그 오류를 가진 중간 프레임을 양산하지 않는다. 검수 통과와 사용자 미술 승인은 별개이며, 기존 승인 범위 안의 작업에 매 자세 재승인을 요구하지 않는다. 승인 외형/동작 변경 등 실제 범위 초과만 확인한다.
5. **후속 검수 유지:** 주요 자세가 맞아도 중간 작화·접합·플리커 통과는 아니다. 앞뒤 주요 자세를 함께 참조해 중간을 만들고 [접합 회귀](#junction-regression-gate-20261107)와 [플리커 전 과정](#flicker-improvement-workflow-20261108)으로 모든 인접 전환·루프를 검사한다. 중간 제작 중 주요 자세를 변경하면 영향받는 연결과 검수 근거를 갱신한다.

기존 QA의 최소 기록: `주요 자세 역할·프레임·자산 / 동작 계약 / 항목별 결과·근거 / 미확인·수정 사항 / 중간 제작 진행 가능 여부`. 이 두 절은 제작 운영 규칙이며 자동 승인/품질 차단 기능의 구현이나 과거 자산 전수 재검수를 의미하지 않는다.

## 플리커 개선 전 과정 — 2026-11-08 사용자 요청 / 필수

신규 애니메이션의 예방, 기존 클립의 플리커 진단·교정·검수·인계에 적용한다. **문제 부위와 원인을 확인하기 전에 전체 밝기 보정이나 재생성을 시작하지 않는다.** 아래 절차가 작업 순서를 소유하며, [첫 프레임 광원](#first-frame-lighting-layout-gate-20261108), [접합 회귀](#junction-regression-gate-20261107), [외부 작화 연계](#external-authoring-default-20261106)는 각 세부 계약을 소유한다. 기존 사용자 제한과 승인 범위가 우선한다. 문서화는 자동 검수 기능의 구현이 아니다.

### 1. 요청·원본·승인 범위부터 고정

- 사용자가 지적한 캐릭터·방향·클립·부위를 그대로 기록한다. 다른 캐릭터 승인 이력 분석 요청을 현재 캐릭터 수정으로 바꾸지 않는다. 사용자가 머리·승모근·소매·발목·신발을 지적했다면 그 범위를 먼저 조사한다. 조사 중 추가 발견은 별도 표시하고 원래 범위를 대체하지 않는다.
- 실제 도구 프로젝트 ID, revision, 선택 프레임 자산, 출력·미리보기의 사용 자산, 승인 원본과 승인 근거를 확인한다. **정체성/첫 자세 승인, 동작 승인, 특정 부위 승인, 전체 클립 승인, 게임 연결 완료**를 구분한다. 최신 후보를 승인본으로 승격하지 않는다.
- 프레임 수·노출 시간·배치 위치·크기·배경, 동작·얼굴·손발 등 보호 대상과 변경 허용 범위를 기록한다. 새 버전과 복구 가능한 수정 전 상태를 남기고 승인 원본은 덮어쓰지 않는다. 현재 유효한 정보를 재사용하며 매 단계 동일 상태를 불필요하게 재조회하지 않는다.
- 이미 승인된 국소 수정과 정상 연결을 회귀 검사 대상으로 등록한다. 기존 QA/제작 명세에 필요한 기록만 추가하며 작업마다 별도 보고서를 늘리지 않는다.

### 2. 원본 → 출력 → 표시를 분리해 재현

- 같은 클립의 원본 PNG, 출력 GIF/APNG/시트, 실제 비교 화면을 대조한다. 원본 자체의 불일치와 셀 추출·크롭·중심 재정렬·팔레트/alpha·리사이즈·로딩/시간표·렌더 문제를 구분한다. 화면에서만 생기는 문제를 원화 재채색으로 고치지 않는다.
- 사용자 지적 부위의 전체 프레임 배열과 문제 전환의 앞–현재–뒤 프레임을 같은 크기·원점으로 놓는다. 확대/실제 표시 크기, 밝은/어두운 배경을 필요에 따라 사용한다. 편의를 위한 자동 중앙 정렬로 위치 튐을 숨기지 않는다.
- 정상 속도와 느린 속도에서 같은 시간으로 동기화한 전후 비교를 준비한다. 루프 전체와 마지막→첫 전환, 시작/끝이 다른 동작이면 진입·복귀까지 확인한다. 마지막과 첫 그림의 동일 여부만으로 루프를 합격시키지 않는다.
- 도구가 정지 캡처만 제공하면 `정지 관찰`, `재생 동작 확인`, `연속 영상 지각 검수`를 분리해 기록한다. 재생 카운터 변화나 GIF 디코딩을 연속 시각 검수로 보고하지 않는다. 연속 검수가 불가능하면 그 사실을 초기에 알리고 가능한 검사만 진행하며, 그 한계를 이유로 근거 없는 수정본을 반복 제작하지 않는다.

### 3. 원인을 분류하고 확인할 방법을 정한다

| 원인 유형 | 확인할 근거 | 해당 원인에 맞는 최소 수정 |
| --- | --- | --- |
| 출력·표시 오류 | 원본은 정상인데 셀 이웃 머리/신발 혼입, 크롭 잘림, 원점 이동, palette/alpha 또는 표시 순서 오류 | 추출·출력·배치 경로 교정. 원화 보존 |
| 고정 부위의 프레임 간 변화 | 같은 기준 대비 머리뿌리·얼굴·장비·접지 발의 위치, 외곽, 내부 묘사가 불필요하게 달라짐 | 의도상 고정이 맞는 부위만 승인 기준으로 복원하고 주변 연결 검수 |
| 형태·중간 동작 불연속 | 머리 가닥/부피, 어깨·소매 형태, 발목/신발 각도 등이 정점 앞뒤에서 급변 | 승인 동작을 유지하는 필요한 국소 중간 형태 교정. 시간표·포즈 변경은 허용 범위 확인 |
| 접합·가림 오류 | 보호 마스크가 옛 선/조각을 남김, 움직이는 면의 부착점·앞뒤 겹침·숨은 면이 끊김 | 양쪽 구조를 포함한 연결 복원 또는 필요한 국소 작화. 경계 블러만으로 처리하지 않음 |
| 실제 색·광원 불일치 | 같은 형태·같은 재질 면을 비교했을 때 색/노출/하이라이트 강도만 달라짐 | 해당 면의 색·명암만 교정. 카메라·가림·회전 때문에 달라진 면은 분리 |
| 명암 경계 자체의 불일치 | 주름·그림자·하이라이트 무늬가 앞뒤에서 새로 생기거나 다른 위치로 이동 | 허용 범위 안에서 해당 내부 명암 경계 교정. 전체 평균 밝기나 대비 완화로 해결됐다고 주장하지 않음 |

- 관찰 사실, 원인 가설, 미확인을 구분한다. 복합 원인이면 가장 명확한 한 원인부터 시험한다. `플리커`라는 단어만으로 색 문제를 가정하지 않는다.
- **보존 검사는 두 축이다:** (A) 같은 프레임의 수정 전후 보호 대상 보존, (B) 의도상 고정인 부위의 프레임 간 일관성. A 통과는 B 통과가 아니다. 움직이는 부위에는 원점 픽셀 동일을 강제하지 않고 부착·가림·형태 연결을 검사한다.
- 승인 원본에도 특정 결함이 있을 수 있다. 승인 범위를 확인하며 결함을 무조건 복사하지 않는다. 머리·발이 보호 대상이라는 이유로 검사를 생략하지 않는다. 보호 부위 내부의 변경이 필요하면 실제 제한 충돌과 필요한 최소 범위를 설명한다.

### 4. 최소 한 구간에서 효과를 입증한 뒤 확대

- 문제 프레임과 양옆, 기준 원본을 고정해 **한 원인·한 수정 방식**으로 시험한다. 전후 예상 차이를 먼저 적는다(예: 소매 밖 검은 돌출 제거, 발목 외곽 위치 안정, 머리 정점 앞뒤 가닥 연결). 밝기 수치 감소처럼 실제 문제와 무관한 목표를 세우지 않는다.
- 승인된 고정 부위·광원·시간표를 유지한다. 필요한 작화는 기존 공식 도구 흐름으로 즉시 연결하고 사용하지 않은 생성본·반려본을 구분한다. 동일 좌표 복원은 자세/가림/접합이 실제로 맞을 때만 사용한다.
- 마스크는 고정 핵심부, 가동부, 양쪽 연결부를 구분해 만든다. 직사각형·색상 임계값이 피부/소매/바짓단을 자르거나 픽셀 누락·얼룩을 만드는지 확대 확인한다. 머리뿌리·승모근–소매·손목·바짓단–발목–신발을 연결된 구조로 본다.
- 사용자가 허용한 범위면 재승인을 반복 요청하지 않는다. 전체 재생성, 금지된 변형, 보호 대상 변경 등 실제 범위 초과가 있을 때만 정확한 변경·이유·보존 방법을 설명하고 확인한다. 성공한 다른 캐릭터의 제작 방식도 현재 제한을 우회하는 권한이 아니다.
- **시험 통과 조건:** 지적한 결함이 전후 비교에서 줄었고, 양옆/접합에 새 결함이 없고, 보호 조건이 유지되어야 한다. 숫자만 줄거나 시각적으로 효과를 확인할 수 없으면 통과로 기록하지 않고 전체로 확대하지 않는다.

### 4-A. 첫 프레임·동일 면 RGB 대응 — 2026-11-11 사용자 승인 / 플리커 개선 메인 절차

카일 우측 Idle v13 사용자 승인에 따라 **고정 부위 원화 공유 + 움직이는 부위의 첫 프레임 동일 면 색 코드 대응**을 색·광원 플리커 개선의 기본으로 적용한다. 눈대중 명암, 전신 평균 밝기, 재질 전체 분위수 대표색 맞추기를 기본 방법으로 사용하지 않는다. 위 §1–3의 원인 분류는 유지하며 형태·접합·출력 오류를 색 보정으로 숨기지 않는다. 기존 v27의 재질별 대응을 아래 절차로 구체화한다.

1. **승인 기준과 보호 범위 고정.** 실제 프로젝트·revision·선택 자산과 비교 출력의 일치를 확인한다. 최초 색 기준은 사용자가 지정한 첫 프레임으로 유지하고, 현재 승인 작업본은 동작·부위 보존의 기준으로 구분한다. 중간 후보를 색 기준으로 누적 교체하지 않는다. 동작·얼굴·손발·외곽/alpha·시간표 및 이미 승인된 띠·소매 등의 보호 범위를 기록한다.
2. **고정/가동 분리.** 의도상 고정이고 광원·가림이 같은 부위는 승인 원화 RGBA를 공통으로 사용하여 색·선·질감까지 고정한다. 바람에 움직이는 자락과 고정 하체의 접합 여백은 별도 검사한다. 고정 부위에 프레임별 색 보정을 반복하지 않는다. 포즈/가림이 다른 면에 원본을 무조건 복사하지 않는다.
3. **같은 면을 먼저 대응한 뒤 RGB·HEX 기록.** 옷깃 안쪽/바깥쪽, 자락의 각 판, 띠의 상면/중앙/하면처럼 실제 구조로 나눈다. 기준/대상 위치·마스크와 실제 RGB·HEX를 함께 남긴다. 밝은 면·중간색·그림자 역할은 확인된 면 안에서만 대응한다. 검은 접힘선·윤곽·피부·다른 주름이 표본에 들어가면 제외하고 다시 지정한다. 자동 추적은 후보 탐색이며 동일 면 확정이 아니다. 중앙색 하나, 화면 좌표 일치, 분위수 일치만으로 전체 면 대응을 주장하지 않는다.
4. **한 구간에서 국소 색만 시험.** 대응한 면의 색 차이만 적용하고 원래 동작·외곽·선 배치는 유지한다. 작은 색 얼룩은 해당 면의 첫 프레임 국소 RGB 표본/중앙값으로 제한해 처리할 수 있다. 이때 색 표본 추정과 실제 원화/붓질 복사를 구분하며, 이웃 주름선까지 옮기는 방식은 제외한다. 카일의 특정 좌표·7×7 표본 크기를 다른 자산의 고정값으로 이식하지 않는다. 전신 밝기·경계 블러·시간축 이미지 혼합·포즈 변형은 대체 수단이 아니다.
5. **독립 표본과 실제 비교로 채택 여부 결정.** 기준/전/후를 같은 크기와 배경에 놓고 확대 및 실제 표시 크기에서 색·선·접합을 확인한다. 보정 산출에 쓰지 않은 표본의 RGB 차이와 보호 픽셀을 별도로 검사한다. 악화되거나 시각 개선이 확인되지 않은 부위는 원본 유지/복원하고 전체에 확대하지 않는다. 대부분 이미 맞는 옷깃을 넓게 다시 보정하는 대신 실제 어긋난 국소 면부터 처리한다.
6. **모든 인접 전환과 루프를 함께 검사.** 한 장의 기준색 오차 감소만으로 채택하지 않는다. 전체 프레임의 대응 면 RGB 변화, 마지막→첫 연결, 고정 부위 및 이전 승인 부위의 회귀를 확인한다. 연결이 나빠지면 해당 부위의 RGB 보정량만 줄이거나 원복한다. 프레임/동작을 혼합하거나 시간을 바꾸지 않는다. 강도 선택에 사용한 표본은 더 이상 독립 검증 표본이 아니므로 구분한다. 국소 재조정 후에도 개선이 없으면 같은 보정을 반복하지 말고 면 대응·선 경계·보호 마스크 원인을 재검토한다. 광역 보호 마스크가 주변 옷감을 포함했더라도 이름만 보고 얼굴/손으로 취급하지 않으며 실제 보호 대상과 허용 옷감을 구별한다.
7. **배경 비교·승인·한계 기록.** 동일 시간표의 기존 승인 열차/배경 전후 비교를 제공한다. 실제 선택 자산·해시·사용자 승인 문구·범위를 기존 QA에 기록하고 다음 수정의 보존 기준으로 삼는다. 사용자 미술 승인, 정지 관찰, 재생 작동, 연속 지각 검수, 도구 승인 플래그, Unity 연결은 별개다. 색이 맞아도 주름 경계/질감 변화가 남으면 별도 원인으로 기록하고 완전 제거를 주장하지 않는다.

현재 승인 사례: [카일 우측 Idle v13 승인 및 근거](../../QA/DirectionImpact-20260921/combat-carriage-durability-v01/PRODUCTION-SPEC.md#kyle-right-idle-v13-approved-20261111), [승인 자산 목록](../../QA/DirectionImpact-20260921/combat-carriage-durability-v01/kyle-right-idle-depth-v13-collar-hem-rgb/approval.json). 이전 [카일 공격 v27](../../QA/DirectionImpact-20260921/combat-carriage-durability-v01/PRODUCTION-SPEC.md#kyle-v27-approved-20261109) 근거는 보존한다. 이 절은 다음 제작·수정부터 적용하는 운영 기준이며 도구의 자동 강제 기능 구현이나 다른 채팅의 재독 완료를 뜻하지 않는다.

### 5. 실패한 방법은 멈추되 작업을 포기하지 않는다

- 효과 없음·악화·새 접합 오류가 확인되면 그 후보를 기준으로 다음 보정을 쌓지 않는다. 이력은 보존하고 선택 상태는 해당 변경을 취소하거나 직전 유효 상태로 복구한다. 직전 상태도 결함이 있으면 전체 정상본으로 부르지 않는다.
- 동일 가설·동일 방법의 효과 부족이 확인되면 강도만 조금 바꾸거나 프레임 수를 늘려 반복하지 않는다. 새 관찰/실패 원인을 밝히고 원본·출력·마스크·형태 대응 중 무엇이 잘못됐는지 다시 확인한다. 근거 없는 자동 재시도와 무의미한 버전 증식을 금지한다.
- 중단 대상은 **실패한 방식**이며 사용자 작업 전체가 아니다. 범위 안에서 확인 가능한 다른 원인을 계속 조사한다. 해결에 필요한 변경이 사용자 제한과 실제 충돌하거나 필요한 원본/검수 수단이 없을 때만 구체적으로 설명한다. 반복 실패를 추가 승인 요청으로 떠넘기지 않는다.

### 6. 전체 전환과 회귀 검수

- 시험이 통과한 수정만 필요한 프레임으로 확대한다. 모든 인접 전환과 루프/진입·복귀를 같은 배경·크기·시간표로 비교한다. 한 구간을 고쳐 이웃 구간이 악화됐는지 따로 확인한다.
- 원본 해시/선택 이력, 프레임 수·노출 시간, 의도하지 않은 위치·크기·alpha 변화, 보호 영역 A/B 검사, 이미 승인된 접합·부위 보존을 확인한다. 고정 부위 복원으로 원래 의도한 움직임이 사라지지 않았는지도 검사한다.
- 자동 수치는 위치와 원인에 맞는 보조 자료로만 사용한다. 움직이는 화면 좌표의 RGB 차이, 전체 재질 히스토그램, 실루엣 겹침 비율, 픽셀 수를 플리커 제거율/자연스러움 점수로 바꾸지 않는다. 형태 대응 알고리즘의 신뢰 가능한 범위가 작으면 클립 전체 효과로 확대하지 않는다.
- 프레임 삭제·재배열·동작 고정·리타이밍·블러·시간 혼합으로 결함을 숨기지 않는다. 그러한 변화가 필요한 경우 원래 작업 범위에 포함되는지 먼저 판단한다. 12장이라는 수와 실제 고유 원화 수, 반복 노출 수는 별도 기록한다.

### 7. 결과·승인·후속 작업을 분리

- 결과에는 `원인과 근거 / 실제 변경 부위·방식 / 전후 비교 / 보호·회귀 검사 / 연속 검수 여부 / 남은 결함`을 짧게 남긴다. 원본 저장·도구 연결·출력·사용자 미술 승인·게임 연결을 한 상태로 합치지 않는다.
- 알려진 결함을 숨겨 승인받지 않는다. 사용자가 일부 또는 전체 시각 결과를 승인하면 정확한 버전·범위·근거를 기록한다. 사용자 승인과 수행하지 않은 기술/연속 검수는 별개다. 승인받은 부위는 이후 수정의 회귀 기준에 추가한다.
- 후속 채팅은 이 절과 대상의 기존 QA만 필요한 범위로 읽는다. 요청 범위·실제 원본/승인·문제 전환·검증된 원인·실패한 방법·현재 선택본·미검수·다음 허용 작업을 넘긴다. 새 채팅 생성이나 자동 메시지 권한을 추가하지 않는다.

기존 QA에 쓸 최소 기록 형식:

```text
대상/사용자 지적: 캐릭터·방향·동작 / 부위·전환
원본/승인: 프로젝트·revision·선택 자산 / 승인 버전·범위·근거
유지/변경: 동작·시간표·보호 대상 / 허용 국소 범위
재현/원인: 원본·출력·표시 관찰 / 사실·가설·미확인 / 확인 방법
시험: 한 구간 전후 자산·방법 / 지적 결함의 실제 변화 / 통과·실패 이유
회귀: 앞뒤·루프·기존 승인 부위 / 보호 A·B / 실제 표시 크기
상태: 현재 선택본 / 정지·연속 검수 범위 / 미해결 / 다음 허용 작업
```

## 첫 프레임 작화 전 구도·광원 확정 — 2026-11-08 사용자 명시 / 필수

**첫 프레임을 그린 뒤 조명을 맞추는 것이 아니라, 첫 프레임을 그리기 전에 구도와 빛의 기준부터 정하고 그린다.** 신규 첫 자세·첫 프레임 제작 및 승인된 재작화에 적용한다. 기존 승인본을 일괄 재작화하거나 외형을 변경하라는 지시가 아니다.

1. **작화 전 기준 확정:** 실제 배치할 배경과 승인 원화를 대조하여 카메라 시점·인물 방향·위치·크기, 햇빛/주광원의 방향·높이·색·강도, 보조광/역광 유무, 밝은 면·그늘·그림자 방향과 농도를 먼저 정한다. 배경이 석양이라는 이유만으로 새 역광이나 하이라이트를 임의 추가하지 않는다. 배경이 미정이면 그 사실과 사용할 공통 조명 기준을 명시한다. 승인 외형·보호 영역과 충돌하는 미결 사항은 작화 전에 해소한다.
2. **첫 프레임 제작 요청에 포함:** 위 기준과 참조 자산 경로/버전을 해당 리소스의 기존 제작 명세·FrameStudio 요청서에 기록한 뒤 첫 프레임을 그린다. 기준이 비어 있는 상태에서 먼저 생성하고 사후 설명으로 채우지 않는다. 매 프레임 재승인을 요구하는 절차는 아니다.
3. **첫 프레임을 실제 배경에서 검수:** 광원 방향, 형태에 붙는 명암, 인물과 배경의 조화, 실제 표시 크기를 확인한다. 미확인 후보를 승인 기준으로 승격하지 않으며, 기준 불일치는 중간 프레임 제작 전에 해결한다.
4. **후속 프레임에 같은 기준 계승:** 카메라·광원·노출·색 기준을 유지하고 동일한 머리 가닥·옷 주름의 밝은 면과 그림자가 형태의 움직임을 따라 이어지게 그린다. 매 장 새 명암 무늬를 만들지 않는다. 의도된 조명 변화가 있는 연출은 시간에 따른 변화 계획을 먼저 명시한다. 첫 프레임뿐 아니라 앞뒤 자세와 루프의 형태·속도 연결도 함께 참조한다.
5. **검수와 한계:** 모든 인접 전환과 마지막→첫 프레임을 확대/실제 표시 크기 및 정상/느린 재생으로 확인한다. 광원 통일이나 픽셀 변화량 감소만으로 플리커 제거를 판정하지 않는다. 접합 회귀 검수와 원본 보존 규칙을 유지하며 실제 관찰하지 못한 연속 재생은 미검수로 남긴다.

제작 순서: **배경·승인 원화 확인 → 아래 카메라 대조·배치 기준 기록 → 구도·광원·명암 기준 확정 → 첫 프레임 작화 → 실제 배경에서 검수 → 같은 기준으로 후속 프레임 작화·접합/루프 검수.** 후속 세션은 이 절부터 확인한다. 문서 등록은 도구의 자동 강제 기능 구현이나 다른 세션의 재독을 의미하지 않는다.

### 카메라 구도 대조 — 2026-11-14 사용자 요청 / 첫 작화 전 필수

레이나 시점 교정에서 구형 열차를 최신으로 선택하고, 강한 부감을 없애려다 지나친 수평 측면으로 재작화한 실패를 반영한다. 전투 요원 첫 자세 및 카메라 변경에 적용한다. 플리커만 수정하는 작업에 카메라 변경을 끼워 넣지 않는다.

LASTRAIL 화면 원본은 먼저 [현재 승인 시안 단일 목록](../../docs/handoffs/CURRENT_APPROVED_VISUALS.md)을 확인한다. 현재 v06 열차 외형과 편성 화면의 커브 부감, 기존 승인 전투 카메라는 서로 다른 범위다. 구 열차 이미지의 역사 분석과 신규 디자인 사용을 구분한다.

1. **디자인과 카메라 원본을 분리한다.** 현재 열차 디자인의 승인·폐기 기록, 실제 목표 전투 화면/영상의 버전·시각·배경 원본, 해당 요원의 승인 원화를 각각 확인한다. 파일명의 final/latest, 최신 수정 시각, 과거 승인만으로 현재 기준을 고르지 않는다. 열차 편성용 조감도는 전투 카메라 기준을 자동 대체하지 않으며, 납품된 역사 영상도 현행 디자인을 자동 소유하지 않는다. 명시적 비교 요청으로 옛 시안을 사용할 때는 비교용임을 기록하고 재승격하지 않는다.

## 세션 계승 후에도 유지하는 제작 절차 — 2026-11-06 사용자 승인

이 절과 [도구에서 시작하는 필수 제작 순서](#studio-first-production-20261017)를 신규·후속 세션의 제작 진입점으로 사용한다. 새 규칙으로 기존 절차를 대체하는 것이 아니라, 기존 절차 누락과 승인 기준 이동을 방지하는 보강이다. 최신 사용자 지시가 우선하며 이전 후보·역사 기록을 현재 승인으로 승격하지 않는다.

### 착수 전 확인과 기록
- 생성·편집 전에 대상 요원/방향/동작의 제작 정책, 기존 QA/인계의 최신 승인 범위, 실제 FrameStudio 프로젝트를 확인한다. 실제 프로젝트 ID·선택 버전·원본 자산 경로·승인 근거·변경/보호 영역·사용할 기능·출력 경로를 기존 QA/인계에 짧게 기록한다. 이미 유효한 기록은 재사용하되 문서 경로를 읽은 것과 도구의 실제 상태를 확인한 것을 구분한다.
- 프로젝트를 열 수 없거나 원본/승인본을 식별하지 못하면 해당 제작만 보류하고 부족한 정보와 복구 방법을 알린다. 파일명·최신 수정 시각·PNG·GIF·웹 미리보기로 도구 프로젝트의 상태를 추정하지 않는다. 새 프로젝트 생성/기존 자료 가져오기는 원본 관계와 후보 상태를 확인한 뒤 기존 절차로 수행한다.
- **수정 요청은 제작 방식 변경 허가가 아니다.** 플리커 교정은 전체 재생성, 신규 얼굴 설계, 파츠 이동, 다른 엔진으로의 전환을 자동 허용하지 않는다. 대상에 승인된 도구/엔진/방법과 범위를 먼저 확인한다.

### 도구와 보조 처리의 경계
- FrameStudio의 UI 또는 공식 로컬 API로 기존 작업·참조·시간표·버전·검수 이력을 관리한다. 파일/DB 직접 변경으로 검증·승인을 우회하지 않는다. 생성 엔진은 당시 승인된 연결을 따르며 현재 구동 가능 여부는 별도 확인한다.
- 기존 필수 제작 순서 §3에서 이미 허용한 외부 작화·원본 보정·출력 보조는 그 조건 안에서 수행하며 형식적 재승인을 요구하지 않는다. 먼저 도구에 작업/원본을 연결하고 기능 부족 또는 기존 실패 근거와 외부 처리 범위를 기록·고지한 뒤, 단계별 결과를 해당 프레임 버전으로 다시 연결한다. 마지막 완성 PNG만 가져오는 것을 도구 제작으로 설명하지 않는다.
- **도구를 작업장으로 사용하는 흐름의 포기, 엔진/제작 방식 변경, 사용자 제한을 넘는 보정은 이유·대안·변경 범위·보존 대상과 복구 방법을 설명하고 별도 사용자 승인 후 진행한다.** 도구 오류·접근 실패·품질 불량은 임의 우회 권한이 아니다. 검증된 실패를 형식적으로 재실행할 필요는 없다.

### 승인 기준과 교정 검수
- 화풍/정체성 승인 원본, 동작 참고, 수정 후보, 출력물, 게임 실사용을 구분한다. 후보를 다음 후보의 유일한 기준으로 연쇄 사용하지 않는다. 최신 파일이라는 이유로 승인 기준을 교체하지 않는다.
- 플리커는 문제 전환·프레임·부위를 먼저 식별하고 선 위치/명암/실루엣/접합 중 원인을 구분한다. 한 문제 프레임을 기존 방식 안에서 교정한 뒤 앞뒤와 마지막→첫 프레임을 검수하고 확장한다. 동일 캔버스 좌표의 표정선 복사만으로 얼굴 구조 정렬을 가정하지 않는다.

## 최신 사용자 정정: 전신 동작 설계와 고정 외형 보호 — 2026-10-31

사용자가 프레임별 전신 새 작화를 요구한 이유는 작은 조각만 움직여 관절과 몸통의 연쇄 동작이 누락되는 것을 막기 위해서다. 움직이지 않는 얼굴·외형까지 매번 재생성하라는 뜻이 아니다. 이 절은 아래 과거 지침 및 개별 QA의 ‘전신 새 작화’를 모든 픽셀의 독립 재생성 의무로 해석한 부분보다 우선한다. 승인 원본·과거 결과는 보존한다.

- **동작 설계는 전신 기준으로 한다.** 직권은 손·손목·팔꿈치·상완·견갑/어깨·가슴/등·몸통 회전과 체중 이동, 반대 어깨/가드 팔의 연동을 함께 설계한다. 발 접지를 보존하면서 필요한 무릎·골반 연결도 검토한다. 주먹 위치만 바꾸거나 어깨만 움직이는 것으로 완료하지 않는다.
- **작화 범위는 동작의 영향을 받는 연결 부위 전체로 정한다.** 팔 조각만 잘라 이동하는 대신 어깨·겨드랑이·가슴·등·옷의 당김/주름·가림·숨은 접속면까지 필요한 범위를 연속해서 그린다. 경계를 관절 한가운데 임의로 끊지 않는다. 이 정정은 조각 이동·회전·워핑만으로 동작을 대체하는 승인이 아니다.
- **변하지 않는 외형은 보호한다.** 얼굴의 위치·각도·가림이 같은 구간에서는 승인 얼굴을 생성 대상에서 제외하고 원본 픽셀을 보존한다. 머리 전체를 무조건 고정하지 말고 실제 위치/각도/가림 변화와 얼굴 내부 작화 변화를 구분한다. 회전이나 표정 변화가 필요한 프레임만 필요한 얼굴 작화를 별도로 설계한다. 참조 이미지·같은 시드·낮은 denoise만으로 고정을 보장했다고 하지 않는다.
- **몸동작과 바람을 함께 연결한다.** 몸통 회전에 따른 옷의 당김과 앞뒤 가림, 띠·옷깃·머리의 바람 위상을 대조한다. 움직이는 머리 형태는 기존 프레임별 작화 규칙을 유지하되 고정된 얼굴 재생성을 강제하지 않는다. 고정 좌표 보호 영역 복원/합성은 허용하며 실제 재사용·새 작화·합성 범위를 정확히 기록한다.
- **생성 전에 범위와 실제 제어 경로를 확인한다.** 승인 원본, 관절 위치/이동 경로, 몸통 회전, 작화 영역, 보호 영역과 접합 여유를 표시한다. 도구가 마스크·보호 영역·구조 조건을 실제로 소비하는지 확인하고, 지원되지 않는 제어를 프롬프트만으로 구현했다고 주장하지 않는다. 필요한 생성 경로/모델 변경은 이유와 바뀌는 조건을 제시해 사용자 승인 후 실행한다.
- **검수는 외형 보존과 연결 동작을 함께 본다.** 고정 보호 영역은 픽셀 차이로, 움직이는 부위는 관절 연쇄·체형·접합·선명도·선 두께·명암·바람으로 검수한다. 접지/타격 시간과 정상·느린 재생의 인접 전환/대기 복귀를 확인한다. 픽셀 불변 검사만으로 자연스러운 동작을 통과시키지 않는다. 불량 대표를 같은 조건으로 반복하거나 전체 프레임으로 확대하지 않는다.

## 1~4번 모든 애니메이션의 전투 카메라 기준 — 2026-10-17 사용자 명시

**현행 적용 정정 — 2026-11-14:** 아래 1~4번 방향 번호·의무는 역사 기록이다. 현재는 사용자 2026-11-13 정정대로 **1번 LEFT / 2번 RIGHT**를 적용한다. 카메라 공통 원칙은 유지하되 신규 제작은 [카메라 구도 대조](#camera-composition-preflight-20261114)와 최신 방향별 승인 원본으로 시작한다. 구 레이나 D1/3/4를 새 1번 좌측의 대체 원본으로 사용하지 않는다.

- **모든 요원의 1·2·3·4번 애니메이션은 실제 전투 화면의 카메라 시점에서 제작한다.** Idle·공격·스킬·피격·다운·복귀 등 제작 대상 전 동작과 첫 자세·중간·정점·복귀의 전체 프레임에 적용한다.

## 부위 대응·명암 경계 제작 도구 보강 설계 — 2026-11-13 조사 / 미구현

사용자 요청: 선화·기준 채색을 분리하는 제작 흐름에 명암 경계 처리와 캐릭터 부위 구분 기준을 편성하고 관련 이론을 확인한다. 이 절은 설계 제안이며 코드 구현·도구 자동 강제·미술 검수 완료가 아니다. 기존 승인 자산과 첫 프레임 동일 면 RGB 정책을 유지한다. 현재 도구의 저장/API/UI 전체 지원 범위는 추가 확인 대상이다.

### 부위와 명암을 구분하는 기준
- 캐릭터 기준 좌/우로 영구 부위 ID를 정한다. 화면 좌/우는 표시 설명이며 포즈가 바뀌어도 ID를 뒤집지 않는다. 해부학적 연결, 의복의 실제 판/봉제·재질, 독립 움직임과 앞뒤 가림을 기준으로 필요한 만큼 나눈다. 색이 같다는 이유로 서로 다른 부위를 합치지 않는다.
- 부위(예: 캐릭터 오른팔 소매), 그 프레임에서 보이는 영역 조각, 그 위의 명암 역할을 별도 관리한다. 주름/가림으로 소매가 둘로 나뉘어도 원래 부위 ID와 재질 팔레트를 공유한다. 모든 닫힌 영역이나 주름 하나를 새 영구 부위로 만들지 않는다.
- 부위별로 부모/이웃 부위, 연결점, 재질/팔레트, 선화와 기준 채색 버전, 안팎면, 가림 관계를 연결한다. 가림 순서는 프레임별로 달라질 수 있다. 첫 프레임에 없는 노출면은 미확인으로 두고 보조 기준을 확정하며 근거 없이 첫 프레임 색을 배정하지 않는다.
- 머리는 뿌리와 큰 가닥 묶음부터 구분한다. 옷은 몸판/깃/소매/커프스/자락 등 실제 구조부터 시작한다. 세부 주름은 해당 부위 안의 형상·명암 정보다. 전체 캐릭터에 동일 분할 개수를 강제하지 않는다.

### 명암 경계 제작과 도구 편성안
1. 선화/밑색/명암 영역/세부 질감/독립 FX를 구분해 검토한다. 명암 경계 안내선은 출력 외곽선으로 굽지 않는다. 영역·마스크가 주름의 실제 선과 구분되게 한다.
2. 명암 영역에는 소유 부위, 기본/그림자/밝은 면 역할, 팔레트 참조, 경계의 단단함/부드러움, 기준 광원, 근거 자세를 연결한다. 자체 형태 음영과 다른 물체가 드리운 그림자를 구분하고 후자는 가리는 물체와 그림자를 받는 부위를 기록한다. 모든 명암을 세 가지 단색으로 강제하지 않는다.
3. 주요 자세에서 명암 경계를 확정하고 중간 자세에 대응시킨다. 색 기준은 최초 승인 팔레트, 형상 기준은 앞뒤 주요 자세를 함께 사용한다. 화면 좌표 고정·최초 마스크 복사·자동 워핑으로 작화를 대체하지 않는다.
4. 프레임별 영역 대응에 유지/분할/합류/가려짐/재노출/신규 노출을 표시한다. 불확실한 자동 대응은 후보로 남긴다. 그림자 생성/소멸에는 주름 변화·회전·광원·가림 등 설명 가능한 근거를 확인한다.
5. 비교 화면에 선화/부위 구분색/밑색/명암만/최종 합성 전환, 앞–현재–뒤와 기준 자세 비교, 명암 경계 겹쳐 보기, 전체 재생과 루프/idle 복귀 검토를 편성한다. 기존 프레임 선택·재생·버전 상태를 재사용하고 별도 승인 원장을 만들지 않는다.
6. 대응 부위 내 명암 면적 비율, 경계 이동, 영역 생성·소멸, RGB 이탈은 검토 경고로만 사용한다. 회전·가림에 따른 정상 변화와 구분하며 전신 통계나 동일 화면 좌표 비교로 자동 합격/불합격하지 않는다. 실제 크기에서 주름 떨림과 밝기 튐을 함께 본다.
7. 선화 변경 시 해당 채색/명암 대응과 인접 전환 검수를 재확인한다. 팔레트 변경은 참조 영역, 끝 프레임 변경은 루프/idle 연결에 영향을 표시한다. 과거 승인 이력은 보존하고 변경 후보의 현재 검수와 구분한다.

구현 전 기존 프로젝트 저장·요청서·외부 작화 연결·비교 화면의 실제 호출 경로를 확인한다. 신규 모델 설치나 엔진 교체를 이 조사로 승인하지 않는다. 최소 도입은 사람이 확정하는 부위/명암 영역과 팔레트 저장·비교이며 자동 추적/채색은 별도 효과 검증 후 판단한다. 첫 시험은 기존 문제의 짧은 연속 구간으로 제한하고 동작·시간표·체격·장비·접지 보존, 영역 분할/재노출, 주름 그림자와 투영 그림자, 앞뒤 및 루프를 확인한 뒤 전체 12장으로 확대한다.

### 조사 근거와 적용 한계
- Paint Bucket Colorization Using Anime Character Color Design Sheets (2024): https://arxiv.org/abs/2410.19424 — 부위 의미와 RGB를 갖는 색 지정표, 기준 자세·명암 주석, 주요 자세/연속 프레임 채색. 본 절의 구체적인 부위 분할 표준을 논문이 그대로 제시한다는 뜻은 아니다.
- Learning Inclusion Matching for Animation Paint Bucket Colorization (CVPR 2024): https://arxiv.org/abs/2403.18342 — 주름·가림에 의한 직접 영역 대응 실패와 포함 관계 대응. 모든 프레임의 일대일 대응을 강제하지 않는 근거.
- The Animation Transformer (ICCV 2021): https://arxiv.org/html/2109.02614v2 — 영역의 공간 관계, 일대다/가림 대응. 부위 정체성과 프레임별 가시 조각의 분리 설계에 참고.
- Learning to Shadow Hand-drawn Sketches (CVPR 2020): https://cal.cs.umbc.edu/Papers/Zheng-2020-Shade/ — 선화와 광원 방향에서 그림자 생성. 단일 그림의 명암 생성 근거이며 이 자료만으로 12장 시간적 일관성 보장을 주장하지 않는다.
논문 초록/공식 프로젝트 설명 및 AnT의 관련 본문을 확인한 설계다. 모델 실행·우리 화풍의 성능 실험은 하지 않았다. 부위별 계층, 데이터 필드와 단계별 검수는 위 근거를 바탕으로 한 LASTRAIL 적용 제안이다.

## 선화·부위·명암 분리 제작 플로우 — 2026-11-13 사용자 요청 반영

사용자: “좋아 단계별로 적용해서 제작 플로우 만들어봐”. 아래는 다음 제작에서 사용할 운영 흐름이다. 도구 코드/UI 자동화 구현 및 실제 클립 시험 완료를 뜻하지 않는다. 위 부위·명암 보강 설계를 이 흐름의 데이터 기준으로 사용한다. 담당은 해당 자산 Direction 제작 세션이며 승인 원본/후보와 기존 도구 연결 정책을 유지한다. 신규 제작에 적용하고 기존 승인 클립은 자동 재제작하지 않는다. 플리커만 수정하는 작업은 원인을 분류해 영향 단계부터 수행하며 승인 동작을 다시 만들지 않는다.

### 단계별 입력·산출·통과·복귀

| 단계 | 입력 → 산출물 | 통과 조건 / 실패 시 돌아갈 곳 |
| --- | --- | --- |
| 0. 대상 고정 | 실제 프로젝트·선택 버전·승인 범위 → 작업 기준 기록 | 원본/출력/화면 사용본 일치, 프레임 수·노출 시간·체격·장비·접지·보호 범위 확인. 불일치는 작화 전 연결부터 복구 |

| 4. 주요 자세 명암 설계 | 주요 선화·광원·팔레트 → 주요 자세별 그림자/밝은 면 경계 가이드 | 자체 음영/투영 그림자와 소유 부위 확인. 주요 자세 간 그림자 생성·소멸 이유 설명 가능. 큰 회전·신규 노출면의 기준 부족은 2~3으로 복귀 |
| 5. 중간 선화 | 앞뒤 주요 자세 → 전체 12장 선화와 프레임별 부위 대응 | 모든 인접 전환의 실루엣·머리 가닥·주름·손목·접지 및 12→1/idle 연결 확인. 분할/합류/가림/재노출 기록. 구조 불연속은 이 단계 또는 3으로 복귀 |
| 6. 밑색 | 확정 선화·부위 대응·색 지정표 → 전체 밑색 | 동일 부위에 지정 RGB 적용, 잘못된 부위 칠하기·미채색·경계 누출 없음. 내부 밑색과 선/alpha 가장자리 혼합색을 구분. 대응 오류는 2/5, 색 배정 오류는 6에서 수정 |
| 7. 명암 연결 | 주요 명암 가이드·전체 선화/밑색 → 프레임별 명암 영역과 합성 | 팔레트 역할 유지, 형태를 따른 경계 이동, 설명 없는 밝은 면/그림자 팽창·주름 점멸 없음. 경계 문제는 4/7, 구조 문제는 5로 복귀. RGB 보정만 반복하지 않음 |
| 8. 질감·FX | 검수된 인물 → 제한된 세부 질감과 독립 FX 연결 | 인물 단독과 FX 합성 각각 비교. 질감이 부위에 붙어 움직이고 새 잔선/얼룩 튐 없음. FX 발광을 인물 기본색에 굽지 않음. 새 튐은 추가한 단계부터 제거/재검토 |
| 9. 출력·전체 검수 | 선택 자산·노출표 → 실제 표시 크기 전후 비교와 검수 기록 | 1→2…11→12 전부 및 12→1 또는 마지막→idle, 정상/느린 속도, 외곽/손목/접지/기존 승인 부위 회귀 확인. 원본→출력→화면 일치. 관찰하지 않은 연속 지각 검수는 미검수 |
| 10. 승인·공급 | 정확한 후보 버전·검수 결과 → 사용자 승인 범위와 공급 기록 | 사용자 미술 승인, 도구 선택/저장, 출력, 게임 연결을 각각 기록. 미승인 후보 자동 최종 교체 금지 |

단계 통과는 제작 검수이며 단계마다 새 사용자 승인 질문을 만들지 않는다. 기존 첫 자세·주요 동작·최종 시안 승인 경계와 변경 범위 초과에 필요한 결정만 유지한다. 보정값에 사용한 표본과 독립 검증 표본을 구분한다. 한 장의 RGB 오차 감소나 보호 픽셀 동일만으로 단계 7/9 통과를 선언하지 않는다.

### 동작 선화 자연스러움 — 주요 자세·중간 선화 단계 보강

2026-11-13 사용자 요청에 따라 단계 3과 5에 적용한다. 이하 구체 절차는 문헌을 바탕으로 한 LASTRAIL 운영 기준이며 과학적으로 검증된 자연스러움 점수나 도구 자동 기능이 아니다. 승인 동작·노출 시간·체격·장비·바람 범위를 보존한다. 자연스러움을 명분으로 승인 타이밍을 바꾸거나 동작을 고정하지 않는다.

**작화 순서: 동작 의도·시간표 → 단순 덩어리 러프 → 주요 자세 → 경로를 정하는 중간 핵심 자세(breakdown) → 중간 러프 → 선화 재생 검토 → 정리된 선화 → 명암 연결.** 단계 4의 주요 명암 설계는 구조가 유효한 주요 자세에서 시작하며, 중간 선화가 주요 자세를 바꾸면 영향받는 명암 가이드도 재확인한다. 머리 가닥·옷 주름 같은 세부 선을 몸의 큰 동작보다 먼저 완성하지 않는다.

| 원리 | 작화·검수 기준 | 피해야 할 적용 |
| --- | --- | --- |
| 동작 의도와 예비 동작 | 준비·발동/접촉·잔동작·회복의 의미와 시점을 먼저 정한다. 손짓과 무기 실루엣이 실제 게임 크기에서도 읽혀야 한다 | 모든 동작에 큰 준비 동작을 추가하거나 승인된 공격 판정/FX 시점을 이동 |
| 타이밍과 자세 간 간격 | 각 프레임 노출 시간과 공간 이동량을 구분한다. 느린 구간은 가까운 자세, 빠른 구간은 큰 간격을 의도적으로 배치하고 전후 속도 흐름을 본다 | 12장을 좌표상 균등 분할하거나 프레임 번호만으로 속도 계산 |
| 경로와 중간 핵심 자세 | 손·팔꿈치·무기 끝·머리 중심의 경로를 정하고 가림이 바뀌는 중간 자세를 직접 설계한다. 관절 회전의 곡선과 목표를 향한 직선 이동을 구분한다 | 모든 동작을 원호로 강제. 승인된 직선 무기 상승을 곡선으로 바꾸거나 끝 자세 평균으로 중간을 대신함 |

| 체격·접지·힘의 전달 | 흉곽·골반·머리를 입체 덩어리로 보고 어깨–팔꿈치–손목과 고관절–무릎–발 연결을 유지한다. 지지 발의 접촉 구간/의도된 회전을 표시하고 미끄러짐을 검사한다 | 2D 면적 고정으로 원근 단축을 제거하거나 중심 표시만으로 실제 질량중심/물리 균형을 검증했다고 주장 |
| 잔동작·부위별 지연 | 몸의 주동작과 머리/자락의 반응을 구분한다. 뿌리·봉제 접속부는 이어지고 끝은 재질·길이·바람에 맞춰 뒤따르거나 회복한다 | 모든 부위를 동시에 같은 위상으로 흔들거나 전 부위에 고정된 지연 프레임 수 적용 |
| 선 자체의 시간적 일관성 | 큰 가닥·봉제·주요 주름의 정체성을 유지한다. 주름 생성/소멸과 가림에 근거가 있는지 보고 선 밀도·굵기 급변을 확인한다 | 선을 무조건 고정하거나 매 프레임 다른 잔선을 추가. 선 보간 알고리즘 통과를 자연스러운 신체 동작의 증거로 취급 |
| 루프와 idle 연결 | 끝 그림뿐 아니라 경계 전후의 이동 방향·속도·몸/머리/옷의 위상과 접촉 상태를 확인한다 | 12와 1이 같은 그림이라는 이유로 통과. 중복 끝 그림으로 의도하지 않은 정지 구간 생성 |

**동작별 적용:** idle은 작은 흉곽·어깨·옷의 연동과 바람을 구분하며 가슴만 확대하는 호흡을 피한다. 공격은 읽히는 예비 동작·발동·반동·회복을 구분하고 빠른 구간까지 모두 완만하게 만들지 않는다. 스킬은 손짓·시선·무기와 FX 사건을 맞추되 가림을 확인한다. 몸통 폭·팔다리 길이·무기 크기는 투영과 가림을 고려하여 비교하며 모든 프레임 픽셀 길이 동일을 강제하지 않는다.

**단계 3 추가 산출물:** 기존 QA에 주요 사건의 시간, 주동작 부위, 지지/접촉 구간, 기준 체격, 손·무기 경로, 필요한 중간 핵심 자세, 머리/옷의 반응 관계를 짧게 기록한다. 주요 자세만 보면 맞지만 중간 궤적이 모호하면 중간 핵심 자세를 먼저 보완한다. 모든 클립을 같은 포즈 개수나 같은 12칸 분배로 제한하지 않는다.

**단계 5 추가 통과 조건:**
1. 상세 선화 전에 러프를 승인 시간표로 재생하여 사건의 순서와 체중 이동 표현·관절 경로·가림을 확인한다. 뿌리/손목/접지 같은 연결을 유지한 채 실제 형태가 바뀌는지 본다. 조각 이동·스케일 변경을 작화로 대체하지 않는다.
2. 앞–현재–뒤와 연속 전환을 함께 검사한다. 선택한 관찰점의 이동량은 실제 시간 간격으로 비교하며 위치/속도 흔적은 경고 자료일 뿐이다. 저프레임 작화의 차분 jerk값을 자동 품질 점수로 쓰지 않는다.
3. 12→1 루프는 최소 11→12→1→2를 검사한다. 스킬→idle은 끝 2장과 연결되는 idle 첫 2장의 방향·속도·위상을 확인한다. 반복 노출·의도된 hold와 고유 원화 수를 구분한다.
4. 정상 속도에서 동작이 읽히는지, 느린 재생에서 형태·접합·선이 이어지는지 확인한다. 실제 관찰 불가능한 연속 지각 검수는 미검수로 남기고 배열/카운터 변화로 대체 통과하지 않는다.
5. 실패 원인을 궤적/간격/체격/접지/가림/잔동작/선 변화로 기록하고 해당 러프 또는 중간 핵심 자세로 복귀한다. 선화가 통과하지 않으면 밑색·명암·FX로 결함을 덮지 않는다.

**도구 보강 항목(미구현):** 기존 프레임 선택/재생에 주요 사건·접촉 구간 표기, 앞뒤 선화 겹쳐 보기, 선택 관찰점의 시간 기반 경로·간격 표시, 부위별 선 표시/숨김, 경계 구간 반복 검토를 편성한다. 도메인 시간표·선택본을 단일 원천으로 사용하고 View에 별도 타이밍/승인 원장을 만들지 않는다. 현재 기능과의 중복·실제 저장/호출 경로 확인 후 구현하며 자동 관절 추정·물리 시뮬레이션·선 보간 엔진 도입을 이 문서로 승인하지 않는다.

### 동작에 따른 명암·그림자 처리 — 단계 4·7·8 보강

2026-11-13 사용자 “좋아 다 보강해서 디벨롭”에 따라 앞선 제안을 운영 기준으로 편성한다. 문서 적용과 실제 도구 코드/시각 시험은 구분한다. 첫 프레임은 부위별 팔레트·화풍·기준 광원의 원본이지 모든 자세의 같은 화면 좌표를 같은 밝기로 고정하는 템플릿이 아니다. 동일 면이 회전·가림으로 다른 명암 역할에 들어가는 정상 변화는 허용하며 이유 없는 색/경계 변동과 분리해 검사한다. 기존 동일 면 RGB 규칙은 동일 재질·명암 역할 조건에서 적용한다.

1. **광원 기준 고정:** 방향·색·강도·경계의 부드러움과 화면/장면 중 어느 좌표 기준인지 기록한다. 좌우 원화 반전이 광원까지 자동 반전하는지 확인한다. 다른 클립/idle 연결도 같은 기준인지 비교한다. 이미 승인된 조명 스타일은 재사용하며 광원 자체를 바꾸는 작업과 자세에 따른 음영 변화를 구분한다.
2. **명암 종류 분리:** 형태 음영(면 방향), 주름/접촉 음영(접힘·겹침), 투영 그림자(가리는 물체→받는 면), FX 조명(발광 사건)을 구분한다. 전부 별도 파일일 필요는 없으나 독립 수정·표시·비교가 가능해야 한다. 투영 그림자는 받는 면에 속하며 가리는 물체의 마스크를 그대로 이동시키지 않는다. 흰 천/금속 등 재질별 밝은 면과 반사 표현을 동일 규칙으로 강제하지 않는다.
3. **주요 자세 명암 지도:** 준비·중간 핵심·최대 동작·복귀 중 필요한 자세에 부위/명암 종류/가리는 물체/받는 면/경계/팔레트/근거 광원을 연결한다. 한 팔이 몸통에서 떨어짐, 머리가 얼굴을 가리기 시작함, 소매 안쪽이 드러남 등 관계가 바뀌는 시점은 추가 기준 자세로 잡는다. 시간·장수는 승인 범위를 유지한다.
4. **중간 경계 작화:** 앞뒤 명암 지도와 해당 프레임 선화·가림을 함께 참고하여 그림자의 위치·방향·면적·단단함을 정한다. 면 분할·합류·신규 노출·재노출과 그림자 생성·소멸 이유를 기록한다. 화면 좌표 복사, 마스크 직선 이동, 알파 혼합/전역 블러만으로 중간 작화를 대체하지 않는다. 필요한 부드러운 명암 경계와 오류를 숨기는 블러는 구분한다.
5. **세 갈래 판정:** 색은 부위/명암 역할의 기준 팔레트, 형태는 자세·광원·가림, 연속성은 실제 시간표의 앞뒤 전환으로 검사한다. 면적/밝기가 달라졌다는 사실만으로 오류로 확정하지 않는다. 반대로 RGB가 같아도 무늬가 튀면 통과하지 않는다. 근거가 불확실한 자동 추정은 검토 후보로 남긴다.
6. **FX와 종료:** FX 조명은 인물 기본 채색을 덮어쓰지 않고 독립 합성한다. 발광 시작/정점/종료 때 얼굴·손짓 가림, 명암 읽힘과 idle 기본 조명 복귀를 확인한다. 밝기가 급변하는 의도된 발동 사건과 의도하지 않은 인물 명암 튐을 별도로 기록한다.
