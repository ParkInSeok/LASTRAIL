# LASTRAIL 프레임 작화 스튜디오

채색·명암 제작은 [동작별 그림자 처리](PRODUCTION.md#motion-dependent-shading-gate-20261113)와 [제작·출력 준비 검사](PRODUCTION.md#production-readiness-gate-20261113)를 함께 적용한다. 첫 프레임 팔레트를 유지하면서 자세·광원·가림에 따른 정상 명암 변화를 허용한다. 운영 기준 반영이며 도구 기능 구현·실제 클립 검수 완료는 아니다.

동작 선화는 [자연스러움 제작·검수 기준](PRODUCTION.md#motion-linework-naturalness-20261113)에 따라 큰 덩어리 러프 → 주요 자세 → 경로를 정하는 중간 핵심 자세 → 중간 러프·재생 확인 → 정리 선화로 진행한다. 승인 시간표·체격·장비를 유지하며 경로·접지·잔동작·루프 속도까지 검사한다. 관련 관찰 도구 보강은 미구현 계획이다.

선화·채색을 분리하는 신규 제작은 [단계별 제작 플로우](PRODUCTION.md#staged-line-color-production-flow-20261113)를 따른다. 기준 한 쌍 → 부위·팔레트 → 주요 선화·명암 설계 → 중간 선화 → 밑색 → 명암 연결 → 질감·FX → 전체 검수 순서다. 운영 문서 반영이며 부위/명암 관리 UI·자동 채색의 구현 완료를 뜻하지 않는다. 기존 승인 클립은 자동 재제작하지 않는다.

다음 제작·수정·재개는 [승인 기준·현재 작업본 확인](PRODUCTION.md#approval-working-version-gate-20261108)부터 시작한다. 신규 동작/승인된 동작 변경은 [주요 자세 사전 검수](PRODUCTION.md#key-pose-preflight-gate-20261108)를 통과한 뒤 중간 프레임을 제작한다. 기존 승인·검수는 범위가 유효하면 재사용한다.

플리커 진단·교정·검수는 [제작 정책의 필수 전 과정](PRODUCTION.md#flicker-improvement-workflow-20261108)을 먼저 따른다. 문제 부위·원인 확인 전 전체 보정을 시작하지 않으며, 한 구간의 실제 개선과 보호·접합 회귀 확인 후 확대한다. 이 링크는 운영 절차이며 자동 품질 판정 기능을 뜻하지 않는다.

## 탄환·명중 효과 제작 — 2026-10-14
방향별 제작 패널의 **탄환 · 명중 효과 제작**에서 물방울/광탄/불씨/고리/마력탄 형태, 외곽·중심 색, 발광과 명중 색·크기·지속시간을 정한 뒤 **효과 제작·저장**을 누른다. 탄환 사용·발사 프레임·총구 위치·방향·속도·비행 시간은 바로 위 단발 사격 설정을 사용한다. 생성 후 탄환 크기는 길이·두께로 조절할 수 있다.

개별 미리보기와 독립 PNG·설정 ZIP을 제공한다. **저장한 배치로 반복 영상 제작**은 비행 종료 지점에 명중 효과를 붙이며 합성 FX와 별도의 명중 PNG도 내보낸다. 실제 적 충돌 판정이나 Unity 연결은 아니다. 명중이 클립 끝을 넘으면 출력 오류로 안내한다. 설정 변경은 이전 출력/미술 승인을 무효화하고 원화와 제작 이력은 보존한다.

물방울탄과 명중 2.2배/160ms는 레이나 승인 시안 기준이다. 나머지 네 형태는 절차적으로 만든 검토용 기본형이며 외부 작가 자산이나 다른 요원의 승인본이 아니다. `effect_design.py`가 설정 검증/독립 제작, `battle_scene.py`가 배치/시간, `EffectDesignView`가 입력과 표시를 소유한다.

메인 화면 아래의 **원화 참고 국소 교정**에서 현재 프레임과 정확히 같은 크기의 교정본 PNG와 흑백 마스크 PNG, 실제 사용한 등록 원화, 생성 근거를 입력합니다. 이 기능은 원화 참고 생성 자체를 자동 실행하지 않습니다. 검토된 외부 생성본을 적용하며 원화 참고 사용 기록은 편집자 제공 근거로 표시합니다. 교정본의 RGB만 마스크로 합성하고 전체 alpha 및 검정 영역의 RGBA는 원본 그대로 보존합니다. 512×512 이내의 수정 범위만 허용하며 자동 크기 조정은 없습니다. 회색 마스크 값은 부분 혼합입니다.

`apply_reference_patch` API는 `index`, `source_index`, `source_asset`, `source_version`(0부터), `source_revision`, `reference_asset`, `generation_note`, `donor_png`, `mask_png`를 받습니다. PNG는 base64입니다. 프레임·현재 버전·프로젝트 revision이 달라지면 거부합니다. 등록 원화의 해시와 실제 donor/mask 사본·해시를 새 버전 검사 기록에 남깁니다. 기존 차단 사유를 보존하며 미술 승인하지 않습니다. 저장 실패 시 기존 프로젝트는 남으며, 성공 결과는 기존 버전 복원 기능으로 되돌립니다. 새 버전 생성 후 같은 요청을 재전송하면 오래된 요청으로 거부합니다.

경계의 명암 차이나 잘린 디테일은 별도 시각 검수가 필요합니다. 보존 검증 성공만으로 전체 모션·선명도·복식 일관성 개선을 보장하지 않습니다.

프로젝트를 선택한 뒤 상단 **컷씬 영상·음향 편집** 버튼을 누릅니다.
`/cutscene?id=<프로젝트ID>`는 기존 프로젝트에 연결된 로컬 편집 화면입니다.

- PNG/JPEG, MP4/MOV/WebM, WAV/MP3/OGG/M4A 파일을 추가하고 화면/BGM/SFX 트랙에 배치합니다.
- 클립 배치 시각·원본 시작·길이, 시작/끝 위치·확대, 불투명도·음량·페이드를 숫자로 편집합니다.
- 시간표는30fps 프레임 격자, 최대60초/48클립입니다. 음원 시각도 같은 격자에 맞춰지므로 정확한 cue 계약과 비교할 때 최대 반 프레임 차이를 검토해야 합니다.
- 저장 후 미리보기(360×640) 또는 MP4 출력(1080×1920/30fps H.264+AAC)을 만듭니다. 미리보기와 출력은 같은 합성 규칙입니다. 실시간 레이어 미리보기 대신 렌더된 영상을 재생합니다.
- 원본 영상의 소리는 자동으로 합치지 않습니다. 사용할 BGM/SFX 파일을 명시적으로 배치합니다. 각 버스 음량은 다음 출력에 반영됩니다.
- 출력 중단, 진행/실패, 저장 버전과 달라진 출력 표시를 지원합니다. 출력파일과 편집 이력은 `data/cutscenes/<id>`에 남습니다.
- `콘티 검토본 / 동작 영상 후보 / 사용자 승인본`은 편집자가 적는 표시입니다. 출력 성공이 기존 미술 승인이나 Unity 적용을 대신하지 않습니다.

영상 엔진 설치: 프로젝트용 Python으로 `pip install --target Tools/FrameStudio/vendor -r Tools/FrameStudio/requirements-video.txt`.

HTTP 파일 범위 읽기로 출력영상 탐색을 지원합니다. 외부 업로드·Runway 연결은 이 기능에 없습니다.

## 원화 조건 마스크 시험 (API, SD1.5 IPAdapter)

## GPU idle release — 2026-10-31
Start-Local.ps1 starts idle_gpu.py with its own lifetime. After 30 seconds with no running/pending ComfyUI work, the guard requests native /free (models + execution cache); it rechecks every 5 seconds and refreshes release every 30 idle seconds to catch short jobs between samples. ComfyUI performs release on its worker after execution, including a request race. No /interrupt or generation process termination. Next generation reloads models; startup may be slower. A fixed-endpoint file lock prevents duplicate guards. Direct main.py starts bypass the persistent launcher; current PID64636 has a guard attached without restart. CUDA runtime allocations remain. Errors are logged in LocalTemp/framestudio-idle-gpu.log. ComfyUI upgrades require rechecking native /free worker semantics.
